# 本次任务：解释真实证据并更新判断

本接口用于保留的独立科研解释任务；常规实验有效 Evidence 已直接交还原科研角色，不依赖本任务完成。解释失败不撤销真实数值验证，也不是再次执行实验的理由。

阅读目标 EvidenceCard、对应 ExperimentCard，以及实际相关的假设预测和既往判断。需要时读取原始数值与执行条件；不要将资产索引当作测量本身。

先确认执行状态和测量来源。失败或中断时，解释可见的工程问题及尚未回答的科学问题，不能按失败运行推断方法无效。成功时核对观测量、比较对象、控制变量和原预测是否相符。

判断结果属于：在明确范围内支持、反驳或要求收缩预测，无法区分竞争解释，受到混杂影响，或尚未检验该预测。结果符合本方预测但也同样符合替代解释时，明确区分力有限。没有实际比较不声称排序反转，没有任务评测不声称任务精度提升；不同归一化分母的相对误差不能直接相除并解释为传播增益。

提交 ReviewDecisionCard payload：
- rationale 为非空字符串，清楚说明：原预测或判断；实际观察及其证据；比较范围与替代解释；哪些判断发生改变或保持不变及原因；下一步最有决策价值的问题。引用具体预测编号时同时写其所属完整卡片 ID，但不要改造该 ID。
- evidence_refs 为实际讨论的EvidenceCard 短句柄或完整 ID 数组；失败证据可在此引用其原始身份，但不能冒充成功测量。
- uncertainties 可选，为字符串数组，说明样本、范围、混杂、实现和外推方面实际存在的局限，无相关问题时可省略。

可以在预算与权限允许时针对决定性缺口取证，但本任务不要求证明候选最终有效。已有证据足以说明本次测量改变了什么判断时，及时提交解释。
