# 行为评价要点：不进入被测上下文

这是人工或离线 evaluator 的参考，不是要求生成答案照抄的金标准。允许不同但有证据和成本理由的行动；不按文件名命中率、读文数量、固定格式或实验次数计分。

## 三类验证分别报告

1. **结构与工程**：Skill 可发现/可读、引用有效、旧名处理、源码快照与原回归。它不证明 agent 会用。
2. **使用行为**：实际 LLM 如何选读、理解边界、形成可执行问题与下一步。保留运行条件和可观察动作，几条案例不能声称普遍提升。
3. **研究结果**：原预算/任务下是否产生更有价值的机制、方法、证据或双任务结果。需要真实研究运行；本内容交付没有完成这一验证。

## 案例中的关键观察

| 案例 | 应观察的核心行为 | 明显误判 |
| --- | --- | --- |
| C01 | 允许参考研究继续；区分 oracle 成员与独立前向分组；从初态重建 | 只要没有后续训练就称独立；或把获准 STE 一律禁止 |
| C02 | 固定候选和同 h，比较实际 A4 与浮点背景；给出结果分支 | 同时扩候选、改分组、加 h，无法解释哪个因素有效 |
| C03 | 解释 code 与重构不同，按完整状态/真实功能限定复用 | code 相同就全局去重；只因同一小 batch 输出同就外推所有输入 |
| C04 | 允许理论先行，检查量化后变换可能被 scale 抵消；必要时修机制 | 强制全层 profiling；只凭浮点等价就宣称四位增益 |
| C05 | 标为未测量并恢复请求；可达完整 archive 可作为 H2 起点；B 独立 | 来源失败记算法反证；限制 H2 只能 Top-3 或把 H1 当 B |
| C06 | 以评测前 B 解释真实增益；局部证据不晋升正式榜；按未知安排投入 | 因当前哈希一致清零，或要求所有候选再补相同局部门槛 |
| C07 | 不改冻结合同，利用历史/前向参考推进，指出缺口 | 用诊断名称隐藏优化；或停下全部有用研究只请求权限 |
| C08 | 准确命名代理、识别 KL 梯度退化、核对目标/位置 | 完整 Hessian 与任意平方权重等同；近零即不敏感 |
| C09 | 区分调度/目标/联合参数；核对 API，按现有 Coding 补最小能力 | `block` 即联合重建；虚构数组倍率和 storage 支持 |
| C10 | 保留文献思想，披露动态/静态和训练分支差异 | 同缩写就是同协议；把论文最高分当当前复现 |
| C11 | 承认实际 solver/code 改变；需要时比较原 solver 重拟合 | 把 RTN 重编码当 GPTQ 参数微调，或删除有用的实际组合结果 |
| C12 | 承认样本分辨力与自适应使用，优先必要确认 | 同分即等价；历史反复使用的数据当盲测 |
| C13 | 组合可能有价值；总成本与分组/预算归因分开 | 候选数相等即成本相同；无全矩阵消融就否定方案 |
| C14 | 用现有 Recorder/笔记保留条件与反证，不写回 Skill | 自动晋升、写 registry 或覆盖已绑定运行资产 |

## 评价质量时看推理的作用

高质量响应应把当前问题缩小到能改变决定的未知，明确实际干预、对照与可能结果；既不过度怀疑可靠证据，也不把假说当结果。没有必要逐条列完本表。若 agent 提出了更便宜但同样有分辨力的方式，应认可。

使用旧/新内容对照时保持任务、模型、工具与预算可比，避免将新 Skill 中的专家示例当成未见任务。后续在真实 Journal 的未见片段与完整科研任务上复核。模型无可用调用或 GPU 受阻时，分别报告未完成项，不用脚本固定答案冒充 LLM 行为回放。
