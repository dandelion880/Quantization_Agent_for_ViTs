# 诊断决策案例：从证据走向可行动的问题

本页区分三类材料：用户历史研究摘要、当前源码/报告确认的能力，以及为解释决策而设计的情境分支。历史摘要只用于启发；需要引用具体数值、时序或方案身份时回读原始记录。情境分支没有被冒充为已发生实验。

## 案例一：DINOv3 的特殊 token 很大，是否直接为它设计量化器？

**历史背景。** 用户 PTQ4DINO 研究曾观察到某些 block 的 storage token 能量/幅值显著偏高，fc2 输入长尾稳定；后续认识没有把 DINOv3 与 DeiT 的全部差异归为 storage token 单因。原训练、动态量化等历史支线与当前 training-free static W4A4 合同应分别标记。

**先保留的解释。** 一种解释是特殊 token 拉大共享尺度，使多数 patch 分辨率不足；另一种解释是它虽然幅值大，却不主导对任务有害的误差，关键损失来自其他通道或传播位置。

**有用的诊断。** 在真实冻结方案上比较相关 token 的能量与实际量化误差，检查影响发生在当前量化边还是下游。若需要进一步区分，可固定其余量化器，对这一边做有方向干预，观察 patch 末端和 CLS，而非只再画一张直方图。

**条件分支。**

- 若该 token 本身误差大，干预同时改善下游，值得考虑表示/码点分配改良。
- 若其幅值大但量化误差小，或下游几乎不变，应把优先级让给其他已显露机制。
- 若 CLS 与 patch 反向变化，先保留任务分歧；不要用分类一个数字抹去对冻结分割表征的损伤。

**迁移所得。** 从“结构化异常”提出干预，而不是把“storage”或“block2”当作所有 ViT 的固定答案。

## 案例二：W4A32 很好，为什么 W4A4 仍差？

**历史背景。** 用户曾建立较强的 DINOv3 权重量化基线，而联合低比特时性能退化明显。这提示激活与 W/A 交互值得调查，但跨日期或不同数据协议的数字不能直接组成四臂因果对照。

**此时该问什么。** 问当前同一完整方案下，A-only 是否也退化、开启两类量化是否改变了输入/参考、某些边的尺度是否是在不匹配背景下确定。先查已有同条件证据，不默认需要重跑四个完整数据集。

**条件分支。**

- A-only 已明显恶化：优先寻找激活表示/网格/尺度与任务敏感性的联系。
- A-only 较好，joint 明显恶化：优先检查 W/A 耦合、次序与真实量化前缀。
- 结果只在改写 FP 参考下异常：先定位参考实现，避免把 FP 漂移误作量化机制。

**迁移所得。** W-only 成功用于缩小疑点，不等于证明激活是唯一原因，也不等于下一步一定要换成最复杂的 A 量化器。

## 案例三：三条候选都盯首层 Q

**当前项目背景。** 用户要求修正候选持续聚焦首个 Q 的现象。2026-11-16 报告确认增加了完整冻结模型传播诊断；报告中的 tiny/合成组件测试展示了局部新增与上游传播可不同、不同干预可能产生不同末端效果，没有证明真实 DeiT 的瓶颈位置。

**有用的起步。** 从现有可信 B 或完整候选选取少量有代表性的前、中、后块边界，复用样本看配对误差。若旧 Evidence 已覆盖大部分位置，只填当前未决范围。

**条件分支。**

- 首层 Q 的局部失真仍显著影响末端：继续这一方向合理；“换位点”不是目的。
- 末端损失主要对应后续块新增或传播：形成有证据的新研究入口。
- 各局部指标均好但末端任务差：考虑参考目标、表征敏感性、头路径或多处交互，而非随意挑第二大 MSE。

**迁移所得。** 让全局观测决定是否扩展搜索；不以强制三个不同位点制造表面多样性。

## 案例四：旁路后反而变差

**教学情境，非已验证项目结果。** 某块总偏差由局部新增与上游映射组成，二者部分抵消。FP 替换消除了本块局部误差，却使输出更远离完整 FP。

合理反应是核对干预是否真正只改变目标块，再检查有符号交叉项与后续输出。该结果反对“消除任何局部误差都必然改善整网”的假说；它不证明低精度本身有普适优势，也不证明该块无需研究。

可行的后续方向包括：保留当前冻结上下文比较更贴合完整 FP 目标的校准；或明确研究如何同时减少上游与本地误差，避免依赖脆弱抵消。是否投入取决于它能否改变当前候选选择。
