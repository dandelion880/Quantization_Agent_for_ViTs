# 误差传播、配对边界与冻结干预

## 1. 一次分解回答什么

对同一输入样本，在可比的块边界记完整 FP 前缀输入为 \(x_F\)，当前量化前缀输入为 \(x_Q\)。令 \(F\) 为该块的 FP 映射，\(Q\) 为当前冻结量化映射。定义

\[
e_{\mathrm{local}}=Q(x_Q)-F(x_Q),\qquad
e_{\mathrm{up}}=F(x_Q)-F(x_F),\qquad
e_{\mathrm{total}}=Q(x_Q)-F(x_F).
\]

只要输出在同一坐标与 shape 下，向量恒等式为

\[
e_{\mathrm{total}}=e_{\mathrm{local}}+e_{\mathrm{up}},\quad
\|e_{\mathrm{total}}\|_2^2=\|e_{\mathrm{local}}\|_2^2+
\|e_{\mathrm{up}}\|_2^2+2\langle e_{\mathrm{local}},e_{\mathrm{up}}\rangle.
\]

交叉项可为负：当前量化误差可能抵消一部分上游偏差。分别使用不同参考能量归一化的 NMSE 不能直接相加。跨层比较还需考虑维度与信号尺度；不能仅按原始 MSE 排根因。

这是一种**给定当前模型背景的条件分解**，不是对整网各层唯一、可加的因果归属。不同块的干预改变后续输入，多个单点收益也不能机械相加。

## 2. 由观察选择下一动作

| 观察 | 值得考虑的解释 | 下一步选择 |
|---|---|---|
| `local_added` 小，`upstream_mapped` 大 | 本块主要承接/传播已有偏差 | 检查更早输入变化，或考虑真实 Q 前缀与 FP 目标的失配 |
| `local_added` 大，但块替换几乎不改变末端 | 下游抑制、冗余或观测不敏感 | 不因局部数字大就继续投入；按实际任务需要检查观测是否合适 |
| `local_added` 下降而 total 上升 | 误差方向改变，抵消减少；参考/背景也可能变化 | 先核对配对条件，再检查交叉项和下游，不宣布局部改进无效或有效 |
| FP 块替换明显改善末端 | 当前背景存在干预敏感性 | 再问合法有限码本/尺度/校准改动能否利用它；不是已取得合法收益 |
| CLS 改善，patch 表征恶化 | 不同任务敏感方向不同 | 保留两个观测，结合当前任务目标选择进一步验证 |
| 早层 Q 旁路无改善，后续块干预有改善 | 单点聚焦可能漏掉传播或后续误差 | 把有证据的新位置加入候选，不强迫所有 H 换位置 |

当“哪个分数更代表研究目标”成为主要未知时，转校准目标选择；当“什么干预能区分解释”仍不清楚时，转判别性实验设计。

## 3. 三种干预不要混淆

**局部量化旁路**：保持其他状态不变，把某一实际量化边切回 FP。它回答当前背景对该边量化的敏感性；若旁路同时改变了缓存、重参数化或相邻量化器，应明确这些额外变化。

**FP block 接收 Q 输入**：用 \(F(x_Q)\) 替换 \(Q(x_Q)\)，可区分该块新增失真与已有输入偏差。FP block 需要与被替换边界一致；不能在不同残差坐标或不同融合前后位置之间直接替换。

**合法量化方案干预**：改变尺度、有限码本、校准背景或补偿机制，同时满足当前最终合同。它回答具体可实现方案的收益。成功仍只限实际样本与任务；是否升级正式评价由研究者决定。

FP 替换的影响不是可保证达到的上界：有限码本方案未必能逼近该替换；重新优化其他块还可能改变结果。把它作为方向线索更准确。

## 4. 配对条件与任务输出

优先复用同一个冻结完整方案、同一组实际样本和同一 FP 源。记录观察究竟来自 calibration、search 还是不参与选择的数据；诊断数据不自动成为独立泛化证据。

ViT 的 token 布局必须从模型确认。只有确认首位为 CLS、后续均为 patch 时才按此切分；DINO 的 storage/register、DeiT 的 distillation token、其他额外 token 都可能改变布局。未知时先报告可确认的 all 表征。

分类 logits 与密集预测表征不能用同一个名称掩盖。对冻结 ADE head 的观测需真正经过该 head；patch 特征误差只是中间证据，不能替代 mIoU。少量样本上的 Top-1 平局可能来自离散性，不能单凭平局认定所有干预等价。

## 5. 当前 QAViT 的可执行入口与边界

依据当前源码，`ptq_agent.execution.propagation.profile_frozen_propagation` 已支持所选真实 block 的 FP/Q 配对、local/upstream/total 与交叉项、token 子集、命名输出和冻结干预。它可通过 `frozen_helper` 直接请求，也兼容现有 custom 实验链调用；参数见 [能力目录](../../../CAPABILITIES.md)；冻结源应由请求顶层 `evidence_refs` 或 `solution_refs` 精确声明，再经 `context['load_frozen']` 加载。名称、配置与当前调用权限以实际接口为准。

已知边界：默认不自动构造 ADE head；当前 block 接口不代表支持任意多参数/结构化输出模块；历史 trial 诊断不等于完整历史方案诊断。真实 DeiT/ADE 效益尚不能从 tiny/合成组件测试推出。

若工具不满足所需边界，向原 Coding 链说明最小测量与状态恢复要求；不要给宿主增加“先做完全网诊断才允许提交”的科学门禁。
