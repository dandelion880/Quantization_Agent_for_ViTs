# W / A / 交互误差定位：条件式研究策略

**适用**：可信 PTQ 模型确实退化，但主导误差来源尚未定位。量化位宽、任务、模型、数据和评测版本不同的数字不能构成严格同条件对照。

## 最小分解框架

在条件允许时比较：`FP (W32A32)`、`W-only (W4A32)`、`A-only (W32A4)`、`joint (W4A4)`。这组术语表示研究上隔离效应的诊断模型，不是对完整 W4A4 合同的多种“合规替代”。若缺少某分量，先判断是否有现有 Evidence，或是否值得补一项测量。

| 可比观察 | 优先研究方向 | 必须保留的替代解释 |
| --- | --- | --- |
| W-only 已显著退化 | 权重组/尺度/舍入、局部重构及下游敏感性 | A 量化也可能重要；W-only 代理误差未必预测 W4A4 |
| A-only 退化明显 | activation 分布与码点、LN/GELU/Softmax、token/channel 异常、scale | 大幅值不一定主导误差；分位统计可能被样本选择影响 |
| W-only 尚好，joint 明显失效 | A-only 与交互效应、上游真实量化前缀、量化误差累积 | 不能只因 W-only 好便证明 A 是唯一原因 |
| W-only、A-only 都可接受，joint 却很差 | W/A 耦合、量化顺序、输入—参考目标失配、层间残差传播 | 可能是评估路径或冻结身份不同，须先排除协议差异 |
| 特定层局部 NMSE 高，但 logits/任务稳定 | 局部误差的下游抑制、指标与任务目标不一致 | 仅改最大 NMSE 位点不一定有价值 |
| 局部误差低，但最终结果差 | 敏感层、残差和 LayerScale 放大、累计偏置、评测头 | 不能仅靠调低单层 NMSE 来证明机制修复 |

## 如何利用工具

- `profile_sensitivity` 是基于简化 RTN W/A/联合 QDQ 的线索；若它指向某个层，可再考察真实冻结候选。不要把 RTN 结果当复杂 PTQ 的因果定论。
- `profile_ptq_candidates` 能比较有限候选与局部拟合，但仍需关注 search/calibration 与独立评测的界限。
- 已有 candidate 才有意义地使用 `profile_trial_diagnostics`、`profile_trial_ablation`；冻结父候选与输入条件，解释撤销量化后其他位点仍量化的状态。
- 仅当两个解释无法区分时，转交判别性实验 Skill；若现有证据已足够定位，则直接形成方案设计或下步判断。

## 案例（仅作为研究模式）

DINOv3 早期 W4A32 接近干净 FP32，而 W4A4 明显下降：这是优先调查激活与交互的合理线索，不是一个已经证明所有问题由 activation 引起的结论。不同日期、校准数据、任务协议与方法版本的结果必须分开记录。

**不要强制**：每次都重新运行完整 4-way；若某个局部确切矛盾只需一次冻结对照，优先少量判别性证据。
