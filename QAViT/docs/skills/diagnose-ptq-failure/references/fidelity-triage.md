# 可信性怀疑时的最小核验策略

**仅在有具体可疑信号时读取。** 本文不是每个研究任务必须执行的测试清单，也不替代现有 Safeguard 或 ResearchBrief 合同执行。

## 先回答“异常是否真的来自量化？”

| 观察到的信号 | 值得检查的证据 | 可能改变的判断 |
| --- | --- | --- |
| FP 任务精度、logits 或特征与预期不符 | 冻结 checkpoint/head/预处理/样本列表；必要时在同输入上逐算子/逐层比较原始 FP 与改写 FP 路径 | 若 FP 不等价，先定位实现/评测而非优化量化器 |
| 新模型或新算子接入后性能突降 | 算子输入输出位置、LayerScale/残差分支、norm/softmax 的位置，显式 attention 等价性 | 排除错误修改了原始函数的情况 |
| 宣称某位宽但码点/覆盖可疑 | 量化器作用轴/零点/scale、distinct reconstruction levels、核心模型的真实 W/A 覆盖、冻结后重载身份 | 查是否是标签不实、仅 Linear fake quant、或超过 ResearchBrief 码点约束 |
| 校准很好但正式结果异常 | calibration/search/holdout/final 样本清单、冻结模型版本、随机性、数据泄漏、归一化及指标口径 | 区分过拟合、协议差异和量化算法失败 |
| 新候选“跑通”但仅一图/局部 | 查看真实 Evidence 的任务覆盖、算子数量、W/A 参与范围、是否保存重载 | 局部可执行性不能升级为完整结果 |

## 建议行动

1. **选最短证据链**：已有等价性测试成功时不重跑；新改写算子只检查受影响的范围。`query_structure` / `query_ptq_sites` / `query_execution_capabilities` 可帮助确认位点和运行能力，但它们不是性能结果。
2. **对量化合同作准确区分**：用户指定 static W4A4 时核心权重与激活都需按 ResearchBrief 量化，允许的 head/neck FP 和算子内部高精度计算不能混淆；A4/W4 各量化边的码字限制须按当次合同的精确定义计算。不能把额外零重构值、额外掩码或下溢例外悄悄排除在码点统计之外。
3. **诊断可有旁路，声明不能越界**：W-only、A-only、去量化单点/局部 A32 是合法机制定位，不是完整 static W4A4。明确实验目的、受影响量化边和结论边界即可。
4. **找到实现问题则归工程**：只将确切失败位点、观测/期望和最小复现实验交给现有 Coding/Safeguard。不要额外生成 Reference 实现、对所有历史候选重新审批，或把工程报错变成“算法无效”。

## 退出信号

- 已有可信 FP/冻结候选与协议：进入正常机制诊断。
- 某个新适配位置明确不等价：交给现有工程链修复，保留相关证据。
- 来源仍不可判定：说清缺哪一项观察；仅在有科研价值时申请最小测量。
