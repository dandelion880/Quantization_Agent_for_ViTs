# 可信基线与 W/A 作用范围

## 1. 先定位异常属于哪一层

基线核验只针对具体疑点。若模型、预处理、冻结头、数据与重载身份已有可信证据，不重复完整审计。

| 具体疑点 | 最短有用比较 | 比较后怎样行动 |
|---|---|---|
| FP 表现比可信历史基线低 | 同一样本、同一预处理下比较源 FP 与当前 FP 包；必要时逐边界缩小差异 | 先解决 FP 函数/评测差异，暂不把量化方案成绩用于算法归因 |
| 显式 attention 或融合改写后变差 | 量化关闭时比较改写前后的算子输出，确认 mask、缩放、残差、bias 和 LayerScale | 只修有差异的适配位置；不创建第二套长期参考实现 |
| 校准后正常，导出重载后异常 | 同输入比较冻结前/后量化参数、输出与当前正式审计回执 | 归为状态持久化问题；恢复后再解释科学结果 |
| 论文/历史数字与当前结果不同 | 先比模型版本、任务头、分辨率、样本划分、量化边和校准预算 | 不可比时标明差异；不把差距全归因于实现失败 |
| 声称 W4A4，但结果异常好 | 只在有疑点的位置核对覆盖、实际重构值数和浮点例外 | 依据 ResearchBrief 判断，不依据方法名或整数编号习惯判断 |

基线不是“越高越可信”。重点是它是否对应当前研究问题，是否仍实现应比较的原始函数。原 FP 与近似改写 FP 的差异本身是需要解释的现象。

## 2. 区分 W、A 与联合影响

可比的四个诊断状态是 FP、W-only、A-only、W+A。它们用于定位，不是四种可互换的最终合规方案。使用时问清：四臂是否共享相同起点与量化参数，是否各自重新校准，是否改变了参考或数据？

- **固定量化参数、切换 W/A 开关**回答“在当前冻结参数背景下，打开某类量化怎样影响输出”。
- **每臂分别充分校准**回答“各自适配后的策略能达到怎样的表现”。两类实验不能混成一次纯量化开关归因。
- FP、W-only、A-only、joint 的任务准确率不可直接相减来得到可加的“因果误差份额”。即使使用平方误差，也需在相同参考与坐标下定义交互。

| 配对现象 | 优先解释 | 仍需保留的竞争解释 |
|---|---|---|
| W-only 已退化 | 权重舍入、分组、输入协方差或实现适配 | A 仍可能重要；当前 W-only 排名不一定迁移到 joint |
| A-only 已退化 | 表示/网格失配、尺度动态范围、敏感 token 或算子 | 幅值最大不必等于任务影响最大 |
| W-only 良好，joint 很差 | 激活及 W/A 相互作用值得优先调查 | 缺少 A-only 时不能宣布“只需修激活” |
| 两个单独状态都较好，joint 显著差 | 耦合、校准输入背景改变、误差方向与传播 | 各臂重新校准或样本不一致也可能造成表象 |
| 单层量化影响小，逐层累积后明显差 | 前缀偏差、跨层交互、下游放大 | 小局部样本/不敏感观测可能漏掉局部问题 |

如果已有局部问题只需一次有方向的实验即可回答，不补齐四臂以满足形式。

## 3. 让 outlier 分析回答问题

从“某值大”走向“它改变了量化选择和关心的输出”，需要按争议挑选观察：

1. **数值结构**：幅值分布、正负不对称、跨图稳定性、token/channel 坐标。相同绝对幅值在不同层未必同样异常。
2. **编码作用**：量化重构误差、削顶与舍入的相对作用、码点利用、共同尺度是否使其他位置分辨率不足。
3. **函数作用**：干预该边后，邻近算子和末端表征怎样改变；残差支路或 LayerScale 是否抑制/放大影响。
4. **可实现作用**：合法 static W4A4 改动能否利用这部分恢复空间，代价和交互是什么。

只观察边缘 token 能量与边缘 channel 幅值，无法确定某个 token×channel 交叉位置。需要时采集目标位置；不为追求完整画像保存全部巨型张量。
