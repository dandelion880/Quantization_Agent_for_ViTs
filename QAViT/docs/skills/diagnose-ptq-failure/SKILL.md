# 定位量化失效与可改善的瓶颈

形成一个足以指导下一项研究的判断：**异常是否可信，哪些解释仍成立，哪一处干预最有希望改变关心的输出**。允许结论是“尚不能定位”，也允许发现问题来自实现或评测。

## 从当前不确定性进入

先用已交付 Evidence、方案身份和当前任务还原症状。只补会改变诊断的缺失信息；已有可信基线不从头审计。下面各入口可以直接进入、组合或跳过。

| 当前症状 | 优先辨认 | 有辨别力的下一观察 |
|---|---|---|
| 新 FP 路径也变差、重载前后不一致 | 参考、模型适配或评测是否发生变化 | 同样本原始 FP 与改写 FP 的对应边界，而非继续调量化器 |
| W-only 较好，W+A 明显退化 | 激活误差与 W/A 交互，不能只凭差值认定单一根因 | 可比 A-only、joint 或一个定向局部干预 |
| 特殊 token/channel 的幅值很大 | 幅值、量化失真与下游影响是否落在同一位置 | 实际编码误差、能量占比及冻结干预的下游变化 |
| 某块输出误差大，但该块局部重构好 | 上游输入偏差、局部新增和抵消/放大 | 同 FP/Q 输入边界下的条件分解 |
| 局部指标改善，末端表示或任务变差 | 比较参考、前缀、误差方向与任务敏感性 | 同一冻结背景下的局部与下游配对观测 |
| 多轮候选都围绕首层 Q | 是否遗漏了更有影响的后续边或机制 | 少量代表性边界的轮廓，再做定向干预；无需强制全网扫描 |

可信性与 W/A 隔离问题读 [可信基线与作用范围](references/baseline-and-scope.md)；传播、旁路与分 token 解释读 [误差传播与冻结干预](references/error-propagation-and-intervention.md)；需要从真实研究背景学习判断时读 [诊断决策案例](references/diagnosis-cases.md)。

## 让诊断改变研究选择

1. **先给出候选解释。** 例如“本块码点分配不合适”和“前缀偏差经本块放大”。只保留会导致不同下一步行动的解释；不为形式要求凑固定个数。
2. **把统计热点转为可检验命题。** 指明真实量化边、输入背景、token/channel 轴，以及预期影响的输出。raw q99.9 最大与量化根因不是同一命题。
3. **需要时做一个定向干预。** 冻结其余量化状态，检查该边旁路、FP block 替换或合法候选变更后的近端与下游变化。先辨认干预回答的是定位、恢复空间还是合法方案收益。
4. **依据结果缩小范围。** 局部失真大而下游影响小，可降低优先级；局部新增小而输入偏差大，转向上游或校准背景；CLS 改善而 patch 变差，保留任务冲突，不强行压成一个结论。
5. **选择够用的诊断深度。** 全网扫描成本高时，可从绑定模型的实际任务读出和分支汇合处取少量配对边界。若多个读出共同恶化，优先区分上游累积与共享规则失配；若只在一段之后分离，可收窄到该段。整块旁路改变多条边，只能提供范围依据。 已能选择干预时停止扩展 profiling。两个解释仍导向不同决策时，转 [判别性实验设计](../design-discriminative-experiment/SKILL.md)；不为填满层表而测所有层。

## 用现有能力取得证据

- 位置/算子不清楚时按需查结构与真实量化位点；`query_structure`、`query_ptq_sites` 等名称是已有 profile 服务内的能力，不是保证本任务直接暴露的角色工具。
- 分布观察可用 `profile_distribution`、`profile_plugin_sites`。只有 token 与 channel 两个边缘统计时，不推断其联合位置。
- `profile_sensitivity` 的简化 RTN/QDQ 结果用于筛查；复杂冻结方案的归因需回到该方案本身。
- 已有 trial 可用其诊断/消融入口。完整历史包的传播诊断可直接请求 `frozen_helper` 的 `profile_frozen_propagation`，也兼容原 custom 实验链；来源、可读 API、支持范围以当前接口回执为准。
- 现有工具不足时，给 Coding 一个最小科学测量目标。请求说明比较对象、冻结条件和观测量，不凭 Skill 猜造 API、路径或已存在的模型包。

## 在决策边界交接

- 机制或有根据的干预方向已清楚：进入 [机制改良](../adapt-quantization-method/SKILL.md)。H3 的理论构想也可直接进入该技能，不必先完成诊断。
- 问题集中在“用哪个目标判候选好坏”：进入 [校准目标选择](../select-calibration-objective/SKILL.md)。
- 目标已确定，问题是尺度在哪里、何时、怎样拟合：进入 [尺度校准设计](../design-scale-calibration/SKILL.md)。
- 已有完整结果，需要决定继续、推广或停止：进入 [候选评价](../evaluate-ptq-candidate/SKILL.md)。

在现有研究正文或 research_note 中简洁保留：症状、主解释及重要替代解释、支持/反对证据、下一行动与未知范围。没有新表单或固定输出顺序。

## 保护证据含义

旁路和 FP 替换是诊断状态，不是完整 static W4A4 结果；其收益也不是合法 W4A4 的可达上界。加载、来源、CUDA、shape 或预算失败说明未执行，不反驳量化机制。H1/H2 都改良明确的完整起点，B 独立保留；诊断不设置换位点、实验次数、论文继承或 H3 审批要求。
