# 用实验区分量化机制

**核心成果**：让一项实验（或一项已有证据）能使研究者改变对竞争解释的判断，而不只是多生成一个分数。

## 作出实验决策

1. 明确当前最重要的研究争议：机制 M、替代解释 A 及各自会预测的不同观测。若两者在拟测量上给出相同预测，先调整实验问题。
2. 查询相关历史 Evidence、冻结候选、当前 peer、可重用的模型前缀与样本身份；复用已有工具/结果，避免为局部问题重建整网。
3. 根据争议选择 [experiment-patterns.md](references/experiment-patterns.md) 的策略：单因素受控对照、条件性 2×2 因子对照、冻结前缀对照、反事实旁路、阶段次序或独立 holdout。**不要求每次完成消融矩阵。**
4. 用 [metrics-and-references.md](references/metrics-and-references.md) 选择能回答争议的目标指标和参考：局部编码/拟合误差、算子输出、AV/PV、logits、任务性能；区分“同部署量化 peer”与“FP 目标”的作用。比较条件尽量一致，无法保持的混杂必须说明。
5. 选择成本最小但能影响决策的 L0、L1 或更完整测量。不存在必须从 L0 逐级通关的要求；已有证据足够时不实验。
6. 预想不同结果如何影响假设：支持、反驳、混杂未解、负结果、实现失败、预算未完成。工程失败不能直接当科学反证。

## 与 QAViT 的交互

实验请求交由原有 Coding/Safeguard/执行链：只描述科学问题、比较组、需保持相同的因素、关键指标及反驳情境。不要给 Coding 强制指定变量名、目录名或无关运行细节；也不新增 Judger 审批。结果返回原请求研究者后，由其解释并可继续研究。

**典型情境**：双区间 GELU 网格看似更优，但使用了不同拟合输入；可以考虑“网格 × 输入来源”的小型交叉对照，区分码点能力和前缀失配。

**不触发**：已冻结可信完整方案，仅按协议运行 ImageNet 正式分类。

**退出**：已找到能区分解释的必要测量、现有证据足以决策，或没有值得成本的区分性实验。可以直接不申请新实验。
