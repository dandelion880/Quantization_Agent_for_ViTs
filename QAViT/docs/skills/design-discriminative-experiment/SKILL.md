# 选择能改变决策的实验

把当前争议转成一个可观察差异，再选择成本可承受、足以影响下一步的测量。**允许结果支持、反对、显示混杂未解或证明当前测量无区分力。**

## 先说明实验将改变什么

从当前假说、反例与下一决策出发，用自然语言回答：

- 当前最重要的解释是什么，哪一个替代解释会让你改做别的研究？
- 两者在哪个可控干预或观测上给出不同预测？
- 若出现相反结果，分别继续、修订、暂停什么？

如果拟测指标在两种解释下都预期变好，先换测量或控制变量。若无论结果怎样都做同一件事，检查实验是否仍有实现核验、估计精度或最终验证价值；没有则省去。

## 按争议选择设计

| 争议 | 可选设计 | 成功后获得的认识 |
|---|---|---|
| 新网格有效，还是校准输入变了 | 固定背景的单因素对照；必要时网格×输入 2×2 | 哪个因素及交互改变结果 |
| 新补偿机制有效，还是自由度/预算更多 | 同完整起点、相近预算的简单可行对照 | 复杂部分是否有独立贡献 |
| 某边是主要瓶颈，还是仅为统计热点 | 冻结单边干预并看近端与下游 | 当前背景下的敏感性与传播 |
| 方法只适配 calibration，还是有可迁移改善 | 冻结参数后观察未参与该次选择的样本 | 改善是否超出拟合样本 |
| W/A 或两个模块有交互 | 保留必要单臂和组合臂；固定其余条件 | 两个变化为何应组合或分开 |
| H3 理论上改变了量化，但整网开发昂贵 | 先做最小数学/数值原型，检查真实码本和预测 | 是否值得投入下一层实现 |

细化对照、配对单位和混杂时读 [实验模式与控制](references/experiment-patterns.md)；需要观察“结果如何改变下一步”时读 [完整决策示例](references/decision-examples.md)。无需按表逐项执行。

## 在可执行性与信息价值之间选择

1. 复用已有 Evidence、冻结包、样本和已验证工具；已有同条件实验足够时直接判断。
2. 先估计每个对照会排除哪种解释、需要几次重校准或后缀前向。固定完整父状态能省去重复校准，但若干预改变了后层的拟合输入，应区分冻结后缀的敏感性与按新规则重建的完整效果。仅剩任务迁移问题时可直接考虑绑定的双任务开发评价。
3. 保持与问题相关的控制变量。无法统一的条件明确写出，不用额外流程掩盖真实不可比性。
4. 将校准内部拟合、search 的候选选择与最终评价分开。结果已用于选择后，该集合不再是对后续选择完全未见的数据。
5. 选择观测精度与样本量时考虑信号。少量 Top-1 平局可用预先合理的连续观测辅助解释；不得事后挑最有利 metric 宣布成功。
6. 给出合理停止点。核心命题已被可信结果否定时可停止；工程失败则先修请求/实现，不能当作科学反证。

## 发出科学请求并接续解释

沿现有 `request_experiment → Coding/Safeguard → 执行 → Evidence` 链，说明科学问题、比较组、需保持的因素、关键观测、数据使用与结果的决策影响。具体函数、目录和运行细节交当前接口与 Coding；不新增判别实验审批。

回执到达后先判断是否真的测到了所需变量，再比较预测：支持时检查最强替代解释；相反时修订主张；混杂未解时调整对照；低信号时判断继续测量是否仍值成本。将这个变化写入原研究正文或 research_note 即可，不另起必填报告。

## 与相邻技能的分工

- 不知道问题在哪里：按需用 [量化诊断](../diagnose-ptq-failure/SKILL.md)。本技能负责下一项取证，不强制先诊断。
- 想选择哪个损失/参考作为量化候选排序标准：用 [校准目标选择](../select-calibration-objective/SKILL.md)。它给出目标，本技能处理目标间冲突所需的判别实验。
- 想分配层/block 的尺度拟合、搜索与重估：用 [尺度校准设计](../design-scale-calibration/SKILL.md)。
- 机制已明确，想构造具体算法干预：用 [机制改良](../adapt-quantization-method/SKILL.md)。
- 已取得候选结果，想判断是否升级正式评价或暂停：用 [候选评价](../evaluate-ptq-candidate/SKILL.md)。

H1/H2 的成熟起点与 H3 的新机制都可以获得有价值的实验机会。B 独立保存已有成果；不因 B 已可运行就自动否定探索，也不为“创新”要求完整消融矩阵或固定实验次数。

局部实验需要非零起点时，experiment_v1 的 parameters.diagnostic_view 可绑定解码前的有序子集，实际消费范围随 Evidence 回传。接口字段见 [实验输入](../../EXPERIMENT_INPUTS.md)。

## 让测量改变科研决定

**触发。** 两个解释都能说明结果，方法与预算/数据混杂，H3 需要最小可证伪原型，或不知道下一项实验是否值得做。

**前提与范围。** 明确下一决定。若无论结果怎样都执行同一动作，应检查实验是否仍有实现核验或最终评价价值；没有就省去。

**步骤。**

1. 写出主解释与最重要竞争解释，以及它们预测不同的可观察量。允许理论启发，不虚构已有 profiling。
2. 选最少必要对照：固定父状态单因素、一个需要的交互臂、参数交换、同预算简单机制，或独立数据确认。只有交互本身影响判断才扩成因子设计。
3. 对齐能改变结论的条件：源模型、数据用途、初始冻结状态、优化自由度、候选池、总成本和任务目标。无法对齐的部分如实保留，历史比较仍可描述但不作单因素因果证明。
4. 沿现有实验入口声明干预、控制、观测和结果分支。先用数学/局部试验否定明显错误，再按剩余问题升级；已足够接近真实任务时也可直接做适当开发评价，不强制逐级打卡。
5. 回执到达后先核实测到了什么，再解释支持、反对、低信号或仍混杂；选择继续、修订、简化或暂停。

**结果解释与下一步。** 新方法与同预算简单对照相同，研究复杂部分是否必要；多步优化仍不改善而少量新图有效，转数据覆盖；只改变局部 loss 而下游无响应，缩小主张；执行失败先定位工程原因。

**案例草案。** 补偿加上更长重构取得收益，但尚不知贡献。若下一步是决定是否保留补偿，只需同一父状态下的“原预算补偿”和“匹配预算无补偿”等能回答该问题的对照，不要求把所有方法组件拆成完整矩阵。

**复用边界。** 不以统计显著性、实验次数或全网扫描作为所有假设的统一门槛。局部 FP 干预可以用于定位，但不能冒充最终量化候选。相同评测清单不保证校准过程可比。
