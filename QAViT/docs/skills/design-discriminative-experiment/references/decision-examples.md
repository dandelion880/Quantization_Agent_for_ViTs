# 从一次实验走向下一次决策

以下为教学用决策情境，不是新增 QAViT 实测报告。其价值在于展示不同结果怎样改变研究行动；不能把预期分支写进 Evidence。

## 案例一：新非均匀网格的收益来自哪里？

**已知。** 候选相对旧方案局部误差下降，但同时把拟合输入从 FP 改成了真实 Q 前缀。当前计划拟将“新码点布局解决误差”作为机制主张。

**竞争解释。** M1：新网格匹配了激活分布；M2：主要收益来自修正输入背景。两者都预测原组合候选优于旧方案，所以再重复一次同样组合不具有足够区分力。

**实验选择。** 先看已有证据覆盖哪几个匹配臂。如果组合与旧起点已有真实配对结果，可只补一个最能改变当前选择的臂。例如“旧网格＋Q 前缀”若已经达到组合收益，就会改变是否继续开发新网格的决定。需要估计交互时再补完整矩阵。

**读到结果后。**

- 旧网格＋Q 前缀已解释主要收益：缩小新网格的机制主张，优先把校准背景作为改良；复杂网格是否保留由其他证据决定。
- 新网格在两类输入下均改善：支持网格具有较独立的作用，仍需检查下游和拟合外样本。
- 只有组合有益：把研究问题改成“网格与输入背景的交互”，不要强行给单一模块归功。
- 结果无法比较，因某臂没有正确安装选中参数：先修实现并保留未执行状态。

**结束条件。** 证据足以决定是否投入新网格，就结束这组诊断；不因矩阵未满而拒绝提交合理候选。

## 案例二：H3 的 P/V 补偿值得开发成整网方法吗？

**已知。** H3 提出改变 attention 概率与 value 的相互作用，使量化后的 PV 更贴近参考。大规模实现昂贵，尚无机制证据。

**先问可证伪命题。** 干预是否在有限码点下改变真实重构值，改变是否落到 PV，而非只改变中间参数名称？若方法在某个单位参数值应退化为原方案，这个控制是否真正恢复父方案？

**最小实验。** 在来源明确的冻结方案上，选择能覆盖该机制的真实 attention 输入，比较父方案、单位参数控制及少量有理论差异的干预。保留 P、V 与 PV 相关观测，保持其他量化边和样本一致。源码不必分成多套；对照由同一清晰实现的参数控制。

**不同结果的行动。**

- 所有臂是同一个实际码器：先解释尺度不变性、舍入平台或安装问题，不能把搜索平局视作新机制已获支持。
- P 的误差下降而 PV 更差：核心输出预测受反证，检查 V 的任务加权作用或改动方向。
- PV 局部改善但末端变差：保留局部结论，研究传播/参考失配；不包装成完整候选获胜。
- 原包无法加载：修来源请求或实现，记录未完成；不写“H3 无效”。

**结束条件。** 原型暴露核心命题不成立时可缩小/重构 H3；有明确支持时再决定是否值得进一步完整化。不要求每个 H3 必经同一原型，也不保证 H3 因新颖而晋升。

## 案例三：该继续局部搜索，还是直接正式验证？

**已知。** 已有可执行完整候选，局部改善与少量末端观测方向一致。剩余争议是能否在当前正式双任务协议下获得收益。再加一项相似局部 profile 不能显著降低这一不确定性。

**选择。** 若资源允许，直接规划合法 L3 是合理下一步；无需先补齐每个 Skill、所有消融或固定样本阶梯。B 已独立保留，允许把下一笔科研投入用于这个探索。

**相反情境。** 若候选只在校准样本上改善、完整实现尚未定义，且一个低成本受控实验可能立刻推翻核心机制，则先做这个实验更合理。两者的区别在于剩余不确定性，不在于“局部实验天然优先”或“正式测评天然更权威”。

**结果返回。** 任务成绩回答该候选表现；要把改善归因于某一机制仍需相应控制。发现负结果后，记录其实际条件和能排除的解释，再决定修订、退回父方案或暂停。

## 案例四：负结果还值得再做一次吗？

**已知。** 一次合法测量不支持假说。研究者想换一组样本再试。

有价值的重复需要具体理由：原样本太少导致观测分辨率不足；原输入没有覆盖方法声称的适用条件；存在明确的实现疑点；或者结论的重要性值得估计不确定性。仅因结果不理想而换样本反复筛选，容易把偶然有利结果变成假规律。

先说明哪个未知会被重复解决，以及再次得到负结果时是否改变行动。若两种结果都不改变方向，优先重新审视研究命题。

## 使用边界

这些案例示范决策方式，不规定目标层、参数值、样本配额、实验顺序或晋升阈值。当前 QAViT 的真实工具权限、科学请求和模型来源以 ResearchBrief 与已授权接口为准；源码/资源失败和数值负结果始终分开。

## 从论文观察设计对照

PTQ4ViT 作者在其 ViT 分类实验中发现，常用 MSE 和 cosine 可能选错尺度，并同时研究了 softmax/GELU 的表示和 Hessian-guided 评分。迁移到另一骨干时，这给出两个能独立检验的解释：有效码器集合没有覆盖好解，或者候选覆盖了好解但评分排错。在同一冻结父状态上复用已有候选响应，先检查不同评分是否真的选出不同重构值。若排序相同，增加相近评分函数难以区分解释；若排序反转，可比较冻结选择在独立 search 样本上的真实后缀响应。改变码本时还要重新核对位宽及实际码点。论文的分类结果不能替代当前两个任务的测量。[作者原文 §3](https://arxiv.org/abs/2111.12293v3)

PTQ4DINO 的参考投影与独立选择提供了另一个区分实验。如果参考答案能在候选族中重现，而从原始父状态出发的前向选择不能重现收益，优先检查选择依据；若连投影也失效，才有理由把注意力转向候选表示。两条分支都是可修订的解释，最终完整候选须交代父配置、独立生成规则和重新拟合的范围。[原研究记录与条件](../../../../knowledge/research-skills/research-routes/ptq4dino.md)
