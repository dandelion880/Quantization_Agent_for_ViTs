# 判别实验模式与控制变量

## 1. 单因素对照与必要的交互设计

先问最小对照能否回答争议，再决定是否扩成矩阵。单因素并非永远更科学：若机制本身声称两个因素交互，仅测一个因素可能回答错问题。

### 网格 × 校准输入

设网格为旧/新，拟合输入为 FP 前缀/真实 Q 前缀。四臂的含义是：

| | FP 前缀拟合 | Q 前缀拟合 |
|---|---|---|
| 旧网格 | 当前比较起点或其受控版本 | 只改变输入背景 |
| 新网格 | 只改变网格 | 同时改变网格和背景 |

统一数据、其他量化状态、选参预算和目标定义后，可观察网格效应是否依赖输入背景。若旧历史结果已覆盖一臂且身份完全可比，不为形式重算；若不可比，保留它为线索而非控制。

主张仅为“组合策略在当前协议更好”时，不必为了作机制归因强行测全部四臂。主张为“新网格消除了前缀失配”时，则需能区分这两项因素的证据。研究主张决定需要的对照强度。

### W/A 补偿与次序

固定完整量化起点，比“只调 A”“A 调整后重新处理 W”“只重新处理 W”等真正能区分解释的臂。区分有无权重补偿、是否只是更多搜索、次序是否改变了各臂所见输入。不要把同一任务执行中的多个臂称为独立重复。

### 两个机制的组合

组合前先说明 A 会改变 B 的哪个假设：分布、坐标、量化前缀、误差方向还是可执行性。若两者彼此无关，一次组合胜出并不能证明机制协同；若一个模块改变另一个模块的拟合数据，独立调优结果也不能简单相加。

## 2. 对照应该控制什么

按争议挑选，而非在每次请求里列全表。

| 维度 | 需要控制时的做法 | 常见错误 |
|---|---|---|
| 完整起点 | 明确父方案/冻结包及未改状态 | 比较两个有多处历史差异的方案，却只归因一个新模块 |
| 模型与任务 | 同 checkpoint、结构、头、预处理和所需输出 | 用不同 FP 路径制造“量化收益” |
| 数据 | 同配对样本、split 和输入变换；记录选择方式 | 用“都用了 32 张”替代同样本配对 |
| 校准背景 | 指明 FP/Q 输入、冻结前缀、FP/peer 目标 | 把条件不同的局部误差直接排名 |
| 搜索自由度 | 比较合理的实际候选与计算量 | 仅使用相同网格名称，就声称相同码器或预算 |
| 表示与执行 | 确认重参数化、码本、bias 和重载状态 | 只验证校准态，部署态函数已改变 |
| 观测单位 | 同样本和同输出坐标报告差异 | 把 patch/token 数当独立图像重复数 |

公平有不同问题：机制归因通常需要控制因素；“同总预算谁更好”允许各方案自行分配预算，但应把它声明为策略比较。不要为强行统一全部实现细节而改变原算法。

## 3. 独立验证与适应性选择

配对比较降低无关样本差异；独立样本验证检查超出拟合数据的表现。两者可同时存在。

- Calibration 用于内部量化拟合；search 用于当前研究中的方案选择；最终评价按 ResearchBrief。
- 若某次 holdout 结果影响了下一轮方案，该集合对后续研究已是开发证据。保留其原始角色与使用历史，不继续称后续结论为完全盲测。
- 搜索多个位点、metric 和网格后挑最优者，会放大选择偏差。优先看跨样本/独立条件是否保持方向，必要时用未参与挑选的测量确认。
- 对极小样本 Top-1，不把一张图的差异包装成稳健规律。也不为了避免离散性而事后只报告最有利连续指标。

统计不确定性不只来自随机种子：校准样本、评测图像、方法配置和 LLM 决策也有变异。只重复读取同一冻结包不产生独立算法重复；缓存命中更不产生新实证。

## 4. 便宜实验也可能无效

一个极小实验只有在干预和观测仍覆盖核心机制时才划算。以下情形应改变设计：

- Toy 输入没有真实 outlier 结构，却据此否定 outlier 方法。
- 只看量化器输入 MSE，却想判 attention 输出误差补偿。
- 干预没有改变实际硬重构输出或相关功能，或观测分辨率不足；此时平局尚未覆盖提出的机制。同一整数码索引在不同 scale 下仍可能重构为不同值。
- 改动影响重参数化后的多个分支，却只观察其中一个局部张量。
- 要验证跨任务保持性，却只看分类 logits。

原型可先验证“数学变化是否真的改变码器、实现是否命中目标、输出是否具有预测方向”，再决定需要怎样的真实模型实验。原型通过不等于真实任务收益；原型失败也需确认它确实代表主张的条件。

## 5. 来源与策略性质

本页的实验矩阵与控制建议是面向 QAViT 的研究设计综合，并非宣称下列论文执行过同一套矩阵。

- [PTQ4ViT 原文](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136720190.pdf)：特殊激活网格与尺度选择动机。
- [GPTAQ 原文入口](https://proceedings.mlr.press/v267/li25dn.html)：完整 FP 目标与真实量化输入的区分。
- [ERQ 原文入口](https://proceedings.mlr.press/v235/zhong24a.html)：W/A 相互作用与顺序补偿动机。
- QAViT 2026-11-16 源码 `agents/prompts/common.md`、`docs/EXPERIMENT_INPUTS.md`：局部实验、原执行链和证据层级的实际约定。

### 原图配对与最小分歧

当同一原图产生多个窗口、裁剪或 token 时，用原图身份配对父与子，先在图内按同一几何归约，再看逐图差值与方向。报告独立原图数、视图数、两臂缺失与配对规则。若估计区间，重采样整个原图及其两臂；共享父包和校准数据也限定外推范围。两种机制都预言某代理下降时，继续加密它的网格区分不了机制。可固定同一父状态及候选预算，只改变发生分歧的干预或观察终点，事先写出反向、并列和无分辨率时分别保留的解释。
