# 量化实验指标、参考与公平性

**按科学问题选择指标**，而不是为每次实验列出固定全套度量。

## 不同参考回答不同问题

| 参考对象 | 适合回答的问题 | 不能直接说明的事 |
| --- | --- | --- |
| 同部署量化 peer（相同真实量化前缀和其他量化边） | 针对某机制的边际改动是否改善当前量化系统？ | 与原 FP 差距是否已经弥合、最终任务是否改善 |
| 原 FP 张量/FP 模型 | 量化输出离原始函数多远？ | 某个候选的相对 peer 改善来自哪一项机制 |
| 同条件 W-only / A-only / joint | 敏感性、交互和失效范围 | 不同日期/协议下的通用因果结论 |
| 独立 holdout / 正式任务集 | 搜索外的误差、Top-1/mIoU 的泛化 | 未经度量的真实部署速度或整数 kernel 兼容性 |

## 指标和证据层级

- **极小单元/推导**：检查网格、编码、数学等价性，排除明显逻辑问题。
- **局部算子**：MSE/NMSE、码点占用、削顶比例、attention AV/PV SSE；更接近机制，但不证明全网。
- **传播和整网代理**：冻结前缀、后续 block 特征、logits 差异；连接局部误差与最终输出。
- **最终任务**：冻结协议下的分类 Top-1/Top-5 或分割 mIoU；是任务结果，不自动等于真实 INT4 速度。
- **资源与硬件**：校准时间、GPU/Token 成本、模型存储、真实 kernel 的延迟与内存；`profile_hardware` 如只测 FP 算子，不可冒充 INT4 加速。

## 公平性的判断

1. 保持比较对象的模型/任务/位宽/量化范围/数据清单/父候选身份可比，或明示不能控制的差异。
2. 区分用于调参的 calibration/search、选择后的 holdout、正式验证；重复使用某集合指导下一轮研究后，不应再称其为未曾见过的独立测试。
3. 实验目标是区分机制而不是仅证明方案更好；不能因性能难看就丢弃不利的测量。
4. 对 8、16、32 张等极小样本的分类或分割数字，不要声称统计稳健；必要时汇报样本波动或独立更多样本。

## 双参考简例

若局部方案相对量化 peer 的 AV SSE 降低 5%，相对原 FP 目标仅降低 1%，合理结论是“对当前量化 peer 的边际误差有改善，整体恢复程度仍有限”；不能写成“整网 W4A4 性能提升 5%”。
