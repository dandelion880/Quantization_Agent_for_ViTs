# 选择能指导校准决策的目标

目标的价值在于它能在实际可选方案中选出更有用的状态。不能只因某个 loss 更复杂、梯度更强或重建更深，就认为它更接近科研目标。依据当前问题选择适当目标；不要求每轮比较全部 metric，也不把目标验证变成进入 L3 的固定前置阶段。

## 先确定要排序的决策

确认正在选择的是单个 scale、一个共享倍率组、联合编码器、block 配置，还是整网候选；恢复真实输入前缀、冻结的 W/A 背景、观察位置和可接受的计算成本。若还不知道误差来自哪里，可用 `diagnose-ptq-failure`；若候选根本缺少有效自由度，应转向 `design-scale-calibration` 或方法设计，不能靠复杂 loss 凭空补足候选。

把一个目标理解为以下选择的组合，而不只是一个名称：

| 选择 | 必须能解释的具体问题 |
| --- | --- |
| 观察对象 | 输入编码、线性投影、attention 路由、残差单元、block 特征、多个 tap 或 logits？ |
| 参考与输入 | 比较 FP 输入上的 FP 输出、Q 输入上的条件 FP 输出，还是同 W 母模型？两路是否配对？ |
| 下游背景 | 观察前继续真实 A4、W4A32 还是全 FP？是否保留已校准前缀和实际非线性？ |
| 前瞻范围 | h 表示算子、残差单元还是 block？观察点位于哪一条分支之后？ |
| 误差形式 | MSE/NMSE、余弦、KL、敏感性加权、相对误差，或有明确依据的组合？ |
| 聚合方式 | token 类型、层、通道、样本和任务如何归一化与加权？权重来源是什么？ |

只展开会改变当前选择的维度。细节见 [目标设计与数值语义](references/objective-design.md)。

## 用失配类型缩小选择

- **量纲或 token 数量支配目标**：先检查按图像、token 类型或观察位置归一化。DINO 的 CLS、storage/register、patch 必须按真实布局识别；不能把首 token 以外全部视为 patch。
- **局部输入误差小、投影或路由误差大**：观察实际使用该输入的运算；必要时保留 Q/K 联合作用、固定 V 的路由输出或残差边界。其余部分固定，避免把候选族同时扩大。
- **前缀误差已累积**：区分局部注入误差和累计偏差。条件 FP 参考适合隔离局部问题；FP 完整轨迹参考适合追踪累计偏差，二者回答不同问题。
- **局部重建好、真实量化后缀差**：尝试适量真实量化 lookahead 或任务相关特征 tap，核实改善来自后缀精度还是前瞻长度。不默认更长更好。
- **梯度加权分数异常小或几乎相同**：核对微分目标、梯度位置、教师/学生初值和数值范围，尤其教师 KL 在两者完全相同时的一阶梯度。不能把无区分度解释成全部位点不敏感。
- **任务指标在少量样本上离散或不稳定**：用更细的表征/分布目标筛选，保留适量独立任务确认；不能把小样本 Top-1 平分当成候选等价。

若充分的直接任务证据已经回答了当前选择，可以采用该证据，无需另造代理指标。目标的选取也必须符合当前 Brief 允许的数据和计算方式；带标签 CE、只读反向和训练优化分别说明，不能混为一种能力。

## 检验“选得对”，而非“分数低”

有排序疑问时，优先在**同一候选池、同一背景、配对样本**上比较少量有针对性的目标。以有意义的后缀或任务测量作为诊断参照，检查选中候选的 regret、明显误选和在独立校准留出上的稳定性。参照本身也可能有噪声和偏置，不等于最终真值。

局部编码 NMSE 更低可能选中任务表现更差的尺度；更稠密候选也可能只扩大错误目标的择优偏差。见 [排序检验与成本控制](references/ranking-validation.md) 和 [PTQ4DINO 的完整实例](../../../knowledge/research-skills/research-routes/ptq4dino.md)。后者包含成功方向，也保留复杂指标失败与停止的实例。

当目标已经能区分当前决策，不必穷尽所有梯度、lookahead 或混合权重。若代理目标仍不能可靠区分，就如实保留不确定性，选择更直接且可负担的测量，或重新审视候选机制。

## 接续研究

在现有请求中说明实际采用的观察位置、参考状态、背景、聚合与选择规则，以及为什么这些足以支持当前决策。不要只写“用 Hessian”或“使用 block metric”。与 `design-scale-calibration` 配合时，本 Skill 决定评价什么，后者决定候选从哪里来、哪些参数一起选、按什么顺序更新。
