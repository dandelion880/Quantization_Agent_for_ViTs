# 在有限预算中验证目标的选择质量

## 固定候选池是一种隔离工具

当需要分清“候选不够好”还是“选择器选错”时，保持候选、当前前缀、后缀和数据用途可比。候选可以来自原搜索、已有方案或参考解投影；参考解候选只用于诊断，不代表最终算法可获得它们。

设 C 为当前有限候选集，m 是待检验代理，R 是较直接的后缀诊断损失。定义

\[
c_m=\arg\min_{c\in C}m(c),\qquad
r_m=R(c_m)-\min_{c\in C}R(c).
\]

这里 regret 只相对于该池、该参考损失和当前背景；不是相对于全球最优 PTQ 的差距。若 R 为准确率等越高越好指标，应反向定义差距。平分候选使用一致的既定选择规则，不能事后挑最优。

比较 regret 的均值、分布和严重误选，比只统计“选中多少次第一名”更能识别少数高代价错误。样本少或候选数大时，同时检查排序稳定性；当候选效果几乎一样，名次差异本身可能没有研究意义。

## 数据用途与自适应选择

可以把校准数据分成用于构造/筛选目标的一部分，以及未参与该轮选择的确认部分；样本不足时采用明确的交叉验证或敏感性分析。不要把长期反复查看的历史确认集再称为盲测。

对同一批图像使用配对比较。若需要不确定性，重采样单位通常是独立图像而非高度相关的 patch/window；分割任务对每次重采样重新汇总混淆计数。统计区间只反映所重采样来源的不确定性，不能修复测试集选参、协议差异或单一模型的外推问题。

不同候选造成当前前缀变化后，旧缓存和敏感性权重可能失效。局部排序验证应标注条件背景；进入实际顺序校准后，可在有证据显示排序漂移的边界重新检查，而不要求每次重测所有层。

## 一个来自 PTQ4DINO 的失败案例

2026-10-16 的候选与后缀研究中，用原/训练编码器构成固定候选池，在 24 个残差单元比较局部 NMSE、几种梯度加权、不同 A4/A32 lookahead 与完整后缀。真实 A4 后缀对若干错误排序有帮助；更复杂的“短真实后缀 + 远端 STE”组合并未可靠优于简单 A4 lookahead，因此没有继续堆系数。

另一个逐组候选实验中，前向局部编码 NMSE 从约 0.063 降到 0.035，甚至低于参考投影的约 0.056；同一历史 ADE512 任务结果却明显落后于该参考投影。该实验其他部分仍用了训练参考参数，不能算完整 training-free 成果。它证明需要检验局部选择的功能后果，没有证明所有 MSE 目标无效。完整条件和数值见 [真实研究路径](../../../../knowledge/research-skills/research-routes/ptq4dino.md)。

## 有价值的对照与停止

| 当前疑问 | 一种可选的判别性比较 | 结果如何改变决定 |
| --- | --- | --- |
| h 增大似乎有效，是深度还是 A4 背景？ | 固定 h 换后缀精度，再固定背景比较少量 h | 决定保留真实量化响应，还是需要更长传播范围 |
| 梯度目标几乎所有候选同分 | 检查梯度/分数分布，与一个前向目标比较 | 区分实现或退化问题与真实弱敏感性 |
| 更细候选训练集 loss 更低，任务更差 | 固定池与确认数据评价选择结果 | 决定修目标、减小搜索自由度，或补足数据 |
| 局部好解在后续校准后失效 | 在改变的真实前缀下重测少量原候选 | 决定是否刷新缓存、有限 revisit，或撤销当前排序假设 |

这些是研究选项，不能变成宿主触发器。若当前直接证据已经足够选择候选，可以停止代理比较；若负结果排除了改动价值，可以终止该方向。最终把目标、成立条件和未消除的歧义交给现有 Generation/Recorder，不自行写入长期 Skill。
