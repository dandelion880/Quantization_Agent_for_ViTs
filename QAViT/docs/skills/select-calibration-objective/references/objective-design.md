# 校准目标：观察什么，和谁比较，如何汇总

这是可选择的设计维度与常见反例，不是必须完成的实验清单。下文的公式是用于明确问题的通用写法；具体张量与算子以实际模型为准。

## 1. 先分清局部注入与累计偏差

设同一边界的 FP 输入为 x_F，当前量化前缀输入为 x_Q，FP 子模块为 F，候选量化子模块为 Q_θ。在坐标和尺度可配对时：

\[
e_{local}=Q_\theta(x_Q)-F(x_Q),\quad
e_{up}=F(x_Q)-F(x_F),\quad
e_{total}=e_{local}+e_{up}.
\]

因此

\[
\|e_{total}\|^2=\|e_{local}\|^2+\|e_{up}\|^2+2\langle e_{local},e_{up}\rangle.
\]

减小 local 不保证减小 total；误差方向可能相消或相长。选择 `F(x_Q)` 适合隔离当前模块的注入损失；选择 `F(x_F)` 会把累计偏差纳入优化目标。前者不能被宣传为自动修复前缀偏差，后者也可能在小数据上拟合上游偶然误差。检查这种差异是否会改变实际选择。

若 FP/Q 路径经过不同 reparameterization，先还原为相同物理量再做分解。不同量纲、不同 token 排列或不同残差位置上的 MSE 不满足上述对应关系。

## 2. 目标常见形式与适用问题

| 形式 | 可回答的问题 | 主要盲点与处理 |
| --- | --- | --- |
| MSE / Frobenius 误差 | 绝对重建误差是否小？ | 大幅值、大维度群体支配；先判断这种支配是否符合任务 |
| NMSE / 分组相对误差 | 不同位点/类型的相对保真是否均衡？ | 参考能量近零时不稳定；明确 epsilon、归一化先后与小能量组处理 |
| 余弦或方向误差 | 表征方向是否保持？ | 可忽略幅度和零向量异常；有必要时分别观察方向与幅度 |
| KL / 分布差异 | softmax 预测分布或注意力分布是否保持？ | 明确方向、温度、归一化轴；低概率与饱和区、有限样本影响排序 |
| 真实运算后误差 | 输入编码差异是否经 W 投影或 QK/AV 放大？ | 运算边界过短会漏掉后续重编码；过长增加成本与选择噪声 |
| 梯度平方等敏感性加权 | 不同误差方向对某个定义明确的目标是否重要？ | 代理 Hessian 不是完整 Hessian；梯度目标、位置、标签来源和近零退化需明确 |
| 多 tap / 多类型目标 | 分类与密集表征都需要哪些特征？ | 任意加权可能只适配当前验证集；先保留分项再决定组合 |

损失计算可以使用高精度累积防止溢出；这不等于把候选 forward 换成高精度。保持真实候选路径与诊断计算精度的区别。

## 3. Hessian、Fisher 与当前实现名称

常见形式 `sum(g_i² * e_i²)` 只是一种非负、对角化的敏感性代理。它是否可以近似某个二阶目标，取决于 g 对哪个标量求导、在哪个输出上取值、采用什么近似。不能因为函数名含 Hessian，就声称使用了完整 Hessian 或保留了误差方向之间的相互作用。

当前 QAViT 的 `hessian_diag_ce` 使用初始冻结模型分类 logits 的 CE 梯度平方，并在候选之间固定这些权重；它不同于原生位点激活上的梯度加权，也不同于 PTQ4ViT 的所有实现细节。把某个位点目标直接改名不能取得整网目标的语义。

若目标为 KL(p_teacher || p_student)，而初始两者完全相同，一阶 logits 梯度可为零。可以检查原始梯度范数、不同候选分数与数值误差，判断当前代理是否有信息。重新定义诊断目标、采用非零误差的实际量化状态或改用前向测量，都需要说明理由；不要凭空加噪声掩盖退化。

只读梯度诊断与 optimizer 更新是两种研究操作。使用前者不自动使最终方法成为训练方法，但“无需反向”的计算声明不能再用于依赖反向的校准。标签依赖也要单独披露。

## 4. Lookahead 是后缀计算语义

用 T 表示明确的后缀，目标可写成 `D(T_Q(Q_θ(x_Q)), target)`。其中：

- T_Q 是否包含后续 A4、W4、LayerNorm、softmax、残差和实际任务路径，应由计算图决定；不能只写“lookahead=2”。
- h 的单位、起点和终点应明确。同样 h=2 可以代表两个算子、两个残差单元或两个完整 block，成本与机制均不同。
- 目标参考可以是完整 FP 轨迹的同位置输出，也可以是 W4A32 母模型或条件参考。换目标、换后缀精度、换 h 是不同变量。
- 残差结构中要保留相应支路和 skip 输入；不能拿截断后的错误张量替代真实单元。
- 若多个 tap 位于范围内，可保存各 tap 的分项损失。只观察最后一个位置可能掩盖中间破坏或有利补偿。

可以先在相同短 h 下比较 A4 与 A32 背景，再在相同 A4 背景比较 h。只有当前歧义需要时才做这些对照。更远的后缀更贴近任务，也更贵、更易受有限校准样本与后续状态变化影响；无法保证单调改善。

## 5. Token、通道、层和样本的汇总

一种可解释的选择是先按每张图、每个 token 类型、每个 tap 计算归一化损失，再按任务相关权重汇总；另一种是保留真实 token 频率。二者都可以，区别在于是否有意控制 patch 数量优势。应说明采用哪一种，并检查关键分项没有被平均抵消。

DINO 的 storage/register 数量与位置来自模型实际定义；不同版本不一定相同。二维输入图像、attention 的 query/key 两个 token 轴与普通序列激活也不可共享一个盲目的 slice。图像 token 数随分辨率变化时，明确损失是否随 token 数放大。

CLS 对分类有直接意义，patch 对 dense task 常有直接意义，但不能据此永远忽略另一个类型；信息可能经注意力交换。用任务相关证据决定权重，而不是把历史倍率观察写成固定生物学式规则。

跨层 NMSE 应说明先按层归一化再平均，还是拼接张量后归一化。小样本分割的任务测量应汇总像素计数后重算 mIoU，不能把逐图 mIoU 简单均值冒充协议值。

## 6. 多目标与成本

只有在分项会导致不同校准选择时，才需要研究组合。可以采用固定有解释的权重、在候选前沿中选择、或先过滤明显破坏关键任务的候选再比较其他指标；不要为小样本最佳分数无限搜索组合系数。

计入目标的实际成本：候选数 × 样本/窗口数 × 后缀长度并不足以精确表示耗时，还包含缓存、重载、forward/backward 和共享计算。报告实测总时间或明确估算来源，不用少数数学乘法替代速度证据。

候选不变时换 metric 是排序问题；候选、分组和数据一起变动的完整方案可以研究，但结论应覆盖组合，不能归因给 metric 单项。真正的正式任务结果仍由原评测链产生。
