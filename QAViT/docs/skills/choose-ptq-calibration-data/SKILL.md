## 分离数据覆盖与恢复算法

**触发。** 真实校准数据不足/不可用，扩大样本、多视图或合成图带来变化，或源域构造后迁移任务下降。单纯按既定清单加载数据不需要本技能。

**前提与范围。** 明确数据许可、监督信息、任务模式和恢复器；data-free 的生成与下游恢复都必须符合 PTQ。方法本文只确认 A8 时，改为 A4 是新验证范围。

**步骤。**

1. 清点真实数据用途：独立图像、视图/窗口、反复呈现、生成、敏感度、选择和评价。校准“32 图”不覆盖另用的大规模重要度估计或搜索数据。
2. 固定恢复器与预算比较真实图、噪声、所选合成/覆盖策略；固定数据再比较恢复目标。不要同时更换生成器与量化学生流程后把收益全归数据。
3. 查看模型内部覆盖：量化范围、patch 关系、attention 及任务相关读出，而非只评图像外观。生成器需要类别头而当前只有 dense 读出时，修改目标要作为新变体。
4. 分别计算生成、教师 forward/backward、搜索和有限重构成本。样本更多、呈现更多和更复杂恢复属于不同投入。
5. 按问题选择源域迁移、联合校准或分任务包，明确其主张范围，再将冻结结果交独立确认。

**结果解释与下一步。** 更多同类图无益但结构覆盖有效，研究选择/生成目标；仅目标域数据有效，缩小单源迁移主张；合成图只有配套重构器下有效，检查交互；校准损失下降但确认变差，检查覆盖与过拟合。

**案例草案。** 以同一有限 block PTQ 恢复器比较 PSAQ 风格合成与 SARDFQ 合成来源，保存各自生成预算；再选择是否研究恢复器。若不是作者原配方，标为组件实验，不将它写成完整原法复现。

**复用边界。** 多窗口不算独立图；合成图片更新不等于网络 QAT；data-free 标签也不能为量化学生完整训练提供许可。DINO register 与 patch 的处理从实际布局确定。
