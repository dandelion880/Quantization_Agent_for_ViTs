# 将机制认识转为量化方案

形成一个具体候选：说明**改变哪个数学对象、为什么应改变关心的误差、如何保留完整推理方案、什么结果会使你放弃当前解释**。方案可以源于已测瓶颈，也可以源于明确标注的理论假设。

## 根据已有认识选择改良层次

| 目前认识 | 候选干预方向 | 优先排除的简单解释 |
|---|---|---|
| 网格对高密度/长尾/不对称区域分配失衡 | 有限码本、分段或非均匀映射 | 更充分的普通尺度拟合已能达到同样效果 |
| 共享表示使部分通道失去分辨率 | 尺度重参数化、等价坐标变化、分组 | 实际只是增加推理自由度或改变了源 FP 函数 |
| 局部重构良好，真实前缀下退化 | 输入/参考关系或误差传播补偿 | 比较使用了不同背景/样本，尚不能归因 |
| W/A 联合误差大于单独观察的直觉 | 联合目标、阶段补偿、舍入/拟合相互适配 | 额外校准预算或参数自由度解释全部收益 |
| 理论上存在新结构或误差约束 | 形式化新机制并构造最小可证伪原型 | 变换在量化后其实不改变码器、或仅换名称 |

定义候选读 [干预设计与完整方案](references/intervention-design.md)；借鉴已有原理读 [成熟方法的机制模式](references/mechanism-patterns.md)；开放创新与反证读 [创新和失败案例](references/innovation-and-failure-cases.md)。

## 把想法写到可执行的程度

1. **选择完整起点或明确完整化路径。** H1/H2 从来源清楚的完整方案出发并提出实质改良；可用当前 Top-3、archive、待测完整种子或其他明确来源，成熟度不限制搜索。B 独立保存，不占 H1。
2. **明确改动对象。** 写出真实张量边、轴/形状、参数含义、编码/解码或补偿算式，以及未改部分。避免只列多个方法名。
3. **解释作用机制。** 连接“干预→中间数值变化→所关心输出”。从理论提出时写清假设，不伪造支持性 profiling。
4. **检查与邻接操作的交互。** 重参数化是否跨残差/分支；补偿是否改变后续拟合输入；网格是否与零点、bias、有效码点和相邻求解器兼容。
5. **给出最简单可信对照。** 保留父方案；需要归因时考虑 scale-only、同预算网格或单模块干预。对照由科学问题选择，不要求每个候选完整消融。
6. **提出可证伪的预测。** 什么观测会否定声称的作用？若局部改善但任务无益，准备缩小哪部分主张？有必要时转判别性实验设计。

## 支持开放创新

H3 可以提出手册外的码本、目标、补偿或组合原理，也可跨轮沿同一灵感修复、调参、组合或简化；续做不要求重新发明机制。先把它与可见已知方法的机制差异说清，再决定最小验证；不要求证明世界首创，也不把“不在内置枚举中”视为科学否决。真正使用内置执行器时遵守其能力边界；需要新能力时经原 Coding 链提供一份实现。

优先采用能直接检验核心想法的实现。复杂程度、论文数量和代码量不是创新证据。数学上可逆或浮点等价，只证明相应浮点关系；它不自动保证量化等价，也不自动改善低比特误差。

## 将专门问题交给相应技能

- 只需决定误差在什么地方：用 [量化诊断](../diagnose-ptq-failure/SKILL.md)。
- 要选择用于候选排序的目标/参考/粒度：用 [校准目标选择](../select-calibration-objective/SKILL.md)。
- 目标明确后，安排尺度的搜索、层序、block 单元和重估：用 [尺度校准设计](../design-scale-calibration/SKILL.md)。
- 想借鉴完整人工或论文研究路线：按问题读取 [共享研究案例](../../../knowledge/research-skills/research-routes/INDEX.md)；本技能负责把认识转为当前干预。需要从一个较好数值参考的结构提炼独立规则时，再用 [参考解启发](../learn-from-reference-solution/SKILL.md)。
- 想区分新机制与竞争解释：用 [判别性实验设计](../design-discriminative-experiment/SKILL.md)。
- 候选已测，需判断范围、投入或晋升：用 [候选评价](../evaluate-ptq-candidate/SKILL.md)。

## 交付与停止

在现有 HypothesisCard 的机制、干预、实现与验证设计中自然表达以上内容；不增加必填模板。证据足以支持本次交付时可提交；同一机制下若数值比较可改变候选、实现或以合理成本改善方案，可继续迭代。核心假设被否定时可以缩小、换机制或暂停；如果缺口只在工程实现，则修实现而不伪装科学修订。

最终声明 static W4A4 时，按当前 ResearchBrief 满足核心 W/A 量化、码点和冻结约束及明确例外。局部旁路、高精度参考和诊断变体可以帮助研究，但不冒充完整合法方案；历史训练式或动态方案只迁移获授权的思想。
