# 面向机制的量化方案迁移和创新

**核心成果**：一个说明了“改动作用在何处、为何可能有效、何时失效”的方案候选；不把方法名称拼接视为创新。

## 选择研究路线

1. 先确定要改变的误差机制或理论缺口。来源可以是可信 profiling/Evidence、Memory 中带范围的失败经验，或第一性原理提出的新推断；未知与已验证必须分清。
2. 优先查已有 Top-3 完整方案库中的**可执行起点**，再按需查 `docs/methods/` 的相关组件、适用条件、数学定义和实现接口。若任务需要忠实论文复现，区分“单个组件”和“完整官方配方”。
3. 按机制选 [established-quantization-patterns.md](references/established-quantization-patterns.md) 中的可迁移策略：表示/校准目标失配、通道尺度与重参数化、真实量化前缀与非对称校准、W/A 耦合及阶段补偿、舍入与误差传播。它们是灵感路径，不是搜索空间的穷尽。
4. 用 [designing-a-remedy.md](references/designing-a-remedy.md) 表达候选：受影响的量化边和张量、参数与码点/scale 的变化、校准输入与目标、冻结时机、推理时留下的操作、成本与最可能反证。
5. 保留未改变的完整起点作为对照，考虑最简单的替代解释（如仅改变校准预算、scale、输入前缀或参数自由度）；必要时交由 `design-discriminative-experiment` 选择小实验，不要求提出 H 之前先全部测完。
6. 在当前 ResearchBrief 合同内构造完整候选。局部诊断可以使用旁路、高精度参考或暂时不合规变体，**但不能把它们包装成完整 static W4A4 研究结果**。

## 不限制开放创新

H1 可保持成熟完整起点；H2 可针对已测瓶颈做最小改进；H3 可以提出未在手册中的新理论或跨机制组合。不要用 Skill 审核槽位、要求新方法必须从论文继承，或强制 H3 完成某项 profile。新颖性、科学性和最后的验证仍以真实证据判断。

**典型情境**：LN 后的通道幅值差异被证明造成量化困难；先探索有利于校准的表示，再检查能否通过受条件约束的等价/近似变换回到可执行推理形式。不能直接假设所有模型分支均可重参数化。

**不触发**：量化精度低的原因尚未区分是评测错误、权重量化还是激活量化，当前首先需要诊断。

**退出**：已有机制明确的候选与可证伪预测，或有理由放弃该迁移路线。未经实验的收益只能描述为“预期”。
