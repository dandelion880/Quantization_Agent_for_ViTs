# 把科研假设变成可实施、可证伪的量化候选

本篇是在机制已有一定把握、或有明确理论创新假设时读取的**思考模板**；不要求科研者按表填报，也不新增 Coding 请求字段。

## 机制—作用点—方案闭环

面对一个候选方案，尽可能在自然语言里讲清：

1. **具体失败**：观察来自哪份 Evidence？是 calibration/search 上的局部现象，还是独立验证上的任务退化？机制是观测、强推断还是猜测？
2. **作用点**：真实张量边在哪里（如 LN→Linear、Softmax→AV、MLP 激活→fc2）、哪些 token/channel/层受影响？`query_structure` 或同类结构查询可确认候选作用域，不能仅凭语义标签猜测。
3. **改变什么**：量化网格、分组/通道尺度、截断范围、舍入方向、等价重参数化、校准前缀、重构目标、参数补偿，还是它们的交互？明确参数是校准结束后固定、还是推理时动态。
4. **为什么应有效**：给出至少一项有方向的预测，如 outlier 所致饱和率下降、量化后的 FP-reference 误差下降、冻结前缀偏差被减少、跨 block 传播更稳。
5. **可能反例**：收益只来自更多校准样本、更大搜索量、局部目标选择、数值精度例外，还是任务指标与局部目标不一致？
6. **验证层次**：最有信息量的一个小对照是什么？如果它支持机制，升级成完整 static W4A4 需要补上哪些权重和激活路径？

## 三种有用的方案颗粒度

### A. 最小定点修复

案例：归因于某 LN 后通道间尺度悬殊。

- 起点：从 Top-3 或既有可运行候选继承完整量化方案，保留未改部分。
- 改动：只对有证据的 LN 相关边更换校准表示或尺度规划。
- 核心对照：未改候选、仅扩大 shared-scale 搜索的候选、针对通道结构的候选；如果有重参数化，检验推理态函数/输出差异。
- 反证：变化一旦传播到真实量化前缀、完整 residual/Layerscale 结构即消失；说明作用范围被高估。

### B. 修正优化目标与参考

案例：单层 peer 重构很好，但后续输出随深度恶化。

- 起点：保持相同网格/参数自由度与校准数据。
- 改动：将输入换为冻结量化前缀，或将目标换为对应 FP 完整模型输出，分别比较；必要时做 2×2。
- 核心观测：相同冻结前缀下的目标误差、下游 logits 或已定义任务代理；**同 peer SSE 与同 FP SSE 分开报**。
- 反证：只改善拟合局部 FP 目标，却没有稳定改善下游独立样本，则不能声称解决累计误差。

### C. 对 W/A 耦合建模

案例：W4A32 与 W32A4 单独表现尚可，组合 W4A4 明显退化。

- 起点：保留真正 W4A4 运行的完整父候选。
- 改动：试探局部联合误差目标、阶段权重补偿或舍入次序；避免不自觉把 A4 旁路为 FP。
- 核心对照：同预算 W-only、A-only、joint 与最简单的仅 scale 变化；定性研究 W/A 的交互，不对 SSE 做缺乏数学支持的“贡献加法”。
- 反证：若 improvement 源自额外参数、层外泄漏或搜索集适配，回退到更简单机制。

## 合规与创新之间的正确关系

**局部机制实验与完整候选不是同一件事。** 为寻找原因可以临时用 W32A4、W4A32、混合精度、局部 FP reference 或旁路进行干预，但报告其真实属性。构造声明为 static W4A4 的完整方案时，必须满足任务合同中核心 backbone 权重/激活量化、各量化位置最多 16 码点及例外边界；计算图内部的 FP 算术是否可用按合同判断，不凭“有浮点”一句话否决。

开放创新可以比现有方法手册更宽，但不能把“有方向的猜想”写成“已经验证”。一项方案在 L0 阶段被推翻也是有效结果；科研者可以直接修订或放弃，无须依次走完四个 Skill。

## 和已有知识协作

- **方案库**回答：什么完整起点可复用、历史表现如何、此前改变了哪些量化位点。
- **方法手册**回答：某个方法的算子级定义和适用条件，是否有原始或忠实实现。
- **Memory**回答：类似问题曾在哪些模型、数据、位宽上成立/失败；条件不匹配时只能作为启发。
- **Toolbox**提供：结构确认、分布/敏感性、候选探测、局部干预和 Evidence 回读；这些工具提供观测，不替 Agent 替代科研判断。
