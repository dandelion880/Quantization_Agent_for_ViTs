# 开放创新与有效失败

以下案例为机制设计练习；除明确引用公开方法的背景外，不宣称已经在当前 QAViT 获得性能收益。其目的是帮助 H1/H2/H3 形成可执行、可反驳的干预。

## 案例一：浮点等价变换为何可能在量化后完全无效

考虑对线性输入和权重做相互补偿的尺度变换。浮点乘积可以不变，但若量化器尺度也按相同比例自动缩放，实际整数码与重构后的整体映射可能没有改变。一个漂亮的可逆公式不保证产生新的低比特自由度。

设计时先回答：哪些量固定，哪些尺度随变换重新拟合？什么实际码点或舍入决策会改变？单位参数能否精确退化到父方案？

最小原型可比较变换前后码索引、重构值和算子输出。若始终相同，应查明不变性，而非不断扩大搜索；若只在裁剪/分组等条件下改变，则把这些条件写进机制。下一步的真实模型实验应覆盖声称的条件。

## 案例二：P 的拟合更好，不代表 PV 更好

设 attention 输出为 \(PV\)。若量化误差为 \(\Delta P\)、\(\Delta V\)，则

\[
(P+\Delta P)(V+\Delta V)-PV
=\Delta P\,V+P\,\Delta V+\Delta P\,\Delta V.
\]

因此仅降低 \(\|\Delta P\|_F\) 不保证输出误差下降；方向、V 的结构及联合项都相关。这个直接代数关系可以启发新的输出补偿机制，但并不自动证明某个新方法更优。

若设计目标改变为 PV，先明确保持哪些张量/量化器不变，以及参考来自完整 FP 还是当前冻结 peer。若改动还改变了 softmax 归一化、有效码点或 V 参数，应按实际干预说明。选择何种重构目标与搜索过程分别交校准目标和尺度设计 Skill。

有用的反证包括：局部 P 更好却 PV 更差；PV 更好但末端表征更差；单位参数不能恢复父方案；所谓新参数没有改变真实码器。这些结果分别指向机制、传播或实现，不应合并为一个“失败”。

## 案例三：已知方法组合的收益不能全算作新机制

以完整方案为起点，增加通道表示改良和真实 Q 前缀校准。组合若更好，有几种解释：通道表示本身有效、输入背景本身有效、两者交互、或者更多拟合预算造成改善。

H1 可以从已有方法原理提出这种改良；H2 可以从当前瓶颈得到同样组合。两者的探索角度不同，并不要求使用不同算法名称。H3 若声称一种新的联合机制，则应定义其超出两项独立应用的关系，并选择能区分该关系的证据。

如果仅前缀校准就解释了收益，保留简单改良同样有价值。若组合导致一个方法的缓存统计失效，先修正表示一致性或更换科学方案；不能要求 Coding 暗中修改已经冻结的定义来制造通过。

## 案例四：理论提出的 H3 不需要先证明某层是瓶颈

研究者可以从“误差在任务敏感方向上更重要”提出有限码本设计，而不是先做全网逐层筛查。此时应明确：敏感方向的定义、估计方式、是否只读梯度、参数如何冻结、如何作用于真实量化边，以及低成本原型怎样反驳该想法。

如果理论先验预测一个方向，但现有证据无法定位适用范围，可以先进行局部原型或选择代表性位点。该选择是实验设计，不是为了满足 H3 先诊断门禁。若当前工具无法实现必要测量，交原 Coding 链定义最小能力，保留未完成状态。

## 案例五：历史路线有启发，合同却不同

用户过去 PTQ4DINO 研究包含过训练式调优、动态激活量化或更高精度诊断。这些路线可启发“怎样隔离自由度、怎样判断输入依赖、怎样解释任务差异”，但当前任务若为 training-free static W4A4，不能直接把历史实现作为最终合法候选。

可以迁移的例子：通过比较 scale-only 与更多自由度的方案判断独立贡献；检查某些 outlier 是跨图稳定还是样本依赖。不能静默迁移的例子：将每个新输入重估尺度的动态方案称为 static；将优化器更新叫作纯诊断；旁路部分核心量化边后仍报告完整 W4A4。

先保留研究思想，再设计满足当前合同的实现。若合同内确无合理转化，也可以停止这条路线，而不否定其在原条件下的研究价值。

## 如何留下有效结论

在现有研究卡与 Recorder 反馈中记录：哪个核心预测被支持/否定、依据什么条件、哪些解释仍未排除、下次最值得改变什么。代码未运行、资源中断和低样本同分分别记录。

不要求每次创新成功，不要求每次失败都形成泛化规律，也不在本轮新增自动 Skill 生成或写回流程。科学认识可以先留在现有 Memory，等待后续独立验证。
