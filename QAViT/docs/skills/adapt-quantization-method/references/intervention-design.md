# 干预设计与完整方案闭合

## 1. 先区分“改什么”与“怎么把它调好”

算法干预改变可表示的函数、量化码本/坐标、误差补偿关系或参数间依赖；校准策略决定在既定候选族里怎样拟合与选择。两者可以共同创新，但应分别说明贡献。

例如“把普通均匀网格改成有限非均匀网格”定义了一个干预；“用 KL 选择网格参数”定义了排序目标；“按 block 顺序分配搜索预算”定义了尺度校准过程。先把三者拆清，再决定需比较哪些因素。不要让一个方法名称掩盖三项同时变化。

## 2. 六个决定实现含义的要点

### 完整起点

明确父方案的模型、量化覆盖、已有算法和冻结状态。继承完整起点的含义是：未改部分具有可复用定义，并非只能使用 Top-3 或完全不许改变其组件。H1/H2 都要有实质改良；待测完整种子可作起点，但没有自动获得实测成绩。

### 数学对象

写出作用边和形状。例如对行向量输入 \(X\in\mathbb R^{n\times d}\)、线性层 \(Y=XW+b\)，若提出可逆对角变换 \(D\)，则

\[
XW=(XD^{-1})(DW).
\]

这只是在相应形状、非零对角与精确算术下的恒等式。量化后的两端误差可能此消彼长；相邻 LN、bias、残差支路是否允许吸收需要另行检查。不能把这个通用恒等式当作所有模型均能直接套用的重参数化方案。

### 码本与状态

有限码本需定义真实重构值及编码选择。计算 \(q=\operatorname{round}(x/s)\) 后再 clip 只是一个例子；新映射应说明饱和、零、负值和解码。明确额外掩码、分段标记和零例外是否扩大实际表示容量。最终规则以当前合同为准，不凭“4-bit”名字推断。

### 校准与推理的边界

说明哪些量只在校准时使用，哪些参数冻结后进入推理，哪些算子必须在推理保留。FP teacher、临时重构张量和辅助分解可以服务校准；它们不能隐蔽成为最终模型的额外高精度通路。training-free 允许范围按 ResearchBrief，不因需要梯度观测就误判为训练，也不把梯度更新伪装成只读诊断。

### 机制预测

预测应指向干预直接改变的量：例如共同尺度下常见值分辨率、PV 输出失真、真实量化前缀的条件误差，随后再连接任务表征。只有“最终准确率会上升”通常不足以区分作用机制。

### 简单替代与成本

考虑普通 scale 搜索、更合理输入背景、等参数自由度补偿是否已解释收益。新增校准时间、状态大小、推理算子与实现复杂度都需按实际影响比较。Fake-quant 或理论位宽不证明真实 INT4 加速。

## 3. 图结构与方法组合

组合前检查两项方法是否依赖不同表示。例如方法 A 修改了 LN 后尺度并吸收到 Linear 权重，方法 B 却仍使用修改前的缓存输入/协方差；这样组合并不等于“两篇方法同时生效”。

可能的应对是重建相关校准统计、改变次序、缩小作用边或选用能在同一表示上定义的替代方法。由研究者选择科学变更；Coding 可以完成有说明的适配，但不能静默替换已冻结的算法定义。

对残差/多分支变换，明确哪些分支共享该张量，是否均已补偿。对于近似变换，直接记录 FP 函数差异并纳入解释；不要把近似身份写成严格等价。

## 4. 三种足够具体的研究描述

**表示改良。** “以完整方案 S 为起点，只对已确认通道尺度失衡的 LN→Linear 边改变可吸收的静态坐标；保持其余量化边。假设收益来自小通道分辨率恢复，比较父方案与合理的共享尺度搜索，并检查部署态函数。”

**误差关系改良。** “保持码本族，改变本层输出所追参考，使当前 Q 前缀上的输出更贴近完整 FP 对应输出；检验是否改善下游，而不只改善局部自重构。”具体目标选择和拟合分配交相关 Skill。

**联合补偿。** “以实际 joint 误差为问题，设计针对 A 噪声的权重校正，再完成 W 量化；明确前后两步的参考、闭式/搜索过程与最终码本状态，比较相近预算的简单方案。”现有 ERQ 的某个步骤可以提供灵感，不自动证明新组合成立。

### 路线停滞时重新表述问题

把“怎样再提高分数”改写成能决定下一笔投入的问题，例如“收益来自数值表示，还是来自增加选择机会”。结构类比应对应源机制中的对象、关系和失效条件：若借用残差补偿，明确误差在哪一层被观测、何处允许注入、下游哪类输出应反向变化。可从固定预算的伪补偿或交换注入位置开始；若预测在对照中同样出现，回到问题表述并保留原方法谱系。H3 也可从数学构想直接给出这种预测。
