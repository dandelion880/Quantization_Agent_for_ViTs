# 构造有研究价值的参考解

## 不同参考的回答范围

| 参考类型 | 能提供的主要信息 | 不能直接说明什么 |
| --- | --- | --- |
| 同码本形式/容量与粒度的 scale-only STE | 只改 scale 是否存在明显较好可行解；参数结构 | 全局最优、所有自由度瓶颈、无需优化的算法能力 |
| scale+zero 或较多参数的联合参考 | 更宽参数族的可行空间、可能交互 | 独立 scale-only 训练能达到的程度 |
| 较密/高成本前向搜索 | 所定义候选族内的较好参考；廉价搜索漏选位置 | 候选族外的上界、成本可忽略 |
| FP bypass / off-grid 诊断 | 去除某类约束后可能恢复的功能 | 合法四位状态可以达到同样收益 |
| 历史人工完整方案 | 已有实际解决路线与边界 | 在当前协议、模型与数据上已复现 |

优先复用已有可信参考；只有当前问题需要新信息且权限/预算允许时才新建。高成本参考若没有明确的机制问题，容易成为“再训练一次”的循环。

## 一个可调整的 scale-only 研究设定

下面是可供设计的思路，不是必须运行的默认训练配方。

- 从可复现 Q0 开始，保留同一 FP 或 W4A32 母模型作目标，冻结权重、W 量化状态、bias/LN、head 等不在问题内的参数。
- 对已有合法 scale 使用保持正值的参数化，硬量化 forward 可用 STE 传梯度；明确范围、初始化与全零状态处理。实际 hard code 和导出重载的行为应与声称状态一致。
- 选择与研究问题相符的特征/任务目标。若无标签，明确教师、tap、token 类型归一化；不把无标签等同于无训练。
- 用训练来源内的留出观察是否取得稳定可行改进，参考快照选择规则不使用最终测试成绩。预算按能否获得可解释对照来定，无需固定步数。
- 记录实际更新的参数及其版本，保留优化前状态。若增加 zero 或其他参数，以明确的新分支研究，而不把其收益回填到 scale-only。

参考解的初值、目标、优化器、预算和随机性都可能塑造其模式。简单重复一次可判断稳定性时才重复；若核心未知已转移到候选排序，不应继续优化以追求更好数字。

## 从训练数值到有效证据

训练 loss 下降可能来自软近似、局部目标或额外自由度。应根据声明范围确认：硬状态是否可重载、权重/head 是否仍冻结、同一实际 forward 是否改善、数据用途是否一致。已有可靠回执可以复用，不必逐项重复完整审计。

若参考优化未改善，不应立即宣布码本无解。可能是目标不合适、梯度退化、初值、参数化或预算限制；选择最有判别力的解释继续，或保留“当前参考未找到改进”并停止。若明显改善，也不能宣布原 PTQ 唯一问题就是 scale 搜索。

## 参数交换的解释

将联合参考的 scale 放入 Q0、zero 保持 Q0，与把参考 zero 放入 Q0、scale 保持 Q0，是**同一联合解的组件交换**。它们有助于研究该解依赖哪些组件，不能视为独立训练各分支的最优结果。

同理，“仅 patch 参数的收益 / 全部参数的收益”是某个条件下的增益比例，不是可相加的因果贡献。不同组件共同影响下游输入、离散阈值和误差抵消；如需声称协同，使用与该主张匹配的交互对照和不确定性，不靠两个正增益直观相加。

## 当前协议中的研究优化权限

外层研究可以明确允许少量优化来发现规律，同时要求最终量化算法无需优化；两者在科研上并不矛盾，但必须在既有 Brief/实验语义中说清楚。QAViT 现有字段及全程禁训的兼容语义见 [源码兼容说明](../../../SCIENTIFIC_SKILLS_COMPATIBILITY.md)；该区分不改变已有冻结 Brief。

本 Skill 不授予额外权限，也不设新的批准节点。合同已经允许时就继续；合同明确禁止时使用历史或前向参考。不能用“诊断”名称隐藏实际 optimizer 更新，不能把研究参考 checkpoint 作为正式候选默认输入。
