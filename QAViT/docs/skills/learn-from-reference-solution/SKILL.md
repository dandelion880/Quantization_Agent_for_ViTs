# 从参考解发现可独立实现的 PTQ 规则

有时先找到一个明显更好的可行解，再问它与原解有什么结构差异，比继续盲搜更有信息。参考解可以来自历史人工研究、轻量优化、较高预算搜索或明确的构造；只在它能回答当前关键未知时使用。没有必要为每个研究方向先训练 oracle。

这里的“学习”指量化研究的机制发现，不表示本轮自动创建、改写或发布 Skill。

## 明确参考能回答什么

先说清待回答的问题：当前码本/粒度是否容纳好解、哪些自由度重要、参数模式是否稳定、原候选是否覆盖、原指标是否能选中，或高成本过程是否可被廉价规则替代。随后选择能区分这些问题的参考，而不是默认更强、更久的优化更好。

已有参考快照时，先用同一冻结父状态上的投影、交换或原参数回退区分表达和选择，通常比另训一个参考成本低。若压缩后的规则仍需读取逐层参考答案，下一实验应从参考前状态只用允许的统计重建，再比较相同样本上的行为。

若想研究 activation scale，在副本中冻结权重及其量化状态、非量化模块和任务 head，保持同一码本形式、码点容量和量化粒度；实际重构值可随允许更新的 scale/zero 改变。scale-only 与 scale+zero 是不同实验；增加 zero、bias 或权重更新时明确记录其自由度，不能借同一名称合并结论。训练 forward、导出 hard forward 与最终协议也要区分。

当前 Brief 明确允许研究参考优化时，可沿既有实验请求与执行链运行适量 STE，不另设角色或反复请求许可。若当前冻结合同禁止整个研究过程中的任何参数优化，就使用已有参考材料或许可的前向参考，并如实说明限制；不能静默把禁止条件改写为允许。参考优化始终不自动取得进入最终 training-free 方法的资格。细节见 [参考构造与证据边界](references/reference-construction.md)。

## 从观察走向可检验的结构

依次考虑下列问题中当前有用的部分，允许从任一已有证据开始：

- **参数与表示**：比较相对原始状态的倍率、范围、zero、硬 code；按实际 token 类型、运算位置、层和既有量化组观察。绝对 scale 差可能只是输入幅度差，需与相对变化及功能响应合看。
- **功能贡献**：通过必要的参数交换、压缩、投影或撤回对照，区分“常见模式”和“该模式确实承载收益”。临时交换是诊断，不等同分别重训后的能力比较。
- **表达与选择**：用更简单的候选族投影参考解，判断搜索自由度是否值得保留；再用不读取参考标签的选择器判断能否自行找到有效状态。两者不要合并为一个成功结论。
- **可独立构造的规则**：把观察转换为由模型结构、前向统计、候选响应或许可的解析量生成的规则；解释在新实例上如何产生参数与分组。
- **可迁移性**：寻找模式失效的模型、位点或数据条件。先选择会改变结论的最小迁移检查，是否开展完整任务确认交由现有研究流程决定。

“patch 常有更小相对步长”可以启发分组候选；不能直接成为所有 ViT 的固定倍率。参考解更好支持存在改进空间，不证明优化器找到全局最优，也不能自动定位是哪一类误差造成了原失败。

## 从参考提案到正式方法

参考阶段可以有意使用学得参数或成员关系来观察机制，但这样的实验须称为 oracle-assisted 诊断。最终声称独立 training-free 的方法应从**参考优化之前的基础状态**重新构造：不读取学得的 scale、zero、逐实例分组、候选标签或隐含学习产物，按声明的规则和许可 calibration 数据生成自己的状态。

研究者可以根据参考发现设计新规则，并披露启发来源；这不同于每个待量化模型都依赖训练参考来提供答案。若最终仍需参考优化、任务标签或反向计算，应准确描述算法成本与类别，而不是隐藏依赖。详见 [从模式到独立算法](references/pattern-to-method.md)。

已有完整路线见 [PTQ4DINO 真实研究案例](../../../knowledge/research-skills/research-routes/ptq4dino.md)：从 scale-only 的研究动机，到后续 scale+zero 参考分析、候选覆盖与排序反例，再到前向分组和粗细校准。原始文档中的不同日期、子集和自由度分别保留，不拼成一张虚假的连续收益表。

## 接续到其他技能

识别待解释结构之后，机制设计交给 `adapt-quantization-method`，独立候选/分组规则交给 `design-scale-calibration`，目标的辨别力交给 `select-calibration-objective`，必要反证由 `design-discriminative-experiment` 设计，当前证据的采用范围由 `evaluate-ptq-candidate` 判断。可直接复用已有信息，无需把同一结论按七个模板重写。

输出当前最可信的结构、仍存竞争解释、可独立执行的方法设想，以及能够改变采用决定的下一步即可。保留来源与未验证状态；本技能既不自动启动长期训练，也不生成长期 Skill。

## 从较好解发现可执行规则

**触发。** 想知道现有表示是否容纳好解，哪些自由度承载收益，或高预算 PTQ 能否提炼为更廉价规则。例行复现和普通 scale 拟合无需先构造参考。

**前提与范围。** 参考来自已核定 PTQ、允许的有限校准优化、解析/高预算搜索或已有人工合法方案；QAT 不作为本技能的参考来源。参考具有可追溯的初态、更新对象和数据，不能称全局最优。

**步骤。**

1. 确定参考回答的具体问题：表达空间、候选覆盖、参数模式、选择能力还是组合效应。已有参考足够时直接使用，不默认重新优化。
2. 对照原状态观察相对尺度、zero、硬码字、分组和功能响应。绝对 scale 差可能仅反映输入幅值，统计模式需与输出作用联系。
3. 需要时用交换、投影、共享/拆组或撤回对照辨认哪项结构承载收益。按参考答案投影属于 reference-assisted 诊断，不证明独立选择器能找到它。
4. 形成可执行规则，写清在新模型/样本上如何从许可统计生成参数和组。若主张不依赖参考优化，就从参考前状态重建，不能读取其逐实例答案。
5. 如果最终算法本来保留有限校准优化，则如实作为 PTQ 配方报告其数据、目标和成本，不强迫丢弃合法优化结果，也不冒称无优化。

**结果解释与下一步。** 小候选族已能容纳好解却不能自主选中，转目标选择；低维投影保留收益，研究共享/简化；模式随模型变化，保留条件规则；重新构造失败，回到规则依赖而非把 reference-assisted 数字当成功。

**案例与边界。** 既有 PTQ4DINO 人工路线中，“参考状态→候选覆盖→选择反例→独立前向分组”是可复用思路；不同日期、自由度和数据子集不能拼成当前 QAViT 的连续成功曲线。本次只读应用内案例，未重读其全部外部原件或重新运行。具体历史阶段能否作为新实验起点，应按当前 PTQ 协议与实际来源核定，不能凭标题中的 STE 一概许可或一概否决。

**复用边界。** 不从成功快照复制逐模型参数后声称发现通用规则；不把参考更好当作原方案根因已确定；“学习参考”是科研活动，不自动创建新 Skill。
