# 根据证据价值选择下一项科研行动

不设置“误差降低 x% 必须进入 L3”的统一阈值。选择动作时对照：原假设的可证伪预测、当前 Evidence 的可比性、剩余不确定性、下一项实验成本、它是否会改变研究方向。

| 当前局面 | 较合理的下一步 | 什么情况反过来不值得做 |
| --- | --- | --- |
| 某机制的核心预测已被可信 L0/L1 明确反驳 | 更新或放弃机制，记下边界条件 | 不需要为“完整流程”再把同一候选校准多次 |
| 两个机制同时能解释数据 | 用 `design-discriminative-experiment` 选最短、能区分它们的一项干预 | 如果结论无论哪种解释都不变，可能不用区分 |
| 局部改善但尚无下游证据 | 选冻结前缀、后续特征/logits 或小规模独立 holdout 观测 | 若收益极小且成本极高、机制重要性低，可暂停 |
| 下游与局部同时改善，完整量化身份清楚 | 考虑独立 L3 正式评测 | 若评测协议/实现不合格，先解决合规性或身份问题，但不新建 Skill 门禁 |
| calibration 很好但 holdout 不稳 | 排查搜索过拟合与样本选择，降低无意义调参 | 不要直接把更多 calibration 迭代视为解决泛化 |
| 方案完整但成本激增 | 在相同质量参考下比较真实成本，简化或回退 | 不凭 FLOPs 或 fake-quant 的理论值声称部署收益 |
| 与成熟基线质量相当，新增机制不清楚 | 回到最简单起点，验证是否真正提供独立贡献 | 不必为“新颖性”保留复杂无效组件 |
| 真正实现/硬件不支持某方案 | 描述未验证或工程限制，选择可运行替代 | 不要将工程失败当成科学反证 |

## 信息价值的简明准则

优先实验并非“最容易得到正结果”，而是：

> 若结果为正，我是否会采用或继续这个方向？若结果为负，我是否会停止或修改它？若两种结果都不影响选择，那么本实验的信息价值很低。

在固定预算下，选择预计最可能改变决策、成本可承担、可复用证据最多的实验。即使已准备了 L1，如果一个完整独立评测是唯一未决信息，也可以直接做 L3；不强制按层级推进。

## 面向 Memory / Recorder 的可迁移经验

科学判断可自然语言交给已有 Recorder，不新增强制表单：

- “在模型/任务/位宽/算子/数据条件 X 下，观测 Y 支持/反对机制 Z。”
- “最强证据为本次原始实验 E（包括校准与独立样本身份），尚未验证边界 B。”
- “下一次相似情境优先做实验 T，原因是它能区分 A 与 B。”

失败也可以形成有用的**负知识**：一个假设为何被推翻，它是否只在某量化器/位宽/模型下失败，以及哪些改动已试且未奏效。未经归因的日志噪声不应被固化为一般规律。若没有新增可迁移知识，保持现有记忆不变即可。

## 停止是合法而常常重要的科研决策

当主要问题已回答、反例足以否定方向、预算不足以做有区分力的下一步，或者边际信息价值已经很低时，可以选择停止。停止应说明科学理由或现实约束，而非为了满足固定轮次数制造实验；预算中断只是未完成，不能冒充负结果。
