# 判断量化结果的可信范围与下一步投入

**核心成果**：区分“已经证明了什么”和“尚未证明什么”，然后作出与预算及科研价值相称的下一步决定。

## 解释证据

1. 恢复原研究问题、候选与基线的身份、原本预测，以及 Evidence 对应的模型/任务/位宽/量化位点/数据划分/量化前缀。重要数字回到原始测量核实；Recorder 的总结不是原始测量本身。
2. 用 [evidence-scope.md](references/evidence-scope.md) 判断证据层级与迁移边界：符号/极小单元、局部真实 L1、冻结前缀或下游输出、整网中间/logits、独立分类/分割任务、真实部署成本。不同层不能用一个“提升百分比”混为一谈。
3. 保留指标参考：相对同部署 peer 的局部改善，不等于相对 FP 目标的恢复；calibration/search 的优势不等于未参与选择的独立验证；FP 算子 profiling 不代表 INT4 推理加速。局部旁路仅支持定位，不证明完整量化合规。
4. 选 [next-step-decisions.md](references/next-step-decisions.md) 中的下一项科研决策：继续机制、补一个能够改变判断的实验、检查传播、转入完整 L3、回到成熟基线、暂缓。考虑当前成本/信息收益，不按固定阈值自动晋升或否决。
5. 如果结果为负、混杂未解、工程未运行或预算中断，分别记录，不虚构科学成败。若已明显完成研究目标，允许直接停止局部探索。

## 与 Memory / Recorder 的关系

研究者做决策，现有 Recorder 负责汇总和记忆发布；本 Skill 不新增记忆层、route_trace 必填表、额外归档审批或重复总结角色。只把有来源、适用条件和反证边界的可迁移经验送回现有机制。

**典型情境**：固定量化前缀下相对 peer 的 AV SSE 改善约 5%，但相对 FP 目标仅约 1%。这是有条件的局部证据，不是完整 DeiT-B static W4A4 Top-1 胜利。下一步先识别下游传播和独立验证缺口。

**不触发**：完整合规候选已按冻结协议完成正式 L3，目前只需要 Recorder 常规存档。

**退出**：研究者能够清楚说明证据最强的支持范围、主要未解疑点和下一项值得投入的动作。没有可靠新经验时可以不发布新知识。
