## 候选空间与合法量化状态

先使用实际量化器定义。以 s>0、整数 zero-point z、整数码边界 q_min/q_max 的常见 affine 形式为例：

\[
q(x;s,z)=s[\mathrm{clip}(\mathrm{round}(x/s)+z,q_{min},q_{max})-z].
\]

四位码本至多有 16 个可取 code，不等于所有可能浮点输入都应命中 16 个值。round tie、截断、符号和 log 的零点处理必须与真实实现一致。使用实数 offset 或其他 zero 参数化时，按其实际编码/解码定义核对有限码点，不能直接把上式的整数 z 换成实数并假设仍是同一四位表示。

在上述整数 z 的形式中，z 调整边界与正负码位分配，不改变内部步长 s。若负值仍落在归零区间，增加负码本范围并不保证该样本恢复为非零。均匀量化的 scale 与 P-log 的 top/base 参数也不是同一个数值对象。

候选只在完整状态等价时去重：code 与解码参数共同决定重构值，相同整数 code、不同 scale/zero 仍可能是不同候选。例如 x=1 时，s=0.9 和 s=1 都可能得到 code=1，重构值却不同。可合并完全相同的参数配置，或在当前测量范围内已确认重构与后续功能完全相同的状态；不能只比较一个小 batch 就宣布所有候选永远等价。

`s = α s0` 方便比较跨组相对变化，但 s0 必须确定。对 s0=0 的合法特殊状态，乘法无法开启非零范围；可以从实际数据的正支持构造少量非零候选，或采用独立参数化。下界 epsilon 应来自数值稳定与码器定义，不能偷偷扩大部署码点数。

## 共享倍率、共享参数和分组

三个例子应分别表述：

1. `s1=αs1,0; s2=αs2,0`：共享倍率，最终绝对 scale 通常不同。
2. `s1=s2=s`：共享绝对参数，改变或限制最终量化粒度。
3. 独立 `(s1,s2)` 作为联合候选评分：联合搜索，未必共享任何值。

token 类型分组也不等于逐 token 动态校准。静态分组可以由类型、通道索引或模型结构确定，并在 calibration 后冻结；随当前样本数值重算 scale/成员的方案属于不同推理协议。若允许变化的只是校准共享组，应保持最终码器和推理路径一致。

可考虑的分组依据包括：结构角色、已有通道粒度、前向候选响应、候选选择的一致性、相邻运算的功能耦合。每种依据都有潜在偏差：结构可能过粗，响应可能受样本噪声影响，联合组可能组合爆炸。选择能解释当前证据的最小复杂度，不将 token→层→block 写成固定层级。

同一层存在多个 scale 时，“按最优粗倍率聚类”提供一种轻量前向规则。应保留 token 类型的语义边界或说明跨类型合组的理由；最佳粗倍率相同也不保证细搜目标一致。可以用留出响应或组内异质性判断是否需要拆分，不必引入训练聚类器。

## 候选从哪里来

| 来源 | 适合的证据 | 需要保留的限制 |
| --- | --- | --- |
| 相对初值网格 | 现有范围附近存在可改善状态 | 共享范围/自由度可能先于网格密度成为瓶颈 |
| 分位数、分布拐点、范围统计 | 尾部与主体分辨率存在可解释取舍 | 分布覆盖不是功能重要性的证明 |
| 粗搜后的局部插值/几何细化 | 当前最佳区域有稳定前向响应 | 离散码器目标不保证光滑或单峰；保留原候选 |
| 码格事件 | 少数舍入/饱和变化主导目标 | 完整事件枚举可能很贵；跨层目标不能当线性局部求解 |
| 解析固定码子问题 | 当前部分在固定 code 下可写成小规模最小二乘 | 解须留在该固定码区间；越界后需重算，不能声称全局最优 |
| 文献编码或已有方法 | 失效机理与方法假设匹配 | 编码变化需重新核对 W/A、粒度、运行开销 |
| 参考解投影 | 想诊断当前候选是否能表达一个有用状态 | 参考参数不属于最终独立搜索器可见信息 |

均匀四舍五入的单点阈值可由 `x/s=k+1/2` 分析，结合合法 s 范围与饱和端点生成候选。只有某些符号和 k 使解落在正值域；还需处理零值与具体 tie 规则。固定 code 下的线性重建可以导出解析 scale，但真实 attention/MLP、后续重新量化和残差一般不满足该全局假设。

## 参考解投影与前向分组

给定训练参考 θ*，求离它最近的候选，测试的是“这个候选族是否容纳某种有效状态”。只比较参数距离还不够，应检验投影后的真实编码/功能。投影性能差也不能严格证明该族没有其他更优状态，因为投影目标不等于任务目标。

使用 θ* 的倍率、逐层阈值、成员关系或最佳候选标签，即使推理时没有训练，也仍含实例级 oracle 信息。可以作为诊断对照；最终可称独立 training-free 的规则需要在初始模型与许可 calibration 数据上自行生成这些量。

一个实用转换是：先从 oracle 中提出“响应同类的 scale 可以共同校准”的结构假设，再由少量前向候选响应生成成员，最后比较该规则与 oracle 成员、简单结构分组和原共享方案。根据当前问题选其中必要对照，不能把三个都设为固定入口门槛。

## 联合自由度与表示缺口

已有候选分别覆盖好的 scale 与好的 zero，不代表它们的配对集合能覆盖有效组合。同样，Q 与 K 独立最优不保证 QK 路由最优；fc1/fc2 单独改动的排序也可能与联合状态不同。

可使用有限联合提案、条件坐标更新、基于残差的修正或成组候选来检验耦合。以同等搜索机会比较，区分联合机制收益和候选数增加的收益。若当前证据不支持强交互，保留简单独立策略可能更合算。

若合法码本无论如何调参都难以覆盖目标功能，考虑改变编码/变换或重建方式；这属于机制层面的新方案。不可把 off-grid rounding bypass 或 FP 替换状态当作可安装的四位候选，也不能把其收益当成四位算法必达上限。

## 一个可变形的两阶段设计

以下改写自 PTQ4DINO 的真实路线，只说明算法结构，不给出跨任务推荐超参数：

- 在当前真实前缀下，为每个已有 scale 试少量倍率；保留每个倍率的响应，而非只保留一个 winner。
- 在 token 类型与所选搜索单元内，根据前向响应/粗搜偏好构成共享倍率组。
- 对组的最佳区域生成少量细候选；必要时加有限联合提案，并用已选定的目标评分。
- 安装明确选中的合法参数，更新受影响的后续状态；根据一次有意义的改善/成本比较决定是否继续。

可从任一步直接进入：已有稳定组时无需重分，候选覆盖充分时无需加密，整体方案已清楚时无需先跑参考训练。历史五点网格与某个 h 的成功只说明那次条件，不应变成新 Skill 的固定常数。
