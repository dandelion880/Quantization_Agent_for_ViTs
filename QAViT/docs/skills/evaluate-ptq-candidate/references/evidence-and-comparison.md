# 证据范围、指标分母与可比性

按当前争议读取相关部分。这里的证据类型用于限定结论，不构成必须逐级通过的验证流程，也不复用项目 Eval-L0/L1/L2/L3 的命名来指代合成实验。

## 证据能支持什么

| 观察 | 最强直接支持 | 尚需其他证据的主张 |
| --- | --- | --- |
| 公式、单元测试、合成张量或随机 Tiny Transformer | 指定条件下的代数关系、执行可达性、机制反例、数值一致性 | 真实预训练模型收益、真实任务准确率 |
| 实际激活统计 | 指定位点、样本与 token 集上的分布事实 | 该异常是任务损失主因 |
| 局部量化/冻结干预 | 指定背景与参考下的局部变化及其下游影响 | 该干预能被合规低比特方法实现、全模型必然变好 |
| 整网特征/logits 代理 | 指定样本上候选与参考的表征或输出差异 | 完整任务精度、迁移泛化、真实 kernel 加速 |
| 完整双任务评测 | 该冻结方案在当前评测协议上的成绩 | 机制因果归因、跨模型规律、未见数据泛化 |
| 实际低比特部署测量 | 指定设备、kernel、框架和批量的性能 | 其他实现或设备的相同性能 |

## 对齐比较对象

先核对会影响结论的条件，缺失项按缺失保留：

- 模型权重/代码版本、量化参数包、完整基础方案及本次改动；量化名相同不保证实际码本相同。
- 校准、候选选择与评价数据的实际 ID、分辨率、预处理和样本数；共同 seed 不保证实际样本一致。
- W/A 位宽与粒度、浮点例外、前缀状态、校准顺序、重估、参考模型、任务 head 是否相同。
- 比较对象是原 FP、当前 B、其他 Q peer、局部 FP block 还是 oracle；同一“误差降低”必须指向同一参考。
- 该结果是新执行、缓存、历史来源还是同一执行的另一个汇总；缓存和确定性重放用于复现核验，不能自动计为独立证据。

保持“受控的同期比较”“相邻完整方案的真实进展”“异条件的启发”三种表达。无需为了列全条件重新跑实验；只有缺失项会改变判断时才补查或补测。

## 写清分母和单位

对于相同参考张量 \(y\)、候选 \(\hat y\) 和明确选取的元素集合 \(S\)：

\[
\mathrm{SSE}=\sum_{j\in S}(\hat y_j-y_j)^2,\qquad
\mathrm{MSE}=\mathrm{SSE}/|S|.
\]

归一化误差没有唯一默认定义。若使用 \(\mathrm{NMSE}=\sum_S(\hat y-y)^2/(\sum_S y^2+\epsilon)\)，保留参考、\(S\)、\(\epsilon\) 与汇总方式；若工具使用其他定义，沿用并明确其定义，不重命名为上述公式。逐图 NMSE 后平均，与先把所有图 SSE/能量相加再取比值会给予不同权重；不同 token 数、能量或分辨率时尤其如此。

误差相对降低写为 \((E_{base}-E_{cand})/E_{base}\)，并同时给出两个原值。分母为零时不要输出相对百分比；分母接近零时以绝对变化和实际数值精度解释。准确率由百分数 79.10 变为 79.30 是 **+0.20 个百分点**，不是提高 0.20% 的相对比例。需要相对变化时另外计算，并说明参照。

完整任务结果保留 FP、B、候选及适用的差值：候选相对 B 的增量回答改良效果，候选相对 FP 的差距回答恢复程度。两者不可互换。分类与分割分别报告；mIoU 按既定全数据混淆矩阵/类别汇总定义计算，不用每图 IoU 的均值替代。

## token、通道与误差传播

同时保留对研究问题有用的总体和分组结果；不要仅选有利分组。CLS、patch、register/storage 的位置从真实模型布局确认，DINO 的特殊 token 不能自动并入 patch。权重按元素数、token 数、图像数还是任务重要性聚合，需要明确；换聚合规则就是换问题。

配对 FP/Q block 分解中：

\[
e_{local}=Q_b(x_Q)-F_b(x_Q),\quad
e_{up}=F_b(x_Q)-F_b(x_{FP}),\quad
\|e_{total}\|^2=\|e_{local}\|^2+\|e_{up}\|^2+2\langle e_{local},e_{up}\rangle.
\]

保留交叉项符号。局部误差下降可能破坏原先的抵消，从而使总误差上升。只有边界坐标与张量语义对齐，分解才有对应的解释。重参数化前后坐标不一致时，先恢复同一输出空间再比较。FP block 替换或 W/A 旁路只说明当前背景下的诊断敏感性，不能当作合法 W4A4 可达到的收益下界、上界或正式性能。

## 小样本、平分与重复

单次小样本结果可以指导预算分配，但与总体规律分开。Top-1 error 在 \(n\) 个样本上的最小跳变是 \(1/n\)；多臂平分时检查连续输出差异、预测是否相同、并列选择规则和样本覆盖。合成标签或 FP argmax 标签只能用于相应的机制/接口试验，不能当作真实任务标签准确率。

需要评估稳健性时，优先保持配对样本和相同模型背景，并选择与主张相符的重复单位：校准样本重采样、独立研究运行或另一模型/数据条件分别回答不同问题。同一图像的多个 token 高度相关，不能当作许多独立样本夸大置信度。预算允许且差异决定结论时，可使用按图像配对的重采样；mIoU 重采样须重汇总混淆矩阵。没有重复或区间也可以报告单次观察，不臆造显著性。

## 避免事后择优

保留候选尝试范围、选择规则和主要不利结果。为一个候选搜索更多尺度、数据或目标后再与未经同等调整的基线比较时，说明搜索投入差异；研究效率评价同时计入这些成本。若对照意在比较算法本身，尽量匹配相关搜索预算；若比较自动科研系统整体，则将搜索策略作为系统的一部分并报告其实际消耗。

指标冲突要形成解释或下一动作，而不是删去不利指标。可以修订机制，也可以在当前数据只能支持较弱结论时停止；无需为了让所有指标一致而无限实验。
