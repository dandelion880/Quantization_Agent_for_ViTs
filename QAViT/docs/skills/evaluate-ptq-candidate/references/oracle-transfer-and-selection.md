# 从探索 oracle 到正式 training-free 候选

## 先区分三类产物

| 产物 | 目的 | 可支持的结论 |
| --- | --- | --- |
| 探索 oracle：例如只优化 scale 的轻量 STE 试验 | 测量当前目标与参数族下的经验可达改善，观察哪些尺度自由度重要 | 指定优化器、初值、预算、数据、背景下的探索结果 |
| training-free 候选：明确规则、有限尺度候选、分组、目标或 lookahead 选择 | 将探索发现转为满足正式协议的方法 | 当前规则实际生成的冻结低比特方案及其测量结果 |
| 正式冻结迁移包与完整 L3 | 检验当前协议下双任务表现 | 该最终方案在指定任务和评测条件的成绩 |

STE 只更新 scale 仍属于优化训练；它不是只读梯度诊断。区分**可选的科研参考优化**与**最终 PTQ 算法的 training-free 约束**：当前任务/Brief 明确允许前者时，按研究价值自主发起，沿现有实验请求与 Coding→Safeguard→执行链完成，无需重复询问许可或另设角色、阶段。若当前冻结合同要求整个研究过程无优化器更新，则使用可达的历史 oracle 或前向搜索参考，不用 Skill、自定义方法名或“仅局部诊断”绕开合同。仅阅读本参考不构成自动启动任何实验的指令。

## 如何评价尺度 oracle

固定清楚的基础方案、数据与目标，说明哪些 scale 可训练、按什么粒度共享、哪些量化参数和权重保持不变；区分同时改变零点、clipping、log-base 与只改变 scale。记录优化步数、初始化、停止依据、正则化和计算成本。原 FP 权重及正式 B 保持可恢复；探索产物采用独立身份。

将 oracle 看作经验参照：优化器可能陷入局部解，参数化和预算可能限制效果，目标本身也可能偏离最终任务。因此：

- oracle 有益，支持“这组自由度在该目标与条件下值得研究”；它不保证存在同等有效的 training-free 规则。
- oracle 无益，只削弱当前优化设定下的可行性主张；先判断优化是否实际改变参数、梯度是否有分辨力、目标和背景是否适当。无需无休止增加步数来追求正结果。
- 优化后的损失不是“理论上界”；单次搜索得到的最好值不能证明整个参数空间的最优性。
- 优化参数的数值模式是提出机制的线索。相邻层相关、token 类别差异或少数 block 大幅变化，需要在独立样本与可能的重参数化等价性下解释。

## 从数值模式转成可检验规则

比较初始与优化后的尺度相对变化，优先检查会改变后续方法设计的结构：是否集中于少数层或 block、是否与传播误差/通道范围/特定 token 分布有关、跨图或校准子集是否稳定。正尺度可用 \(\log(s_{oracle}/s_{base})\) 观察相对变化，但不同方法的尺度定义不同时先对齐实际量化作用。

按观察提出简洁的候选，而非直接复制整份 oracle 参数：

- 层内相对变化稳定：测试少量统一倍率或较低自由度共享尺度。
- 通道或 token 结构可解释：测试明确的分组、预处理或分组目标，并检查静态运行所需信息是否推理前可固定。
- FP 背景与 Q 背景差异大：测试校准时机、逐层/逐 block 或重新估计。
- 最有用变化不能被局部目标预测：测试 block 输出、有限下游 lookahead 或任务相关代理；lookahead 的深度和代价由待解决的不确定性决定。

将“从 oracle 学到的规则”与“规则在新实例上生成参数的过程”分开。正式候选从 **oracle 之前的基础状态** 重新构建，不能继承训练后的尺度、权重、零点、rounding 或其他隐含数值状态。每个新实例的参数与分组成员关系均由允许的校准信息和独立规则重新产生，包括按合同允许的前向统计或只读敏感性量；若仍需运行 STE 或直接复制本实例的学习分组，不能称其生成过程 training-free。

规则可以受到历史 oracle 的启发；若使用了据此选定的固定阈值、分组原则或目标，披露设计来源并在未用于设计的情境验证。归纳出的“如何分组”与训练得到的“本实例具体分组成员”必须区分，后者不能偷偷进入最终包。可将从基础状态重新生成的 training-free 方案与 oracle 分别测量，检验规则保留了哪些收益。

## 正则化和自由度如何进入判断

oracle 可以使用把 scale 约束在基础尺度附近、共享组内参数或限制自由度的正则化，但这些都是显式实验条件。正则项降低训练损失不等于任务改善；比较时保留未加正则的数据项与选用目标。正则化使模式更平滑，也可能人为制造想看到的层/组结构，不能把这种结构直接当作模型天然机制。

training-free 候选同样可能对少量校准图过拟合。少量候选、稳定分组和简洁规则可以作为降低自由度的方案；是否保留由独立 search 证据及目标决定，不规定必须最简单或必须加正则。需要时比较完整规则、去掉关键结构的对照和直接固定倍率，以分辨收益来自所声称的机制还是一般搜索预算。

## 冻结迁移与自适应选择

内层 calibration 用于拟合；外层 search 用于候选比较；L3 按既有正式协议执行。不得在 ADE 上重校准 scale、优化权重或重训冻结 head 来完成本次固定迁移协议。任务 loss 若需要标签，明确声明标签来源与允许范围；只读梯度评分与优化器更新分别记录。

不在 ADE 拟合能证明冻结迁移流程。若科研循环已反复读取 ADE val 成绩并据此选 B 或修改方案，该数据已参与自适应选择；应如实称为验证集驱动的研究结果。需要声称未见泛化时，另用未参与规则设计、提示词修改和候选择优的任务/数据评估，而不是把同一验证集改名为 test。

评价从 oracle 得到的规则时，避免用同一组样本既提炼规律、选超参又证明迁移。按现有允许的数据切分，选择足以回答问题的独立对照。资源有限时可以只报告探索观察与待验证范围，不需要为完整路线一次性运行所有实验。
