## CLAMP-ViT

<a id="clamp-vit"></a>

**定位与来源。** 综述 [38]，[CLAMP-ViT: Contrastive Data-Free Learning for Adaptive Post-Training Quantization of ViTs](https://arxiv.org/abs/2407.05266)，§3.2–3.5、Table 3、§4.2–4.6；[作者仓库](https://github.com/gt-synergy-lab/CLAMP-ViT)。已核对论文完整算法与仓库 README。README 主要提供预量化模型评估入口，因此目前只能确认公开入口存在，不能宣称整个合成和搜索链已经独立复现。

### 第一层：原配方

交替进行合成图片更新与量化参数进化搜索。数据阶段利用局部 patch 的对比关系，形成更有语义的合成输入；量化阶段在层级候选中搜索 scale，混精度分支同时搜索 bit width。搜索采用父代选择、交叉、变异及额外随机父代维持多样性，并缓存候选适应度。固定精度实验保留固定 bit；混精度实验允许各层不同。更新对象是图片、量化参数与位宽配置，不能将此进化搜索误判为训练网络权重。

Table 3 给出的原设置为：batch 32，首次图片生成 500 iterations，邻域 3×3、4 个正 patch，10 passes、6 cycles、15 个初始候选，候选位宽 2–8。后续周期刷新已有图像，而非每次从新噪声开始。原文固定精度主要有 W8A8、W4A8；混精度结果为实际平均 W/A，例如 DeiT-S 的 W4.7/A5.9，不能改写成 W4A4。正文中 scale 扰动区间的上下标存在可疑排版，落地时必须对照 PDF 和作者实际代码，不能按 HTML 的 `10^3` 字面生成巨大扰动。

### 第二层：可复用组件

提取局部 patch 对比生成目标、候选适应度缓存、逐层进化搜索、多样性保留与校准数据周期刷新。量化参数搜索和 bit allocation 应独立：前者可以固定 4 bit 运行，后者属于 mixed profile。对比目标可以成为校准阶段的候选 objective，但它的可信度应由后续真实任务收益验证。

### 第三层：研究 workflow

原文有固定精度、混精度、任务和搜索超参数对照。QAViT 首先在同一量化器和总 forward 预算内比较：静态合成集、周期刷新、周期刷新加进化搜索；再固定数据与误差目标，比较现有显式搜索和 CLAMP 的进化策略。记录“候选数×重复评估成本”，不能只比较最后的图像数量。分类得到的赢家能否迁移 ADE，是待验证的研究问题。

**差距与协议。** QAViT 已有候选试验和误差评价；应补数据生成与搜索状态，而非另造一套完整研究 agent。固定 precision 的 scale 搜索可进主线；2–8 bit 位宽搜索保留完整原法进入 mixed profile。代码状态为“官方仓库及评估入口已核对，端到端生成与搜索实现待核”。


## 接入依据与来源边界

**基线组件** 候选误差评价、基础量化、图片入口。

**配方阶段与依赖** 补局部 patch 对比合成、周期刷新、进化 scale/bit 搜索和 fitness 缓存失效规则。

**部署条件** 固定 bit 的 scale 搜索可主线适配；完整 2–8 bit 分配归 mixed。

**尚需核对** 公开入口主要是评估，完整生成/搜索代码未核；scale 扰动排版疑点未闭合，A4 不承接原 A8 结论。
