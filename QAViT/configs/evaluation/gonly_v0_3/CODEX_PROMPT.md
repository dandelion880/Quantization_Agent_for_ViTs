# Eval-L0 当前维护说明（gonly_v0_3）

本文件是当前离线评价资源的维护入口说明，不是重建科研流程的指令。初次接入指令原件在 `../v0_1/CODEX_PROMPT.md` 和 v0.2 来源链中保留；其中六角色、对辩/H4 及上传 ZIP 处理要求只属于当时接入任务，不能套用到当前运行。

当前实现与使用入口以 `QAViT/docs/EVAL_L0.md` 为准：`tools/evaluation/` 独立读取已有轨迹，`configs/evaluation/<version>/` 保存冻结评分合同，结果进入独立 `EXP/evaluations/`。不把评分器、评分结果或实验次数要求加入科研门禁。按原 manifest 的资源版本恢复旧评分；新 prepare 默认 v0.3，未覆盖任务显式报告，不影响其他任务。

v0.3 新增 Generation focus，并将 H3 首次提出与同一灵感的持续发展分别评价；修复、调参、组合、解释和简化可符合科研要求。当前 Generation 综合审查三个最终候选，各自按确切版本进入原 L3；独立 B 不占候选槽位。研究运行中的主题、灵感、方法与候选版本保持各自身份。

维护时验证冻结合同、来源指针、时间边界、缺失信息、成本归并、评价隔离和旧包兼容。是否调用 Skill、是否新增实验、调用数量与最终胜负均不直接决定分数。不得伪造新 Judge 分数或数值结果；新标准尚需人工校准，历史原件与原分数不改写。
