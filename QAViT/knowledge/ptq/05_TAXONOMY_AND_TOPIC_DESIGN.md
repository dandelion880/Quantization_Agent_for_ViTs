# 分类、选题与角色上下文的文字规格

本文件将新方法材料连接到 QAViT 已有的 Focus、Generation、Critic、Coding 和 Recorder。它是后续接入的文字设计，不宣称当前宿主已经提供这些新字段或接口。这里提出的分类和实验安排属于 QAViT 设计；方法事实以各方法正文及其原始来源为准。

## 1. 八个研究维度与检索标签

沿用已经讨论的八个研究维度。它们回答“本轮允许改变哪些量化决策”，与综述的方法家族、证据状态和检索元数据分开维护。

| 研究维度 | 典型可变量 | 与本包的连接 |
| --- | --- | --- |
| 校准信息与统计 | 数据来源与规模、视图、采样、统计量、合成数据、统计更新 | 数据生成方法、域适配、统计与校准成本 |
| 表示变换与重参数化 | 尺度迁移、平移、LN/Linear 等价变换、结构表示调整 | RepQ、RepQuant、DopQ、NoisyQuant、相关变换 |
| 码本与编码规则 | 均匀/非均匀/log、端点、舍入规则、零码、位宽与格式 | 表示方法、四位容量、精度与格式分配 |
| 参数共享与分组 | tensor/channel/head/token/group、固定成员、动态归属、共享轴 | ORQ、IGQ、DUQ 与模型布局适配 |
| 校准目标与参考状态 | 重构目标、task proxy、敏感度、FP/量化前缀、参考后缀 | APQ、APHQ、FIMA、PD-Quant、metric registry |
| 参数求解与误差补偿 | 网格/进化/闭式/优化、舍入、scale、权重或残差修正 | ERQ、QDrop、QwT、BiasComp、CPT/Evol-Q |
| 校准顺序与耦合关系 | W/A 顺序、层序、block/多 block 范围、重估时机、阶段调度 | I&S、PFCR、MGRQ、Bit-Shrinking、传播诊断 |
| 推理数值路径与落地形式 | 固定/动态数值行为、整数非线性、融合、附加分支、缓存、原生后端 | 新协议、部署方法、实际成本与导出重载 |

每轮围绕具体问题确定主要维度，并在需要时联动配套维度。主题写清研究问题、作用对象、可变维度、固定条件和调整范围的依据；不要求轮流覆盖八类，也不要求互斥八选一。一个尺度优化可能同时涉及目标、求解与顺序，只有实际改变的部分才属于本轮自由度。

### 用于发现资料的多维标签

单个方法不必被塞进一个互斥类别。AIQViT 同时涉及量化表示、权重补偿和校准优化；一个“representation”标签无法决定它需要哪些执行能力。以下是描述每个完整配方及拆出组件的检索元数据，不是另一套互斥研究主题。

| 维度 | 需要表达的内容 | 用途 |
| --- | --- | --- |
| 科研问题 | post-LN 通道不均衡、post-Softmax 长尾、GELU 非对称、W/A 耦合、误差传播、目标失配、校准过拟合、域偏移、结构离群、资源瓶颈 | 从实际故障检索研究路线 |
| 数学作用 | 码本/映射、范围估计、等价变换、舍入、分组、补偿、损失、求解器、调度、数据生成、预算分配、算子近似 | 找到可以替换和组合的组件 |
| 作用对象 | W、LN 输出、Q/K/V、attention probability、AV 输出、MLP 输入/输出、残差、block、任务输出 | 定位真实图边与参考张量 |
| 拟合范围 | 算子、残差单元、单 block、多 block、完整校准目标 | 确定缓存、更新对象和误差上下文 |
| 数据用途 | 统计、敏感度、搜索、重构、合成、开发选择、最终评价 | 还原真实构造成本和数据条件 |
| 推理行为 | 静态/动态、精度覆盖与例外、分支、缓存、结构变化、整数非线性 | 确定实际配置与比较组 |
| 任务证据 | 论文验证任务、QAViT 已验证任务、仅提出适配的任务 | 防止把分类结果继承为密集预测证据 |
| 可执行状态 | 已有组件、需要补全配方、需要新组件、来源尚不充分 | 让研究计划知道所需实现工作 |
| 来源身份 | 原法、作者代码配置、QAViT 适配、组合变体 | 维护结果和方法名称的对应关系 |

“近期”“正式发表”“有官方代码”“已经复现”分别记录，不能压缩成一个成熟度分数。正式发表不等于已在当前模型、位宽、任务上得到验证；预印本也不能只因有代码就获得成熟基线身份。优先纳入依据明确的 PTQ，使用可访问全文和作者实现建立可追溯起点。

QAT 来源只进入排除账本，不进入以上可检索的方法/组件/工作流分类。混合论文的 PTQ 部分有独立分支身份；分类不明时停留在来源待核实清单。

## 2. 方法短目录与长文

短目录用于发现材料，保留方法 ID、来源、问题标签、关键作用对象、推理属性、实际实现状态和正文链接。它不替代完整配方。详细的目标、超参数、顺序、张量轴、精度例外和来源差异放在方法长文中。

目录可以显示“需要重构求解器”“需要动态分组”或“有正文、未实现”，让 Focus 能提出相应研究。执行阶段只调用已经注册的真实接口。不要通过隐藏未实现方法把科研空间永久缩成当前代码的交集，也不要给尚未实现的方法填入可调用的 plugins 名称。

## 3. 选题以可检验的问题为起点

一个研究主题至少把以下关系写清：观察到了什么现象；有哪些合理解释；哪些已验证 PTQ 机制与它有关；最小的判别实验能排除什么；得到不同结果后下一步如何改变。

以下是可直接派生主题的示例，均为建议实验，不是已证明的结论。

| 观察 | 竞争解释 | 可选方法材料 | 判别实验 |
| --- | --- | --- | --- |
| post-Softmax 的 MSE 下降而任务效果下降 | 概率尾部预算失配；搜索池不足；AV 对 V 的方向敏感 | AdaLog/FPCS、DopQ、AIQ、APHQ、metric 注册表 | 固定候选池比较 selector，再固定 selector 比较码本；同时看 P 与 AV |
| 重参数化后 A 误差减少但整网变差 | W 条件恶化；后续统计仍来自旧 W；非局部传播 | RepQ、RepQuant、ERQ、传播诊断 | 分离 FP 等价性、A 量化、W 量化与顺序重估四个干预 |
| 局部重构改进在后层消失 | 局部参考失配；cross-block 耦合；校准过拟合 | I&S、PFCR、MGRQ、QDrop、QEP | 固定数据和目标，只改变重构范围/输入上下文，并评估未参与拟合的数据 |
| 少量离群 token 决定范围 | 通道统计问题；特殊 token 角色；结构性异常 | ORQ、IGQ、RegCache、相关分布诊断 | 以真实 token 布局区分固定位置处理、在线分组与结构干预 |
| 分类保持而密集任务损失较大 | 分类 token 权重过高；空间对齐变化；校准域差异 | DAQuant、任务特征 metric、多视图 PTQ | 同包迁移与目标域分别校准分列，保留每个任务的原始指标 |
| 参考量化精度较好却无实际加速 | 元数据/重排成本；FP 分支；非线性或访存瓶颈 | 部署方法文稿、精度分配文稿、成本 metric | 在固定后端上分解算子、访存与重排成本，再比较资源受限配置 |

从这些主题产生 H1/H2/H3 时，多样性来自竞争解释、干预位置、目标或求解方式。无需每次机械分配“保守/激进”三个槽位，也不应把同一 scale 搜索的三个数值当成三个独立科研假设。

主题优先级可以综合当前证据、预期信息增益、可执行成本和与已有经验的差别。不要仅按论文年份、公开 top-1 或代码接入成本排序。完整原法复现、机制判别和新组合各自有价值；明确本轮属于哪一种。

## 4. 可供角色 Prompt 引用的文字

以下段落是后续接入可复用的正文。角色原有工具约束和流程由宿主维护，不在这里复制整套 prompt。

### Focus / Generation

> 根据当前模型、任务目标和已观察现象提出研究问题。先读取相关方法的完整配方与研究工作流，说明采用哪一条原法、哪一个组件或什么新组合。区分已有证据与当前假设，并给出能区分竞争解释的实验。允许提出需要新实现的 PTQ 机制，明确其依赖；执行只能使用实际注册能力。遵守当前协议与用户研究范围，QAT 不进入候选。

### Critic

> 检查候选是否真正检验所声称的问题：参考张量和输入上下文是否一致，码本/候选池/选择器是否被混为一谈，重参数化后的统计是否仍有效，精度例外与数据条件是否影响比较，校准收益能否泛化。批评应对应具体机制或证据，并提出能够改变判断的检查。不要以旧版 training-free 限制否决已获许可的有限校准 PTQ 重构。

### Coding

> 以已提供的方法正文为算法规格，读取原配方的来源版本、张量轴、目标、顺序、预算和例外。优先复用现有数值能力，缺失的共享组件单独实现。原论文与作者代码有差异时保存不同配置；无法核实的参数不编造成作者默认。新增能力通过实际接口暴露，未实现条目保持清楚状态。不要将复现便利性的改动自动命名为原方法。

### Safeguard / L3 结果说明

> 依据候选实际构造与推理事实解释结果，包括有限校准优化、精度覆盖、动态行为、附加计算和数据用途。按本轮比较条件评价，保留不满足主配置但满足获准扩展配置的有效结果。最终冻结和可重载是执行事实，不能用推理阶段无梯度来掩盖准备阶段的参数更新。

### Recorder

> 保存这次实验消除了什么不确定性、哪些解释仍成立以及下一次应如何选择。将经验写成带模型、数据、位宽、目标和干预条件的结论，连接到方法和实验身份。不要把一次成功提升为普遍规则，也不要因一次失败永久屏蔽整类机制。能跨候选复用的决策过程进入 Skill；具体数字、配置和反例保留在证据中。

## 5. Skill 和研究案例应怎样形成

研究 Skill 的单位是可复用的决策过程。例如“在更换 metric 前区分候选池与选择器问题”“重参数化后检查统计是否失效”“评估有限校准重构是否过拟合”。方法名本身不足以构成 Skill。

每个 Skill 保留触发条件、所需可观察量、决策步骤、不同结果对应的下一步和适用边界。算法细节引用方法长文；案例记录具体模型、数据、干预和结果。现有的创建、修订、退休、共享流程继续使用，本轮不另设角色或固定审批阶段。

完整运行之后，适合由 Recorder 更新的是条件化经验，而非改写原论文的配方或事后改变实验的协议身份。
