# Static W4A4 v2 协议

日期：2026-11-25。当前协议为 `static_w4a4/2`。运行入口及历史语义见 [执行协议](../../docs/STATIC_W4A4.md)。

## 1. 研究范围和协议对象

QAViT 研究从预训练模型出发、使用有限校准数据完成的训练后量化。允许统计估计、离散搜索、闭式求解、只读反向传播和校准重构优化。QAT 方法严禁录入，不提供其配方、机制或工作流。具体模型由用户指定，通过实际模型目录、计算边和任务适配器确定结构，协议不写入某个 ViT 的层号、token 数、图像尺寸或固定超参数。

static W4A4 描述最终部署模型的表示与推理行为。它不要求准备模型时只能前向运行，也不要求所有部署参数只能由 minmax 计算。

本协议的主比较对象是同一预训练来源、相同评价流程下的静态 W4A4 模型。动态量化、混合精度、数据生成、附加补偿和结构方法均可进入 QAViT 的研究库；原配方超出静态 W4A4 时，保留其真实配置，进入相应扩展比较，或另建经过验证的静态适配变体。

## 2. 四个需要分开的事实

| 事实 | 说明 |
| --- | --- |
| 允许的研究空间 | 用户允许研究哪些精度、数据、更新对象和部署形态 |
| 本轮比较条件 | 本轮要回答的问题及保持一致的模型、覆盖、数据或资源条件 |
| 候选实际配置 | 方法最终选择了什么量化表示、粒度、优化和附加模块 |
| 执行事实 | 宿主真正使用了哪些数据、参数更新、算子、状态和资源 |

用户允许研究多个配置，不代表这些配置的成绩可直接按单个任务指标混排。反过来，同一比较问题可以包含前向校准与优化型 PTQ，公开其数据和构造成本即可。

## 3. 主配置的 W4A4 边界

主配置要求模型主体中的 Linear/Conv 权重使用四位编码；这些算子的量化输入以及实际 attention 矩阵乘法的输入采用四位表示。按模型实际计算图确定边界，包括 Q、K、V、用于 PV/AV 的 attention probability，以及第二个 MLP 线性层实际消费的非线性输出。

同一个张量边满足多个语义要求时，只在真实边上表达一次量化，不为文档名重复插入 Q/DQ。融合 QKV、转置 K、LayerScale、窗口注意力、多分支等结构通过模型适配器识别。Softmax-free 模型按其实际计算边建立对应覆盖，不能虚构不存在的 Softmax 位点。

默认覆盖主体的首尾 Linear/Conv 和 patch embedding。原配方若使用首尾层较高精度、部分 attention 边未量化或其它例外，保留并列入实际覆盖表。它可以进入研究和论文对照，但名称应明确例外，不能与无例外主配置混写为相同的完整 W4A4。

任务 head/neck 可以保持浮点，并记录具体模块、输入输出边界及是否计入部署成本。分类头、分割解码器、检测 neck 的设置应与相应 FP 对照一致；对其进行 PTQ 量化时作为显式实验变量。量化后的任务训练不因更新范围仅限 head 就自动成为 PTQ，本包不录入这类训练配方。

## 4. 四位表示的具体含义

每个已声明量化组内，每个四位 code 最多指向 16 个解码值。允许对称、非对称、均匀、非均匀、对数或其它可编码的静态码本；允许使用少于 16 个值。四位只说明编码容量，实际格式仍要记录。

零若作为独立可编码输出，应占用码字；不要求每种量化器都具有精确零值。symmetric [-8,7]、[-7,7]、无符号码本及其它合法码本可以各自使用。

以下情况必须按实际编码解释：

- 16 个非零 log 值再加独立下溢零，共有 17 个可区分状态，不能只凭 bits=4 称为固定四位编码。可保留零码、合并一个状态，或明确额外编码机制和成本。
- 浮点 zero-point 或饱和规则可能改变实际解码值个数。按完整码本与边界规则核对，不用校准样本中观察到的 unique 数量证明容量。
- 两个四位分支的输出相加、粗细码分别四位、异常值逃逸码、独立符号或索引，都应报告总表示及附加成本，不能只取其中一个字段的位宽。
- scale、zero-point、码本表、固定分组表和 bias 可以使用高精度存储；这些属于常见元数据，但其体积与推理操作需要记账。

固定组可以有不同码本。每个组的成员规则、元数据和成本必须明确，不能为每个待量化权重任意设置独立高精度码本后，仅以 code 的四位宽度主张同等压缩。

主配置的 W4/A4 表达对应权重与激活标量的编码位宽。一个 b 位索引表示整条权重向量时，应报告向量维度、码本成本和每标量等效存储；不能直接把“4 位向量索引”改写成相同含义的 W4。向量码本仍可作为 PTQ 资源比较中的独立表示方案。

## 5. static 的具体含义

最终导出时，部署权重、量化参数、码本、分组规则、校准得到的常数、补偿参数和结构选择均已确定。推理过程中不根据当前输入的数值重新估计范围、拟合参数、挑选量化分组或更新模型。

允许推理根据张量形状和模型元数据应用已经确定的规则。例如，固定区分 CLS、register/special、patch token，按固定通道组或 head 使用尺度，在不同图像大小下依照既定布局规则分配 patch。这里的归属由结构决定，不依赖 token 当前数值。位置相关或分辨率专用的静态参数也可研究，但需声明支持范围，不能默认为跨分辨率通用。

固定分段量化器的范围标志、固定码本查找、log 指数的奇偶解码及饱和判断属于既定编码计算，可以是静态量化。它们不重新估计尺度或调整独立量化组的成员。不能因编码步骤含数值条件分支就一律称为动态；同样，输入依赖的高精度逃逸分支也不能仅因阈值已固定就隐去其精度与成本。

下列方法保留在扩展配置：

- per-token/per-group 的输入数值驱动动态 scale。
- IGQ 式按实例重新分配 group 成员，即使组的 scale 是预先确定的。
- token/window 动态位宽、输入相关异常值旁路、数据依赖路由。

这些方法可以形成有效的 PTQ 成果。其动态行为和成本应在名称及结果中体现。固定部署规则本身是可重载的，但它不等同于静态量化参数和分组。

## 6. 允许的内部高精度运算

主配置允许 LayerNorm、Softmax、GELU 或替代非线性内部的高精度计算；允许 normalization 的 gamma/beta、bias、位置编码、CLS/register 常量、残差相加和矩阵累加使用高精度。进入第 3 节规定的量化边时，张量按相应四位表示消费。

因此，static W4A4 与 integer-only 是两个独立属性。整数非线性、整数累加或全整数执行图可以作为额外目标，不能由 W4A4 名称推断。

新增数据相关的高精度计算需如实分类。能够吸收到原有权重、bias 或静态 requantization 中的补偿，可在确认融合后的表示和数值后进入主配置。新增 FP 矩阵分支、低秩残差分支、保留异常值的浮点乘法等，进入带附加计算的配置；记录额外参数和算子。在公平资源比较中可以与主配置并列。

## 7. 校准和优化许可

主配置允许使用有限校准数据进行以下构造：

1. 统计范围、敏感度和分布；计算只读梯度、Hessian/Fisher 近似。
2. 离散搜索 scale、zero、裁剪、码本、固定组和调度。
3. 闭式回归、误差补偿和权重重编码。
4. 优化舍入、scale、裁剪阈值、等价变换、补偿和局部权重重构参数。
5. 原方法所需的 block、多 block 或分阶段重构；有限校准集上的结构恢复。

更新对象、优化范围、初始化、数据、目标、停止条件和实际投入随配方记录。原权重经重构发生变化是允许的；不能把“预训练来源固定”误解为所有浮点权重数值都不能变化。对于 GELU→ReLU 等非等价结构调整，记录原结构、改后结构和恢复过程，并保留能区分结构收益与量化收益的对照。

本协议不规定一个适合所有算法的统一迭代次数。原配方预算用于忠实复现；共同预算用于效率比较。统计准备、曲率、数据生成和超参数搜索也计入构造成本。

QAT 方法排除。原论文采用量化感知训练的配方，不能通过删除训练步骤、改名为“参考”或仅抽取其中的机制而录入本包。若一篇论文同时提供独立 PTQ 与 QAT 实验，只保留已核实的 PTQ 分支和相应结果；无法把两者分清的条目暂不录入。

有限校准数据上的 PTQ 重构仍然允许。是否属于 PTQ，应结合原文对方法的定义、数据量、更新对象、目标与训练流程判断，不能只由 optimizer 或 backward 是否出现判定。大规模数据训练、完整任务微调或量化感知训练不属于本协议授权的 PTQ 构造。

training-free 作为子标签保留。建议分别记录 gradient_use=none/read_only/optimization、参数更新方式=none/closed_form/discrete/iterative，以及原作者的术语。论文若宣称 training-free，应在正文解释其含义，不能用最终评测阶段没有 optimizer 来否认准备阶段的优化。

## 8. 数据、任务与迁移

校准样本量、来源、分辨率、图像变换和任务视图可以研究。真实无标签、teacher 输出、真实标签、合成数据分别记录。主配置不把“32 张 ImageNet”写成永久约束，也不把某个模型的分类 crop 当作所有任务的统一输入。

支持以下三种任务设置，结果明确命名：

| 设置 | 量化构造 | 可以支持的主张 |
| --- | --- | --- |
| 单源校准、同包迁移 | 只在声明的来源上构造一次量化 backbone，多个任务使用同一冻结状态 | 从该校准来源向其它任务/视图迁移 |
| 多源或多视图联合校准、同包评价 | 共同拟合一个量化 backbone，记录各来源和任务信号 | 多任务共同构造和统一表征保持 |
| 各任务分别校准 | 每个任务得到独立量化包 | 各任务的 PTQ 效果；不能当作同一 backbone 的通用迁移结果 |

为研究任务使用 ADE 等目标域校准数据是允许的，但需与源域直接迁移分别报告。默认从合法训练/校准划分取数据；开发集用于研究选择；最终报告集不参与参数拟合。被开发反复使用的公开验证集，按实际用途描述，不能重新命名为从未接触的保留集。

任务 head 的预训练或既有任务训练属于 FP 任务设置，在所有对应比较中固定；本包不以量化后的任务 head 训练补救结果。特征损失、teacher KL 和真实标签损失要区别，不能把 teacher 输出称为人工标注免费等价物。标签和 teacher 信号的许可不构成 QAT 许可；其实际用法仍须符合第 7 节的 PTQ 范围。

## 9. 比较方法与评价

至少保留原配方复现、统一量化条件、统一资源预算、跨任务/模型迁移四种比较目的。它们共用事实记录，但保持各自问题。

统一量化条件的比较固定模型来源、任务头、输入与评价、覆盖、表示约束和数据使用许可。若校准量、优化预算或其它变量不同，表中公开差异，并按研究问题决定是否补共同预算曲线。

资源比较允许动态、混合精度、FP 补偿或稀疏旁路。参数平均位宽按参数数量加权；激活和计算开销按实际张量与算子计算。额外 scale、索引、分支、缓存和重排进入记账。真实延迟需说明后端、硬件、batch、分辨率、warmup 和同步方式；理论 BOP、参考 QDQ 时间和原生低精度时间分列。

多任务保留每个任务的原始指标及对应 FP。主次目标、最低保留率或 Pareto 目标由任务配置决定。不能在看到结果后悄悄改变排序规则。某候选在不同实际覆盖或数据条件下获得较高 mIoU，不会自动替代所有配置下的 B。

## 10. 最终模型与复现记录

导出包保存推理所需的权重表示、码本、scale/zero、分组或动态规则、变换、补偿、结构、任务适配和配方版本。独立加载恢复确切模型；重新优化或重新校准不算加载。

记录内容由宿主尽可能自动收集：预训练来源、方法及代码版本、校准样本身份与用途、实际更新对象和预算、量化覆盖与例外、真实配置、评价视图、原始指标、成本及模型包身份。不要把这些都变成研究角色每次手填的长表。

局部诊断和消融可包含 FP、旁路或较高位宽，不需要伪装成最终模型。其结论限制在实际干预范围。完整结果的声明依据对应配置的覆盖、状态和测量事实。

## 12. 接入说明

本文件定义研究语义，不要求新增角色、审批阶段或每次必做实验。原有 Focus、H1/H2/H3、Critic、Coding、Safeguard、L3 和 Recorder 流程继续使用。

接入时同步修改协议解析、上下文、数据用途、参数更新记录、父包复用、结果核对和方案比较。不要只删除 static 检查，也不要只改变提示词。旧接口中的 training 可以暂作兼容字段，新逻辑应读取本次构造与评价的具体属性。
