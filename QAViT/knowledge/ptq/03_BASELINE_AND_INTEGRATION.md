# 源码基线与接入说明

基线：QAViT(20261124-101904)。本文件说明文字资料如何进入现有组件，不规定最终目录。

## 1. 当前已有的研究基础

当前主流程已经是 Focus → H1/H2/H3 → Critic → Generation 综合修订 → 三候选各自 L3 → Recorder。主题、方法、灵感、候选有不同身份；原件能够按确切引用恢复。Recorder 已有 Skill 的创建、修订、退休和跨运行共享机制。

现有数值库包含 RTN、GPTQ、GPTAQ、AdaRound、uniform、twin、log2/log√2、AdaLog、PTF、SmoothQuant、RepQ-LN 和偏置变换等。原生 AdaLog 是 base×scale 适配，不能等同完整 FPCS。ERQ 的研究路线已存在，但本版没有原生可执行 ERQ 注册。

底层执行契约已有动态 activation calibration、per-channel/per-group/per-token、多种整数与低位浮点参考格式、逐层不同 spec。它们提供表示容器，不代表已实现 IGQ、混合精度分配器或对应原生 kernel。integer LayerNorm/Softmax 也是参考数值能力，不是已测得端到端整数加速。

现有 frozen_trials 支持同父模型、同输入、多视图、多层、分类与 dense 特征/logits 评分；propagation 支持配对 FP/Q、本地新增误差、传播和交叉项。AV 类输出评分已有基础。新材料应补全数学定义、使用方式和可执行变体，不重复建设这些概念。

## 2. 本包材料的五种接入去向

| 去向 | 接入内容 |
| --- | --- |
| 方法文档 | 机制定义、数学对象、参数、前提、原始来源、适配方式 |
| 完整配方 | 有序组件、数据、拟合范围、超参数、结构/精度例外、最终产物 |
| 科研 metric | 准备统计/梯度、评分对象、参考、归约、选择器评测和成本 |
| 研究 Skill/案例 | 问题、竞争解释、判别实验、结果如何改变下一步 |
| 来源与能力目录 | 原文版本、阅读范围、实现状态、接口及确切文档入口 |

同一篇论文可去往多个位置。共享机制只实现一次，完整原法通过配方组合调用。对原法作数学或资源改变时保存适配变体身份和差异。

## 3. 方法文稿与实现状态

文档出现方法名称不开放执行接口。现有方法索引的 plugins 只填写真实注册能力；尚待实现的条目用文字状态和建议接入点表达。建议将“论文已报道、原文已读、作者代码已核对、组件已实现、完整原法已复现、目标协议已验证、后端已实测”作为彼此独立的事实。

不存在统一的成熟度分数。正式发表但代码不完整的方法，可以据原文实现；只有摘要可读的条目不能凭常识补出训练顺序。原方法的公开数字不填入 QAViT 实测结果。来源存在错误时保留更正，不能以综述的表格行替代原始论文身份。

QAT 严禁录入。接入方法索引、Skill、metric 和研究案例时都遵守这一范围；不能将被排除的 QAT 条目放到“启发”“上限”或“仅 primitive”栏目绕过。来源覆盖表只记录排除及其依据。混合论文仅使用经过原文核实的独立 PTQ 部分。

## 4. 共享实现应表达哪些数学选择

### 重构

把更新对象、重构范围、目标函数和调度分别表达。参数可以是 rounding、scale、裁剪、变换、补偿、权重或局部结构；范围可以是算子、残差单元、block 或多 block。完整 FIMA、APHQ、QDrop、I&S 等复用公共设施，各自保留原顺序和状态。

### 数据和任务

明确使用哪个 task view、哪些窗口/token、哪个 head 和 loss。现有 calibration.capture 的梯度路径主要是二维分类 logits；已有 dense 观测不等于已有 dense 拟合。扩展时保留真实 mask、空间布局、窗口归约和标签使用事实。

### metric 与候选

保留现有冻结评分器。曲率/teacher 等准备步骤独立执行并缓存，缓存绑定模型、数据、参考和任务身份。支持完整模型包候选，不要求所有方法伪装成 scale 乘数。已有 OutputErrors 还服务健康/等价性检查，科研 metric 的新增不能改变这些检查的含义。

### 组合

组件写出需要的输入和统计、改变的状态、下游应重估的量。组合顺序由机制决定。可编程的兼容检查只检查真实接口和数学前提；关于“组合可能有害”的经验保留为条件化研究材料。

## 6. 科研上下文怎样读取本包

方法短目录只给问题、作用对象、实现状态、主要条件和正文入口。Generation/Focus 按问题读取完整原文稿；Coding 读取当前选择的配方、primitive 和数值接口；Critic 读取候选所依赖的关键机制与比较条件；Recorder 将实际结果写成带条件的经验。

方法长文不全部塞入常驻 prompt。Skill 只描述可复用决策过程，具体公式和配方放方法正文或 references。保留必要全文读取，避免只靠目录摘要形成算法结论。

## 7. 文字接入的完成标准

1. 来源清单每条都有正文或明确的来源缺口，别名、版本和重复关系可追溯。
2. 完整原法、拆出的机制、QAViT 的新变体有明确身份。
3. 方法的前提、更新对象、数据与精度条件在索引和正文一致。
4. 新 metric 有明确数学对象和准备条件；没有把功能近似当原方法。
5. 未实现能力在上下文中可被发现，但不会伪装成已经可调用。
6. 现有能力复用，旧协议与历史成绩保持原义。
7. 人可以从问题找到方法、读懂选择理由并定位原始来源。

这些是此次接入的检查点，运行中不要求每个研究任务逐项重复填写。
