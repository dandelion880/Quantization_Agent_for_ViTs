# 从 PTQ 方法中提炼的研究工作流

本文件给出可供 Focus、Generation、Critic 和 Recorder 使用的跨方法研究路线。它们是为 QAViT 设计的实验推理方式；方法正文另记作者已经完成的证据。按问题选用，不要求每轮逐项执行。

QAT 方法及其训练路线不在本包范围。有限校准重构的许可遵循 01_STATIC_W4A4_V2.md。

## 1. 从成熟原法建立可信起点

**适用问题：** 当前完整方案薄弱；新论文的公开结果明显更好；改编结果与预期不符。

先确定具体版本与原配方：量化范围、输入处理、校准量、参数更新、默认优化预算和精度例外。用已知结构的参考模型验证关键语义，再迁移到用户指定模型。存在论文与作者代码差异时，保存两种配方，先决定正在复现哪一种。

比较原配方、当前实现和目标协议适配三个对象。若适配效果差，分别检查代码数学、原法条件改变和模型差异。缩减校准量、去掉学习阶段、改变首尾精度或参考输入，都会形成新变体，应把差异写进解释。

**下一步选择：** 关键算子已经对齐而整网差距仍大，再检查拟合顺序、输入上下文、校准及评估条件。来源或实现错误不构成机制反证。原法稳定后，将完整方案作为 H1/H2 可追溯父方案；其公开成绩不直接成为本地 B。

来源思路：AdaLog、ERQ、FIMA-Q 及各文稿中的论文/代码版本差异；这是本包的通用复现流程。

## 2. 区分表示、候选生成与选参能力

**适用问题：** 新码本或更密的搜索获得收益，但原因不清楚。

把三个变量分开：可表示的候选集合、生成候选的算法、选择候选的 metric。同一个倍率网格未必对应同一批实际码本；比较时保存每个候选的真实参数和最终状态。

先用固定候选池比较 metric，再在固定 metric 下比较不同搜索器。码本形状比较匹配候选评估次数，并另外记录统计准备成本；搜索效率比较给出预算—效用曲线。FPCS 的收益可以来自更有效的局部细化，不能全部归因于 adaptive log 表示。

**结果解释：** 池中存在好解而选不出来，研究 metric；池中没有好解，研究表示或候选覆盖；低预算差、高预算好，研究搜索效率；局部候选好但组合差，研究交互和调度。

参考：AdaLog §3.2–3.4，https://arxiv.org/html/2407.12951v1 。

## 3. 观察 W/A 误差转移和耦合

**适用问题：** smoothing、RepQ 或裁剪降低了激活误差，却没有改善 block 或任务输出。

对一个线性层采用 Y=XW+b，X∈R^(n×d)，W∈R^(d×m)。令量化误差分别为 E_X 和 E_W。忽略额外 bias 改动时，输出误差为 X E_W + E_X W + E_X E_W。三项的平方范数还包含交叉项，不能把分开测得的 W/A 损失直接相加。

在同一父状态上比较变换前后、W-only、A-only、联合量化及必要的顺序变化。诊断 FP 旁路用于定位，最终效用仍由合法量化方案确认。变换后重新测量 W 分布、输入相关统计和局部输出，不只展示激活峰值缩小。

**下一步选择：** 若 A 改善被 W 恶化抵消，考虑补偿、目标 scale 或联合拟合；若顺序决定收益，研究真实前缀与重估；若交叉项主导，扩大干预单元或联合求解。

参考：RepQ-ViT 的重参数化；ERQ §IV，https://arxiv.org/html/2407.06794v2 。上述线性误差展开为本文件推导。

## 4. 将局部拟合与真实传播联系起来

**适用问题：** 局部重构损失很低，后层或 dense 任务仍明显退化。

明确参考是全 FP 网络的输出，还是同一量化输入经过 FP block 的输出。前者包含上游累计偏差，后者隔离当前 block 的局部影响。保留两种观测，分别回答局部注入、上游传播和下游放大问题。

先检查现有配对传播记录，再选择少数会改变判断的条件：FP/量化输入、局部/残差/block/多 block 目标、短/长后缀。比较扩大范围是否获得独立数据收益，以及其额外拟合和显存成本。

**下一步选择：** 局部误差下降但后缀放大，研究目标或范围；真实前缀拟合有效，研究顺序；更大单元只降低校准损失，研究过拟合。QAViT 已有的 propagation 和 local_fp 观测可作为起点。现有 frozen_trials 的 local_fp 固定在 parent 输入上；候选若同时改变上游，它与候选输出的差就不再是同输入的纯局部误差。按 metrics_registry.md 区分 parent 输入参考和 candidate 当前输入参考，复用现有配对传播能力。

参考：GPTAQ、QEP、PFCR、MGRQ，见相应方法条目。上述决策分支是 QAViT 实验设计。

## 5. 检验 metric 是否真正帮助选择

**适用问题：** 新目标的数值更小、与任务相关性更高，但没有稳定带来更好候选。

冻结同一候选池，在声明的选择数据上分别用 MSE、结构目标、APH/FIMA 或任务代理选出候选，再在独立确认数据上评价这些选择。记录池内可达最好结果、所选结果、选错损失和多任务冲突。相关系数作为辅助，不能替代最终选中候选的质量。

敏感度准备绑定父模型、数据、损失、扰动和参考。比较目标时把准备成本计入预算。真实梯度为零时保留事实，不用另一种 loss 偷换；普通协方差/PCA 与 Fisher 的估计对象不同。

**下一步选择：** 简单目标已能选中好解时可保留它；复杂 metric 只对特定候选族有效，沉淀其触发条件；所有目标都难选时，检查候选差异是否低于观测噪声或确认数据是否代表部署分布。

参考：APQ、APHQ、FIMA-Q 与 PD-Quant；具体数学对象见 metrics_registry.md。

## 6. 研究有限校准重构的泛化

**适用问题：** 增加优化步数降低拟合误差，却损害开发集或迁移任务。

固定数据和初始状态，比较重构过程中的扰动、正则、单元大小、阶段顺序和停止点。首先查看校准与独立确认曲线是否分离，再决定增加样本、调整扰动或缩减自由度。记录唯一图像数与反复使用次数，避免用更多 sample presentations 冒充算法效率。

QDrop 的 activation quantization dropping 可作为独立干预；I&S 的阶段性表示转换可作为优化路径干预。若原法分阶段更新的对象不同，不能把它改写为“所有参数一起 Adam”后继续使用原方法名。

**下一步选择：** 扰动只改善独立数据，研究其泛化作用；只是拟合更快，研究预算收益；更多数据有效但更长优化无效，研究校准覆盖。不要仅凭一次损失曲线声称找到更平坦的最优解。

参考：QDrop，https://arxiv.org/abs/2203.05740 ；I&S-ViT，https://arxiv.org/html/2311.10126v3 。

## 7. 判断固定粒度还是动态分组更合适

**适用问题：** 某些通道/行/token 的尺度差异大，但不同输入的敏感位置并不一致。

先测组内离散度、跨输入的范围变化和固定分组的稳定性。用同等组数比较固定成员和输入依赖成员，再把运行时统计、分组索引、重排和 scale 元数据计入成本。动态分组不是 per-token minmax 的同义词。

静态适配可以根据校准数据确定固定组，但这已经改变 IGQ 等原方法的关键机制，应使用独立变体身份。相同收益下比较更少组、更粗粒度或更简规则，形成可解释的简化。

**下一步选择：** 稳定异质性适合静态分组/重参数化；实例变化明显再研究动态机制；动态收益主要来自更大组数时应补预算匹配。任何静态候选都按静态主协议验证，动态原法按其真实配置报告。

参考：IGQ-ViT，https://arxiv.org/html/2404.00928v1 。

## 8. 把数据覆盖、目标和恢复器分别研究

**适用问题：** 扩大校准集、多视图或合成数据改善结果，却不清楚改善来自哪里。

在同一恢复器上比较数据来源、数量、视图和选择策略；在同一数据上比较目标和恢复器。分别记录数据生成/选择成本与量化拟合成本。对于分类和 dense 输入，同一原图的多个窗口不能算作独立图像。

源域单次构造后迁移、目标域校准、联合校准分别回答不同问题。对合成数据，比较其被量化模型内部的范围、patch 关系、attention 和任务输出覆盖，而不仅看图像外观。用于评价合成器的下游恢复过程必须也是已确认的 PTQ，QAT 学生训练配方不录入。

**下一步选择：** 校准变大仍无法改善，研究恢复器/表示；少量结构性样本有效，研究覆盖；只有目标域数据有效，缩小迁移主张并研究域差异。

参考：PSAQ-ViT、CLAMP-ViT、SARDFQ、DAQuant 的已确认 PTQ 部分，见对应条目。选择策略实验是本包建议，不将 DAQuant 冒称样本选择算法。

## 9. 区分等价变换和输出残差拟合

**适用问题：** bias、affine 或线性补偿有效，希望简化它或判断能否跨任务迁移。

等价变换在未量化时保持原函数；输出补偿则拟合量化残差。先明确补偿张量的形状和参考，测残差均值、通道/位置相关性，再比较常数、逐通道和更大线性模型。

比较原始补偿与融合后的真实结果；融合中的舍入、偏置量化和下游 clipping 可能改变效用。token×channel bias 不能未经处理就跨分辨率加载。补偿参数多时，应查看独立数据收益和资源开销。

**下一步选择：** 均值偏差占主导可简化；结构残差显著时保留足够表达能力；融合后损失收益，研究表示和安装位置；换视图即失效，研究共享轴和拟合数据。

参考：Bias Compensation、QwT、QwT-v2，见补偿方法条目。

## 10. 从精度分配到实际部署取舍

**适用问题：** 低位配置的精度不够，或理论计算下降没有转化成真实速度。

构造每个候选位点的质量—资源响应，再进行全局 bit、format 或 group 分配。敏感度是分配器输入，实际目标由预算与任务决定。预算匹配时包含首尾例外、旁路、元数据、分支和不支持的算子。

部署研究先确定后端真正执行的图，再测端到端结果。检查 nonlinear、residual、requantization、pack/unpack、布局转换与 FP fallback。参考 QDQ 用于数学验证，不能用它的时间证明低比特 kernel 加速。

**下一步选择：** 少量高敏感位点决定大部分损失，研究分配；分配复杂却无实际速度，研究融合/格式兼容；仅某硬件有效，明确部署条件。硬件研究只有确认独立 PTQ 流程的部分进入方法库。

参考：AMP、LampQ、MixA-Q 的 PTQ 分支、IPTQ 及已核实的 PTQ 部署条目。

## 11. 从结构干预得到可解释的结论

**适用问题：** register/token 处理、非线性替换或其它结构改变带来收益。

按实际机制选择对照，区分结构本身、量化和恢复优化。例如比较原结构 FP、改后结构 FP、原结构量化和改后结构量化；若改结构需要重构，则记录数据和预算，并根据问题增加对应恢复对照。并非每次都必须跑全部组合。

在 dense 任务中核对 patch 网格、特殊 token、窗口位置与任务头入口。删 token 后的插值、缓存或新前缀属于方法的一部分，需要导出和成本记录。不能因模型已经有 register 就直接推断 RegCache 一定有效或无效。

**下一步选择：** 量化误差改善来自已确认结构机制时研究更便宜的实现；主要收益来自额外优化时如实归因；任务间冲突时研究空间信息与共享表示。

参考：APHQ 的 PTQ MLP reconstruction、RegCache 原文及相应条目。

## 12. 让研究结果进入下一轮

每条有价值的结论保存问题、父状态、干预、实际条件、观测、替代解释和下一步。成功、失败、未执行和工程错误分别记录。某个 metric 的选择能力、某种组合顺序或某个数据条件被反复支持后，再提炼成 Skill 的触发条件与工作流。

方案库保存完整可重载模型与评价；灵感库保存尚未完成的机制及原件；知识保存带条件的判断；Skill 保存可复用的决策过程。三者可互相引用，无需复制长正文。论文中的已发表结果保持来源身份，运行产生的新证据才更新本地结论。

这一闭环评价的是研究是否更有效：是否减少重复、是否更快排除错误解释、是否保住跨任务效用、是否形成更简洁或更强的可复现方法。方法名和 Skill 调用次数只作覆盖统计。
