# 共同科研约定

本页用于遇到歧义时查阅。它不创建新角色、阶段、固定输出 schema 或宿主校验；当前任务目标与冻结实验协议决定实际行动边界。

## 方法、参考、假设与结果

- 文献、历史人工研究与启发案例提供可复用线索；当前实验结果由真实执行与 Evidence 支持。
- “观察到”用于已有测量；“可能因为”用于解释；“建议测试”用于未执行的方案。实现存在、CPU 小例子、真实模型局部结果、正式任务结果支持不同范围。
- 参考解是一个可用参照，可以优于当前状态；未经证明，不称全局最优或理论上界。FP bypass/off-grid 只说明特定干预的功能后果。
- 完整方案包含可执行的量化范围、编码、校准和评测定义；可以从已有可信方案局部改良，不要求重新发明所有部分。
- 论文里的公开论证可以重构为研究路线；作者真实试错顺序未知时，不用虚构历史填补。

## 几个容易混淆的边界

| 术语 | 本包含义 |
| --- | --- |
| training-free | 最终方法按当前 Brief 的定义不依赖参数微调；统计、解析补偿与只读梯度是否允许分别明确 |
| forward-only | 校准计算不依赖反向；比“不使用优化器训练”更强，不能混称 |
| static | 校准得到的参数/规则按协议冻结；不把逐输入重估 scale 的结果记作同协议静态量化 |
| W4A4 | 按项目覆盖范围实际形成所需有限码点；浮点 head/neck 等例外沿用 Brief，不自动放宽其他位点 |
| scale 共享组 | 校准中共同选择的参数或倍率；不自动改变推理量化粒度 |
| block 调度 | 更新次序；是否观察 block 输出、是否联合优化由各自定义决定 |
| oracle-assisted | 在实验中使用较好参考的逐实例参数、标签或成员；不能冒充不依赖参考的独立方法 |
| 合成/单元数值证据 | 小例子的计算或接口正确性；避免用 L0 与项目 Eval-L0 离线评价编号混淆 |

相同整数 code 索引不保证相同重构值；不同 scale/zero 可能导致不同输出。相同最终位宽也不保证相同粒度、静态性、码本形式、训练成本和任务协议。

## 数据与状态

区分方法构造/校准、选择确认、正式评测的数据用途。实际重复使用过的数据不能重新命名为未见数据；历史已调 head 或用正式成绩选分支的限制应保留。当前 frozen transfer 中，ADE 不应按目标域正式数据再次拟合量化器或 head，除非原协议明确允许并如实作为另一个任务报告。

FP、W4A32、Q0、候选、B 与 oracle 需要可追溯状态。比较应尽量使用相同输入、预处理、head、样本和背景；不以文献 FP、另一子集 FP 或另一轮 B 自动代替本次参照。百分点与相对百分比、pooled mIoU 与逐图均值分清。

候选改变前缀、变换或码器后，判断缓存是否仍匹配实际状态。已有足够可信证据就复用，保持效率；缺失来源通过当前请求修订机制解决，不绕过可见性，也不把未测量记录为失败机制。

## 自由研究与证据责任

H1/H2 均改良已定义完整方案，H1 偏方法启发、H2 偏证据瓶颈；可从 archive 或其他可访问完整来源开始。B 是独立保底。H3 可以由理论、反例或新表示直接提出，不必先做 profiling，也不按固定次数或强制配额获得/失去机会。

一个机制可以同时影响多个决策，因此 Skill 可组合；调用哪个由当下缺口决定。充分的直接证据可以跳过代理比较；理论启发可以先建小原型；预算不足可以保留未验证状态。对原创想法评价其可证伪增量与研究价值，不以名词新颖、组件数量或正结果强制加分。

## 本轮对记忆与沉淀的范围

继续利用现有 Recorder、研究笔记、Journal 与可访问历史方案。失败条件、反证和未解决问题可沿当前复盘沉淀。流程版本与读取快照见[资源生命周期](../../docs/RESOURCE_LIFECYCLE.md)。

本包的 `learn-from-reference-solution` 研究量化算法本身。

H3 默认跨轮发展一条活跃灵感；首次定义机制后可持续修复、调参、组合或简化，不要求每轮新机制。独立灵感库保存负结果、未完成实现及暂停方向，Generation 决定是否继续；H1/H2 在完整父方案上吸收可用部分并保留增量与回退。
