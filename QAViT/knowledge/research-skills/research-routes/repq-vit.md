# RepQ-ViT 路线案例：把异质性定位与等价变换连接起来

**用途**：当 LayerNorm 后跨通道尺度悬殊、不同粒度量化差距明显，或某个变换改善激活却使权重量化恶化时参考。优先关联“诊断量化失败”“改造量化方法”“评估量化候选”。

**证据性质**：第 1 节概括论文公开论证；之后为 QAViT 的独立研究提案。这里重构的是可学习的逻辑，不是作者实际先后做过的全部实验。

## 1. 已核对的公开论证

公开逻辑从两种失配出发。post-LN 的通道范围差异使统一层尺度难以兼顾各通道；论文先做 per-channel 校准，再调整 LN 的仿射参数及后继线性层的权重/bias，转到推理时的 per-layer 表示，并重校准受影响权重（§3.2、Algorithm 1）。post-softmax 中较大值被 log2 码点过粗表示；论文采用 log√2，再通过换底及奇偶相关尺度改写其计算（§3.3）。

## 2. 从“异常很大”推进到“异常在哪个维度稳定”

建议先检查异常是否随样本变化，及其稳定轴：通道、token 类型、head、空间位置或层深。稳定通道尺度适合考虑离线变换；样本依赖异常可能需要另一种静态分组或非均匀表示，不能因为单图恰好有极端通道就直接迁移同一变换。

有用的观测包括：各通道分位数范围、跨样本排序一致性、不同 token 类别的贡献，以及变换前后相邻权重的范围。无需为每个观测写死阈值；重点在于是否有证据支持一个能解释失败的机制。

## 3. 数学视角：浮点等价与量化等效要分开

以下是用于推理的通用仿射恒等式，不是 RepQ-ViT 的完整更新公式。采用行向量约定：

\[
Y=XW+b,\qquad
X'=(X+C)D^{-1},\quad W'=DW,\quad b'=b-CW,
\]

其中 \(D\) 为可逆对角矩阵，\(C\) 按样本广播，因此 \(X'W'+b'=Y\)。

**本案例的推论**：浮点函数相同，不意味着分别量化后的函数相同。重分配尺度可能同时改变激活和权重误差，所以研究对象应是相邻组合的输出，不能只查看激活直方图是否更平坦。若权重已做量化补偿，变换后继续沿用旧码本也可能改变问题本身。

## 4. 竞争解释与可区分预测

| 解释 | 预期观测 | 有价值的反证 |
| --- | --- | --- |
| 固定通道异质性是瓶颈 | 静态通道尺度跨样本较稳定；调节后激活误差与组合输出一起改善 | 仅单图改善，跨样本无规律 |
| 变换把误差转移给权重 | 激活误差下降，权重误差或线性输出误差上升 | 重校准后仍无变化，需检查其他原因 |
| 变换实现或融合不一致 | 尚未量化就出现超出数值容差的函数差异 | 浮点等价成立，问题只在量化后出现 |
| 异常主要属于 token 类别 | 聚合通道统计掩盖不同 token 的行为 | 按 token 分组后仍是相同稳定通道主导 |

## 5. 推荐的研究顺序与对照

先做一次很便宜的浮点等价检查，其目的只是保证正在研究预期变换。然后在一个代表位点比较：当前配置；只改变激活表示的诊断参照；变换后按同等预算重新校准相邻量化参数的候选。诊断参照不构成可达到的性能上界。必要时再分离“变换”和“额外重校准”效应：给原配置相同的重新搜索机会。

| 应匹配的条件 | 为什么 |
| --- | --- |
| 相同量化前缀与校准样本 | 排除输入分布不同导致的假收益 |
| 相同目标输出与比较粒度 | 防止把单张量收益误报为组合收益 |
| 相近候选数/数值成本 | 排除重校准机会不对等 |
| 对齐最终表示容量，固定非研究变量的粒度、码本形式及静态规则 | 排除额外容量或动态参数带来的收益 |

这里对齐的是码点数、粒度与码本形式等比较条件，不要求不同变换后的重构值逐个相同。如果粒度或码本形式正是研究变量，应把它单独列为变化。“通道粒度更细”的实验可作诊断，但最终方案是否允许这种粒度由当前协议决定；不必把论文的部署偏好提升为 QAViT 的额外限制。

## 6. 结果如何影响方法设计

如果激活改善、权重恶化，下一步可以研究变换强度、分组、校准顺序或相邻补偿；不要直接判定“重参数化无效”。如果浮点等价正确但量化后组合误差没有改善，就应检查位宽下的码点使用与权重重校准，而不是无限搜索相同尺度。若只有 CLS 指标改善而 patch 恶化，说明目标选择和 token 覆盖值得重新审视，不能仅凭分类信号宣称保留了通用表征。

## 7. 完整研究片段示例：假想，不是实测

一个模型的若干 LN 输出通道跨样本始终偏大，静态激活量化损失明显。研究者据此提出“稳定通道异质性”假设，先验证变换前后的浮点函数一致，再测试量化后的邻接线性输出。如果激活误差降低但输出不改善，就检查新的权重范围，并让对照与候选都有一次相同预算的重校准。若改善只在重校准后出现，结论应保留“变换与校准时机共同作用”，而不是把所有收益归给某一个尺度公式。

## 8. 迁移条件与可保留经验

- 不把“同为 ViT”当作迁移依据。实际 LN/线性连接、残差、分支共享、bias 与 LayerScale 会改变可融合位置。
- 对 post-softmax 方案，同时检查注意力输出及整个 block。改善 \(P\) 的逐元素误差不必然改善 \(PV\)。
- 本案例不承诺任何设备上的实际加速；数学上便于实现、fake quantization 正确和真实内核高效是不同证据。
- 静态变换由校准数据确定后冻结，最终权重和激活仍按指定 W4A4 量化。诊断过程中暂时保留浮点的对照不能作为最终成绩。

**可迁移策略**：先找出异常的稳定维度，再提出能作用于该维度的变换；同时追踪误差被转移到哪里，以组合输出和目标任务检验净收益。
