# GPTAQ 路线案例：研究输入来源、参考目标与误差传播

**用途**：当局部重建误差不错，但误差随深度扩大；或量化顺序改变结果；或浮点输入下的候选排序不能迁移到真实量化前缀时参考。优先关联“诊断量化失败”“判别性实验设计”“改造量化方法”。

**证据性质**：第 1 节是原论文论证摘要，后文为 QAViT 的独立应用提案。没有声称论文作者实施过这里设计的全部对照。

## 1. 已核对的公开论证

公开逻辑是：前层量化改变后层输入；若当前层只拟合该受扰输入下的浮点输出，就未显式恢复原浮点路径（Fig. 1–2）。因此 §4 Eq. 4 改为用实际量化路径输入拟合原浮点参考输出，并从该目标推导同时处理当前量化误差与前缀失配的权重更新。

Table 5 在 LLaMA 设置下分别保留两类更新项，检验它们的贡献；§5.5.2 另比较量化顺序，检查激活误差是否在权重校准时可见。**§5.1 默认采用 per-token 激活量化**，故论文 W4A4 数字不能直接充当 QAViT static W4A4 基线，LLM 消融也不是视觉任务上的直接证据。

来源：[正式论文信息](https://proceedings.mlr.press/v267/li25dn.html)；[原文 PDF，Fig. 1、§4、§5.1–5.2、§5.5](https://arxiv.org/pdf/2504.02692)。核对版本：arXiv v3，2025-05-13；ICML 2025。

## 2. 首先写清“谁给谁当输入和目标”

“逐层校准”“顺序校准”“非对称校准”不是足以复现实验的描述。至少在研究笔记里明确：

| 对象 | 需要辨认的状态 |
| --- | --- |
| 浮点参考输入 \(X_f\) | 哪个固定模型、哪些预处理与样本产生 |
| 待校准路径输入 \(X_q\) | 已量化哪些前缀；本层激活是否已按候选量化 |
| 参考输出 \(Y_f\) | 原浮点路径输出，还是对 \(X_q\) 运行浮点算子的输出 |
| 候选输出 | 校准时的临时输出，还是冻结全部参数后的实际输出 |

若这些来源在候选之间不同，“MSE 更低”很可能是在比较不同问题。确认来源属于理解证据，不应变成要求 agent 填写冗长表格才能实验的流程。

## 3. 数学视角：区分两个重建问题

采用教学记号 \(Y=WX\)，忽略已一致处理的 bias。两个目标为：

\[
L_{\mathrm{same}}(\widehat W)=\|\widehat W X_q-WX_q\|_F^2,
\]

\[
L_{\mathrm{ref}}(\widehat W)=\|\widehat W X_q-WX_f\|_F^2.
\]

第二个目标对应论文 §4 的核心问题。基本代数给出：

\[
\widehat W X_q-WX_f
=(\widehat W-W)X_q+W(X_q-X_f).
\]

**本案例的推论**：在第一个目标上非常优秀的量化器，仍可能保留前缀引起的漂移。两项之间还有相互抵消或放大的作用，所以不宜仅靠独立误差大小判断最终改进。

## 4. 竞争解释与分级干预

候选在整网失败时，至少考虑：参考目标不合适；校准时输入与冻结部署时输入不同；局部解过拟合少量校准样本；当前改动的位点并不影响主要下游损失。

推荐先用已有缓存做来源一致的诊断，必要时在一个 block 开展小规模对照：

| 对照 | 保持不变 | 回答的问题 |
| --- | --- | --- |
| 相同 \(X_q\)，不同目标 | 量化形式、候选数、样本 | 是否需要拟合原浮点参考？ |
| 相同目标，改变校准时机 | 合法码点、数据、搜索预算 | 前缀和激活冻结状态是否重要？ |
| 层级与 block 级目标 | 输入来源、最终协议 | 相邻局部补偿是否相互破坏？ |
| 同一候选在独立样本重测 | 参数冻结 | 是否只是在校准样本上补偿成功？ |

不必全量遍历所有组合。优先选能区分当前两种主要解释的比较。已经充分支持的机制无需每轮重复证明。

## 5. 与现有方案组合时特别要注意什么

方法组合可能改变输入和目标的语义。先做重参数化再做权重补偿，与补偿后再改变激活分布，通常不是同一个问题。重用缓存前应判断其对应哪个变换状态，而不是仅根据文件仍存在就复用。

另一个可研究方向是：同一合法 static W4A4 量化形式，分别使用一次性浮点校准、按层更新量化前缀、按 block 更新校准。它们的差别在于观测和优化时机，不需要把最终推理改成动态量化。若采用少量真实任务指标来选候选，应使用独立开发样本并清晰报告标签使用，不能把最终保留测试结果反复纳入校准。

## 6. 结果怎样改变判断

- 若参考目标改动同时改善 block 与末层特征，前缀误差补偿得到初步支持；仍需确认目标任务收益。
- 若只在校准集改善，先检查样本覆盖、正则化和参数自由度，不应立即宣称传播机制错误。
- 若更换目标无效，而改变校准时机有效，可先把时机作为搜索变量，不必强行采用更复杂的更新式。
- 若若干候选在不同 metric 下排序翻转且影响最终选择，转入指标判别实验；不把某个代理损失写死为科学真理。
- 若数值任务未执行或中途失败，结论是缺证据；不能将失败日志解释为非对称补偿无效。

## 7. 完整研究片段示例：假想，不是实测

三个候选都改善第一层 Q 的局部误差，却未改善末层 patch 特征。研究者首先检查候选是否在同一已量化前缀上评估。随后用冻结模型观察误差沿 block 的变化，发现更晚位置才出现主要放大。研究者在该处固定量化形式，比较相同输入目标与原浮点参考目标；如果后一目标只改善当前 block，后续仍恶化，就继续检查邻接算子和校准更新时机，而不是再回到第一层 Q 做更细尺度搜索。

## 8. 迁移边界与可保留经验

本路线可迁移的是“识别输入与参考的失配并设计补偿”，不是默认复制论文的激活粒度、damping 数值或分类成绩。最终静态参数由校准确定后冻结；权重、激活均遵守当前码点约束。权重闭式校准或离散补偿与梯度微调不同，不因需要修正权重而自动引入训练。

**可迁移策略**：局部优化失效时，先问它是否在拟合正确的输入—输出关系；用相同候选和真实量化前缀检查目标、时机与传播，而不是把更低局部误差当作最终目标。
