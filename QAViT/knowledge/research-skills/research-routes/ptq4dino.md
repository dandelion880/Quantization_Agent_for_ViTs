## 问题起点与参考解

**包作者记录的用户确认路线。** 现有 PTQ 在 DINO 上效果很差，因此怀疑原 scale 选择未能保留任务所需信息。先进行轻量 STE，只训练已有激活 scale，取得一组明显更好的选择；观察其与 token 类型、算子、层和 block 的关系，进而研究候选生成、同层分组、metric 和 lookahead，最终形成不依赖训练的校准改良。[D0, D1]

这一决定有明确研究价值：若同样四位表示、相同已冻结 W 和 head 下，主要通过激活参数即可恢复性能，那么“必须先增加位宽/更新权重才能改好”就不是唯一解释。参考解提供存在性证据和结构线索，并不直接给出失效机理，也不保证全局最优。

**后续更详细的原件是另一个自由度分支。** 2026-10-16 保存的参考实验同时优化 5619 个激活 scale 与 1728 个 fc2 zero 潜变量，1000 次 Adam 更新，冻结 W4、bias/LN/LayerScale/SQ、Neck/Head。训练使用 1024 张无标签 ADE train 图，另 64 张 train 留出图选择快照。它是 scale+zero 联合参考，不能冒充早期 scale-only 训练的日志。[D2]

在该报告的 **ADE128、236 窗**上，Q0 为 8.8118 mIoU，联合参考为 30.9185；仅换入参考 scale、保留原 zero 为 28.6993；仅换入参考 zero、保留原 scale 为 9.7226。这些是同一联合优化解的参数交换，**不是分别训练的 scale-only / zero-only 方法**。该 128 图来自已排序历史子集前缀，不能外推为完整 ADE2000 成绩。[D2]

→ 对 agent 的启发：先明确参考允许改变的自由度、硬量化状态和问题，保留原始起点；从“存在一个较好状态”开始研究，不把 oracle 输出直接当正式 training-free 方案。

## 从参数模式到功能假设

联合参考在许多位点把 patch 的相对 scale 调小，而 CLS/storage 更接近原始倍率。跨 12 层的中位数例子如下；表中值是相对 Q0 的倍率，不能解读为绝对 scale。[D2]

| 位点 | CLS | storage | patch |
| --- | ---: | ---: | ---: |
| QKV 输入 | 0.991 | 0.965 | 0.738 |
| Q | 1.079 | 0.969 | 0.841 |
| fc1 输入 | 0.935 | 0.934 | 0.745 |
| fc2 输入 | 0.971 | 0.945 | 0.779 |

这支持按 token 类型、算子、深度和组研究校准偏好；并不意味着所有特殊 token 都应放大到大于 1，也不意味着 patch 永远应缩小。P-log 的 top 与 uniform 步长语义不同，不能合并平均。

后续在 **ADE512、943 窗**上做参数组交换与数值诊断：Q0=10.2203，联合参考 L=38.1063，仅换参考 scale=37.2788，仅换参考 zero=12.3383。patch 与核心 QKV/QK/MLP 参数集合承载了较大条件收益；但增益比不可相加为因果份额，交换也不代表这些子集独立优化后的能力。L 相比仅 scale 多 0.8275 pp，其同时区间跨零，不能据此断言 zero 无用或强正协同。[D3]

研究把“步长变化”进一步连接到 rounding、clipping、固定 W4 投影和真实后缀响应。一个待检验解释是：原共享选择使某些 patch 组分辨率过粗，参考解重新分配范围与内部格点，改变任务敏感误差方向。仅观察 scale 缩小、异常值减少或归零比例下降都不能完成该解释。

→ 对 agent 的启发：统计结构给出候选假设；参数交换与功能观察判断结构是否有用。看到相关性后选择最能区分解释的对照，避免把分布图直接翻译为算法结论。

## 拆开候选覆盖与选择能力

原实现已经存在 token 类型和通道组的独立 scale，但搜索时某些单元共用一个倍率，Q/K 也存在共享限制。这是**当前实现的候选约束**，不能推广成全部 PTQ 方法的共同缺陷。[D3, D4]

2026-10-16 的研究先问：问题是倍率范围、网格太稀，还是共享自由度不足？576 个核心 uniform patch 组中，574 个参考倍率仍落在原连续区间 [0.4,1]。把网格从 4 点加密到 13 点显著改善参数接近程度，但对应的功能投影并没有得到明确收益。[D4]

| Oracle 投影状态 | 同一 ADE512 mIoU |
| --- | ---: |
| site 共享倍率投影 | 23.0279 |
| token 类型共享倍率投影 | 26.7619 |
| 逐组 4 点网格投影 | 37.0625 |
| 逐组 13 点网格投影 | 37.0420 |
| 联合训练参考 L | 38.1063 |

**边界。** 这些投影按与训练答案的距离选参数；fc2/P/RGB 保留 L。它们说明给定四点候选能容纳一个很有用的状态，不说明部署时能自行找到它；较差共享投影也不证明任何低维算法都不可能更好。解除共享同时涉及多个因素，不能把全部收益只归给 token 分组。13 点未显示更好，也不是两者严格等效的证明。[D4]

随后研究最简单的独立选择：在真实 Q0 输入上，对各组从同样四点中选择局部编码 NMSE 最小者。平均 NMSE 从 0.06305 降到 0.03509，低于 oracle 投影的 0.05640；任务表现却只有 **20.6014 mIoU**，明显低于 oracle 四点的 37.0625。该比较其余 fc2/P/RGB 仍用 L，因此不是完整独立 PTQ 成果。[D4]

这反证的是“固定 Q0 输入上的可分局部选择，联合装入即可充分恢复”这一具体方案。它同时可能受指标排序、联合输入漂移与组间耦合影响，不能把全部差距单独归因给 NMSE。

→ 对 agent 的启发：分别问候选是否容纳好状态、代理是否能选中、条件选择能否组合成完整模型。候选存在后仍盲目加密网格，可能只把错误目标优化得更好。

## 让指标看见真实量化传播

为隔离选择器，研究对全 12 个 block 的 24 个残差单元各构造原/训练编码器的四组合，在相同候选池上比较评分；16 张发现图选择、16 张确认图测量后缀表现。它们是局部反事实，不能把 24 次最佳选择直接拼成已测完整模型。[D4]

| 发现集选择准则 | 确认集表征 regret，越小越好 |
| --- | ---: |
| 条件局部 NMSE | 0.0017214 |
| A4-STE 梯度平方加权 | 0.0054895 |
| A32 前瞻 4 个残差单元 | 0.0046899 |
| A4 前瞻 2 个残差单元 | 0.0002930 |
| A4 前瞻 4 个残差单元 | 0.0000208 |
| 完整 A4 后缀四 tap 表征 | 0.0000080 |
| 完整 A4 后缀任务 KL | 0.0015381 |

这里的 regret 相对于该单元确认集四候选中的最佳值，不是全局 PTQ 最优差距。同深度 A4/A32 的比较说明，保留真实后续激活量化在该条件下有价值；不是“只要多看几层 FP 就等价”。某些梯度平方代理没有帮助，也没有据此宣称完整 PTQ4ViT 方法失效。[D4]

一个具体反例来自 Block3 MLP：只换 fc1 使后缀 KL 从 3.18808 恶化到 3.40146；只换 fc2 为 2.36849；联合换为 2.26906。局部条件 NMSE 和本地梯度平方仍偏好 fc1，A4 h=2/4 偏好联合。研究报告全部 24 个单元，避免只对一个反例定制规则。[D4]

完整任务 KL 也不天然可靠：在这次小样本选择中，发现/确认集同选只有 7/24 个单元，而四 tap 表征为 23/24。更接近最终输出的目标可能更贵也更不稳定，前瞻深度和特征边界需要结合选择泛化判断。[D4]

→ 对 agent 的启发：metric 应包含输入、参考、观察边界、实际后缀精度、h 单位和聚合方式。评价一个目标能否选对方案，比给它一个复杂名称更重要。

## 复杂指标失败后如何转向

研究提出过“近程真实 A4 响应 + 远程 STE 代理”的有符号新准则，锁定 h=0/2/4 后检验。它没有可靠优于简单 A4 lookahead，表征选择还更差，于是停止扩展，没有继续堆系数。[D4]

另一次尝试从 clipping/必然归零的局部能量界缩窄搜索。它在关键组只排除了约 3.3% 的 61 点，而且实际已经计算所有点，不能宣传校准加速。fc2 的问题还包含 scale/zero 的配对候选缺口；P 的部分 top 原本为 0，纯乘法无法开启正值。加密同一倍率网格不能解决这些结构问题。[D4]

这些负结果影响了下一步选择：保留少量有意义候选，把工作集中在当前量化前缀、真实 A4 响应、前向分组与有限联合提案上。失败没有被改写为成功故事，也没有变成“所有梯度方法、所有复杂指标都不好”的定律。

## 独立前向分组的正式实验

2026-10-20 的正式报告提供了更强的衔接证据：三项新实验都独立从原 Q0 开始，不读取 L/STE 的逐坐标倍率或组标签；同一个最终 checkpoint 完成 ADE2000 与 ImageNet50000。[D5]

历史算法 **B** 在此仅是该人工研究的对照名称，不能与 QAViT 当前运行的 B 身份直接混用。E1 更改倍率策略并加预算；E2 改 storage 分组及预算；E3 改为实际前向残差响应分组。结果如下：[D5]

| 算法 | ADE2000 mIoU | ImageNet50000 Top-1 | 关键区别 |
| --- | ---: | ---: | --- |
| 历史 B | 30.568030 | 62.130% | 每类两组、原搜索策略 |
| E1 | 30.143497 | 61.750% | B 的连续成员、新倍率策略与更大预算 |
| E2 | 30.097159 | 62.998% | storage 2→3 组的预定分支 |
| E3 | 33.019808 | 65.002% | 真实当前残差响应分组 |

**E3 如何把参考启发变成独立规则。** 在每个位点固定当前 Q 前缀和该位点 Q0，用少量粗倍率构造各原生坐标的真实残差响应；每种 token 类型选择两个代表，按实际响应代价分配成员，不要求等人数，不重排通道，再用共享组倍率搜索。粗代表来自 {0.2,0.6,1,1.4}；252 个类型分组中有 246 个不同于原连续成员，6 个按记录原因回退。最终组倍率可以离开初始代表，组标签并不是一个固定大小次序。[D5]

**搜索与评分。** 新搜索采用统一初始化、粗点与几何补点、有限真实联合提案及后续按预算回访；scale 相对固定 `base_original`，完整 Q0 作为独立候选，fc2 zero 按原负范围联动。评分沿真实 A4 路径，h=2 明确指当前残差单元之后的两个残差单元，保留末端 LN；CLS/storage/patch 权重为 0.1/0.1/0.8。校准使用 ADE64+ImageNet64 无标签 train 清单，源/图像/图内窗口等权；这些是那次实现，**不是本包建议的普适默认参数**。[D5]

**必要的研究诚实性。** E3 与 E1 都有 6048 个实际全局去重正式配置，但 E3 另付出响应构建成本；同配置预算不等于同总成本。报告记录 E3 搜索约 2.445 小时，响应约 2.027 小时、4.054 GPU 小时。E1 的更多局部改善并没有转成双任务改善。E2 使用了 E1 正式有标签成绩决定预定候选家族，需披露这种方法选择；历史分类 head 曾用 ImageNet 验证集部分图像选 epoch，所以这 50k 不是相对整个历史开发过程的纯盲测。[D5]

这次实验固定 W4、SQ、P/RGB、head 与码域，采用 FP32 hard fake quant，没有反向或训练。它给出了“从参考提出结构 → 不读参考答案的前向规则 → 完整任务验证”的实际路径，同时留下计算成本、迁移与历史开发数据的边界。[D5]

## 两轮校准的后续汇报

2026-10-22 的汇报进一步描述了一种可变组数的两轮结构：[D1]

1. 逐层、同位点对各已有 scale 试粗倍率 {0.2,0.4,0.6,1.0,1.4}；在三类 token 内分别把粗搜选择相同倍率的 scale 分组。
2. 按第一轮分组和最佳区域细搜，例如粗选 0.4 后试 {0.3,0.4,0.5}。

汇报以 DINOv3-B 的同 W4A32 起点描述，表中 FP 为 ImageNet 79.13、ADE 52.86；原 W4A4 为 40.22、11.10；两轮校准为 **64.99、34.51**。这是作者汇报的历史结果，本次没有重新运行。该页没有单独列明 seed、完整样本清单及最终选用 metric/h，因此不能把前一报告的全部实现细节自动填到这一版本中。[D1]

这与 E3 都利用前向响应和分组思想，但粗点、组数规则和细搜方式不同。历史里尝试过多种设计，不能将四点两代表规则与五点同选分组写成一个唯一固定算法；也不把 E3 与后续汇报的差异全部归因给某一改动。

## 可迁移的研究方式与边界

| 可复用能力 | 这条路线如何体现 | 不应固化的东西 |
| --- | --- | --- |
| 找到可行参考 | 在受限参数族内观察较好解 | 必须先训练、固定训练步数、把参考视为上界 |
| 从统计到机制 | 比较类型/组模式，配合交换与实际功能 | patch 永远缩小、所有大值都不重要 |
| 分离搜索问题 | 分别检验表达、候选、排序和组合 | 网格越密越好、最近参考参数即可最终使用 |
| 设计功能目标 | 在同池比较真实 A4 后缀与简单局部目标 | 固定 h=2/4、固定 token 权重、梯度必胜 |
| 产生独立算法 | 从初态按前向响应生成组与参数 | 继承 oracle 的逐实例答案，再称 training-free |
| 让负结果影响决策 | 停掉不可靠复杂准则和无实测加速的剪枝 | 所有失败都解释为工程或预算不足 |
| 评价完整方案 | 同一最终状态测双任务与实际成本 | 局部 loss 改善就是任务收益、配置数就是总成本 |

QAViT 可以从这些决策中任一处进入，亦可由理论不变量、文献机制或完整现成方案开始；这不是必须重演的研究剧本。未来发表时，可以把它作为专家科研路线的示范与 agent 行为评价素材，但不能把专家结果写成 QAViT 自主取得的成果。是否帮助 agent 形成新方法，需要接入后的真实对照研究证明。
