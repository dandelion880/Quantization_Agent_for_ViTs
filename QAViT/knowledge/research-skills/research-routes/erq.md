# ERQ 路线案例：用误差分解研究权重与激活的耦合

**用途**：当 W4A32 和 W32A4 的诊断不能解释 W4A4；或激活补偿后权重更难量化；或插件组合收益不稳定时参考。优先关联“诊断量化失败”“判别性实验设计”“改造量化方法”。

**版本边界**：本案例依据 ICML 2024 的 ERQ。后续同作者论文题名与方法扩展有所变化，不把扩展版机制或成绩混入此版本。

**证据性质**：第 1 节重构公开论证；其余为 QAViT 的独立研究设计，不是论文作者的历史实验记录。

## 1. 已核对的公开论证

公开逻辑是：权重与激活一起量化时，输出误差由二者共同决定（Eq. 4），独立处理难以直接求解这一耦合目标。因此 §4 将问题拆为顺序修正：Aqer 暂保浮点权重，用 Ridge Regression 调整权重以补偿激活误差；Wqer 随后量化权重，通过 rounding refinement 及剩余权重的 Ridge 补偿继续减小误差。

Table 4 分别开关 Aqer、Wqer 中的 rounding 与 Ridge，检验各项及组合收益，而非仅比较整套方法。§6 指出该框架主要处理含权重的层，量化 self-attention 仍有改进空间。上述是论文设置的证据，不能直接外推到当前 QAViT。

来源：[ICML 2024 正式信息](https://proceedings.mlr.press/v235/zhong24a.html)；[原文 PDF，§4.1–4.2、Eq. 4–8、Table 4、§6](https://openreview.net/pdf?id=jKUWlgra9b)。

## 2. 从隔离诊断转向交互诊断

W-only 与 A-only 对照可以定位问题，但二者误差不应简单相加。建议在同一输入和参考上观察：只有权重被量化、只有激活被量化、两者一起量化，以及一个有明确机制的联合修正。前三者是诊断状态，最终交付仍需回到 static W4A4。

如果 A-only 好而 W4A4 差，可能是二者相互放大，也可能只是使用了不同的激活校准状态。先把输入与参数版本对齐，再解释耦合。

## 3. 数学视角：误差项与一个可检查的闭式问题

令 \(\widehat W=W+\Delta W\)、\(\widehat X=X+\Delta X\)。基本代数给出：

\[
\widehat W\widehat X-WX
=W\Delta X+\Delta W X+\Delta W\Delta X.
\]

这说明独立误差大小不能决定联合输出误差。为研究一次 activation-aware 的权重修正，可用以下教学问题；它与论文 Aqer 的目标同类，但这里使用统一矩阵记号，不复刻论文全部更新算法：

\[
D^*=\arg\min_D\frac1N\|(W+D)X_q-WX_f\|_F^2+\lambda\|D\|_F^2.
\]

直接求导可得：

\[
D^*=(WX_f-WX_q)X_q^\top\left(X_qX_q^\top+N\lambda I\right)^{-1}.
\]

实现宜用线性求解并验证维度与残差，而非显式求逆。这里的 \(N\lambda\) 来自目标采用均值；若使用误差总和，正则项尺度会变化。由此可见，原样迁移一个正则化数值没有充分依据。

## 4. 需要区分的三个假设

| 假设 | 最有信息的观察 | 后续可能选择 |
| --- | --- | --- |
| 激活误差可由有限权重调整补偿 | 独立样本输出误差随适度正则修正下降 | 检查修正后权重量化是否仍保留收益 |
| 补偿导致权重范围恶化 | 修正前后权重分位数、量化误差和组合输出变化 | 调节正则、分组或补偿强度 |
| 相邻步骤破坏前一步优化 | 冻结激活时有益，重校准或组合后消失 | 比较操作顺序和一次必要的再校准 |

不要把每个假设都变成全网大实验。在一个有代表性、可复查的位点先辨别方向，得到信号后再扩大。

## 5. 有解释力的对照设计

基础比较可为“当前方案”“只增加激活误差补偿”“只改变权重处理”“组合”。若预算不足，先比较当前方案与最有机制依据的一臂。关键是对照拥有相同数据、相同最终位宽、相同输入来源，以及合理匹配的参数搜索机会。

对正则化采用少量有尺度意义的候选，记录 \(\|D\|\)、输出误差、权重范围与后续 W4 重建表现。若补偿在浮点权重下很好、回到 W4 后消失，这正是机制信息，不应仅保存最漂亮的中间误差。

闭式修正并不自动保证优于已有求解器；应将其视为一个明确可检验的候选。上述候选可用闭式求解及离散校准实现，不依赖梯度微调；如另设训练得到的 oracle 诊断参照，应与候选本身分开记录和解释。

## 6. 完整研究片段示例：假想，不是实测

一个 FC2 位点的 A4 误差较大，研究者提出用权重补偿恢复输出。初次闭式修正改善校准误差，但最终 W4A4 没有收益。进一步观察发现修正后的权重范围明显扩大。研究者据此比较更强正则与较小分组，并让未修正对照获得相同的 scale 重搜机会。如果某一修正在独立样本和最终 W4A4 都有效，可暂时支持“受约束联合补偿”；如果只有校准集有效，则应缩小策略的可信范围。

## 7. 不宜机械迁移的地方

- 有可更新权重的 Linear 与 \(QK^T\)、\(PV\) 这类运行时激活矩阵乘法不同。不能把对权重矩阵的更新规则直接套到每次输入生成的激活上，并称为静态方法。
- 偏置、分组、输入统计、样本数量和 token 数都会改变修正尺度。比较正则值时应先统一归一化约定。
- 只证明局部误差可降低，尚不能证明分类和分割都会改善；在两任务冲突时保留真实结果及当前项目的选择规则。
- 如果前缀漂移显著，需结合 GPTAQ 路线澄清 \(X_f\) 与 \(X_q\)，避免将当前层激活误差与前层传播混为一谈。

**可迁移策略**：把联合量化看作耦合问题；在每次修正后追踪误差去了哪里，并始终检查修正能否在最终低比特表示中保留下来。
