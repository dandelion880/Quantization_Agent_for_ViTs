# gate-fp-block-headroom-to-static-ptq

适用于能冷载同一量化父包、在当前 Q 输入上做单块替换且能区分任务读取路径的模型。结论限于诊断背景和样本。

先核对不重校准的父包配对及当前 Q 输入，分别报告边界分组和端点响应；若总误差与任务相关分组冲突，不按总误差淘汰，并检查有符号交叉项而不是相加误差贡献。用等预算、同类合法改动和恒等臂比较优先位置与竞争位置；冷载不复现恒等则先判执行无效。若在独立于拟合的图上两条任务相关路径均改善，升级为同一冻结包的双任务评测；若两位置互补，再测联合臂；若仅局部改善，优先检查可调范围或上游输入，不扩大同一网格。

## 反例与边界

FP 替换同时取消块内多处误差，或改变与上游误差的抵消，单码器可能完全不能复现；分类输入上的 patch 误差不是分割结果；同次多臂不是复现。
