# QAViT V2 当前科研流程伪代码（2026-11-03）

输入：ResearchBrief、明确模型/数据资产、科研约束、实验协议、运行资源和预算。
持久状态：不可变 Journal/卡片、任务队列、预算账本；Memory/目录可由事实重建。

```text
初始化或恢复运行：
    核验配置、源码身份、提交链与冻结资产；不重置预算
    接收已完成 worker 回执，重建队列、证据与 Memory

在原截止时间、调用额度与资源约束内：
    Generation 从 Brief、任务绑定的前轮反馈、相关证据生成 H1/H2/H3
        H1：已有方法；H2：工程改进；H3：新机制
        科研正文说明问题、机制、可证伪预测和有区分力的实验
        程序补任务身份/预测编号/引用，不代写科研判断
    Judger 筛查约束与科学可比性；证据不足本身不构成硬性淘汰

    按顺序进行 H1–H2、H1–H3、H2–H3：
        不合格配对由程序记录 ineligible
        每场最多 5 次交锋：
            A、B 分别生成立场；本 exchange 对方私有材料隔离
            回应对方最强论据，说明机制、控制变量与证据局限
            Judger 获取双方已汇合立场及合法可见实测
            可主动请求能够改变判断的低成本实验
            证据足够则 A/B/tie；仍可推进则 continue；理由充分可 undetermined
            提交终局 verdict 后立即 match_closed；后到证据不能改判
        下一场只在本场结案后发布

    初始选择：依据三场直接结果固定 H*
        明确全胜/唯一合格/全部不合格由程序复用已有裁决
        未决才由 Judger 给出有依据的暂定选择
    若存在合格 H*：
        Evolution 只根据固定父版本、批评及证据形成 H4
        筛查 H4；只比较 H4–H*；最终只从这二者选择
    最终选择写入 L1，并按配置申请 L3

    Recorder：
        程序冻结尚未综合的完整来源版本；原始事实早已在 Journal
        交付假设、实测、裁决/选择/解释、工程失败摘要和按需原件入口
        LLM 提交科学分析、下一轮建议、未决问题
        可选提交有条件的知识、重点判断分析、指标适用性与盲点
        程序绑定所有 source_refs、解析短引用、核验 Evidence 和知识范围
        成功：原子发布 Meta + L1/L2/L3 投影 + 批次完成事件 + TaskCard
        非关键失败：沿既有两次修复；耗尽后标记 scientific_review=pending
            不伪造 Meta，不推进科学综合游标
            下一轮获复盘缺口与原始事实；下一批自动合并未综合来源
    记录 round_finished；进入下一轮或收尾

收尾：
    在剩余原预算内处理迟到增量；同一失败批次不无限自动重试
    硬预算截止只持久化待办，不额外启动模型或实验
    分别报告 workflow_completed / scientific_review_complete / formal_validation_success
```

实验子流程复用现有入口：

```text
request_experiment(科学问题、预测、控制条件、测量、判断影响、科学执行参数、时间上限)
    程序：校验可见来源、展开显式 modules、补资源/接口/一致性镜像
    按请求者沿现有科学审批路径冻结完整 ExperimentCard
    已有方法：直接调用 profile / tensor_probe / quantize_evaluate / evaluate_artifact
    新方法：Coding → 独立 Reference → 实际数值/接口验证 → Safeguard 三项审查
        原冻结定义、文件隔离、修订次数和独立性不变
    工作进程核验冻结合同/模型/数据/覆盖/结果；完整模型导出、重载、评测
    程序生成 Evidence 与原始资产哈希；有效缓存不计独立重复
    原 Judger 主动请求：直接返回原任务，在原判断中解释证据
    其他原有路径：保留独立 Judger interpretation
```

L0 保存全部事实；L1 保存当前科研状态；L2 保存带范围和版本的知识；L3 保存科研综合。目录、短引用和按需读取借鉴 MemFS；卡片/资产权限、必需长正文完整交付、证据时序和数值正确性依旧由程序保障。
