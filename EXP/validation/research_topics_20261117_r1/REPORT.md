# 动态研究主题与研究范围

已在现有 gonly、独立灵感库、完整方案库和 Memory 上接通运行链。主题是“研究问题＋可修改范围”，由 Generation 决定；不修改冻结 ResearchBrief、量化约束、评价协议或晋升标准。

## 实现

- `core/topics.py` 使用原 Journal 保存主题版本、决定引用、稳定研究动作及复议条件。继续、缩小、扩大、暂停、恢复、切换都保留旧版本；未完成动作跨轮恢复，明确更新的问题清单可反映问题已解决。没有科学评分、固定轮数淘汰或新的完整方案存储。
- `workflow.py` 在新轮 H1/H2/H3 前增加一次共用 Generation `focus`。先交付上次决定、关联灵感/方法、关键证据、原实现与配置入口、未完成动作及用户输入，再决定本轮方向。默认交付短状态和最近引用，完整原件按需读取。共同决定消耗原 LLM/时间预算，不增加候选槽位。
- `interaction.py`、`experiment_requests.py` 将 `topic_ref`、`method_id`、候选版本接到原请求、代码、配置、结果及 Coding 接续链。`read_topic` / `read_method` 可找到准确原件；无主题方法的原代码也能授权读取。轮中 `revise_topic` 必须声明影响槽位与理由，旧候选及其 L3 归属不变。发布前后中断均复用原决定，不能借恢复替换正文。
- 主题、灵感、方法谱系、候选版本分别维护。切换主题不自动暂停灵感或重建算法；同算法可沿用 `method_id`，派生记录父方法/完整父方案。H3 单活跃灵感、H1/H2 各自完整父方案上的实质增量与回退、独立全局 B、三个最终候选全部 L3、双任务评价和 ADE20K Top-3 规则保持有效。候选优先一卡并行、Coding 串行及预算口径未改。
- 同步角色/任务提示词、工具合同、Recorder `topic_notes`、恢复权限、导航及生命周期说明。Recorder 只整理进展、条件与来源；主题投入与目标改变仍由 Generation 决定。允许把已有收益转为解释、必要性检验或简化，相关进展与正式性能提升分开记录。

## 针对性验证

状态测试覆盖首轮选题与三候选共同绑定、缩放/暂停/切换后恢复、未完成动作及复议更新、灵感和方法跨主题连续性、旧候选归属、暂停后仍规划三个 L3、冻结读取、角色权限、旧无主题状态、原件授权和重启幂等（含卡片写出后、Journal 提交前中断）。全部是脚本状态夹具，测试中的排名与指标不是新实测。

主回归 67 项通过；扩展回归首次 139 项中有 5 项失败：3 项旧夹具假定没有共同选题步骤，已适配并复测；2 项在并行真实回放期间受订阅锁/时序影响，隔离复测通过，未放宽阈值或修改预算实现。收尾来源/状态专项 26 项、中断恢复及队列/候选/Recorder 专项 45 项，以及最后方法归属修复后的主题专项 10 项通过；重复测试不累计为新增覆盖。知识导航、29 个变更 Python 文件的语法和 `git diff --check` 通过。完整批次和修复记录见 [RESULTS.json](RESULTS.json)。

真实 Generation 回放使用原订阅通道，配置 `gpt-6-astra/high`；服务端未回显实际模型/effort，记录为未知。三个隔离情境均先读取确切源码和原 ExperimentCard，再作共同决定：

| 情境 | 实际观察 | 输入 token | 输出 token | 端到端延迟 |
|---|---|---:|---:|---:|
| 未提升但有可验证下一步 | 保留灵感，收窄到干预是否生效及配对误差检查；不按低分终止 | 45,483 | 1,843 | 90.32 s |
| 新条件要求调整方向 | 扩大至有效候选/干预位置，暂存旧动作，给出重新收窄或转向的条件 | 45,848 | 2,058 | 93.22 s |
| 已有收益但来源不清 | 转向组件必要性、配对撤除与简化；不把复杂度进展当正式增益 | 46,303 | 1,928 | 90.44 s |

每个情境为 2 次真实模型调用（读取原件后提交），合计输入 137,634、输出 5,829 token；其中缓存输入 8,448 已包含在输入内，推理 token 已包含在输出内，不重复相加。这是新增共同选题阶段的实测开销，**不是**旧/新完整流程的净增量对照。中断恢复修复后另复放一次未提升情境，通过：2 次调用、输入 45,769 / 输出 1,939 token、95.04 s，仍先读原件再给出条件化下一步；费用与结果在 RESULTS 单列。此后仅补充“显式绑定其他 method_id 的对照请求不得归入新方法”的身份隔离及对应状态测试；提示词未变，未重复付费回放。各回放源码哈希及与交付版的差异均保留在 RESULTS。

证据分层：上轮主题、灵感、方法和恒等占位源码为明确脚本夹具；三种新增观察是假想条件；只读历史 ImageNet/ADE 数值附原文件路径、哈希和来源，不作为当前受控对照；方向决定与读取行为是真实 LLM 输出。模型均识别出原代码没有实际量化干预，保留“未实现/未测”的限制，没有将占位源码称为已验证算法。评价依据是恢复、证据条件、下一步及复议点，而非某个唯一选题标签。所有回放均未启动数值 worker、未产生新 Evidence。

复现入口：[replay.py](replay.py)；使用新的 `--attempt`，避免覆盖已有产物。最新流程：[PSEUDOCODE.md](PSEUDOCODE.md)。

## 剩余限制

没有启动高成本完整贯通、GPU/双任务正式评测、真实组件消融或长周期研究，不能据此宣称科研精度提高。真实回放只有少量受控情境，且占位源码影响了方向判断；尚未验证长期主题管理质量及完整流程净成本。源码/配置/历史结果未被迁移或回写；旧运行缺少主题时保留未知，已有源码变更恢复仍须原有显式 intervention。方法是否连续、下一步是否值得投入由 Generation 判断，宿主仅校验身份和保存事实。
