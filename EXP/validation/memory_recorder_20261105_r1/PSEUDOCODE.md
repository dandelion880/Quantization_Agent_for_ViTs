# 当前 QAViT 科研流程（2026-11-05）

```text
Supervisor / 程序调度：
  建立 ResearchBrief、身份快照、资源与预算、Journal
  for 每个已授权科研轮次：
    Generation 自主形成 H1、H2、H3，各自可在形成假设前反复申请实验
    Judger 筛查，依次完成 H1–H2、H1–H3、H2–H3 辩论；已结案不改判
    按既定规则选择并保存 H*
    Evolution 围绕 H* 自主研究并形成 H4，保留原研究者实验循环
    筛查 H4，完成唯一 H4–H* 父子挑战与最终选择
    如本次启用 L3：计划并执行实际评测、导出与重载核验
    Recorder 在原轮次边界同步复盘；仅工程补记无新增科学材料时跳过模型调用；失败保留pending并继续

request_experiment(原研究者, 科学问题, 需要的测量, 可选科学条件)：
  先核对已经给出的字段结构、镜像及已知授权/资源/阶段冲突
  格式问题只回原提交任务修必要字段；无坏请求或无效 Coding 子任务
  保存未经改写的原始提交；补齐确定性默认，检查明确冲突
  L1/L2 按本次干预绑定；L3 绑定最终候选条件；观察整网不等于干预整网
  不消耗数据的能力查询、权重统计、浮点对照不虚构校准
  位点目录等尚未就绪时，延后相应事实核验到 worker
  if 已有服务可直接执行：
    程序绑定完整执行记录
  else：
    保存不可变请求，交 Coding（原始需求、Brief、已知资源/接口条件）
    Coding 交付唯一源码及必要执行选择
    程序检查语法、接口与资源；按原对象/对象数组位置补缺执行选择
    已给值与数组长度不可改，原始需求不变；绑定代码版本/执行记录
    Safeguard 直接审查原始需求、源码、实际执行条件
    程序把批准绑定到请求哈希、执行记录哈希、源码哈希和宿主版本
  核验当前身份与批准（新增代码时），执行或使用精确匹配且可见的真实缓存
  内置执行器按其原生能力执行；自定义源码使用自身方法/observer/参数
  程序校验实际数据、原 FP 状态、结果有效性和适用的 L3 导出重载条件
  只读梯度可用于诊断；禁止未授权的优化器更新并记录真实调用
  保存原始回执、完整统计、实际范围、Evidence
  把结果直接交回等待中的原研究者；无等待者的独立 L3 沿用原解释流程

局部失败处理：
  可确定的缺失 -> 程序补齐；明确冲突 -> 返回具体字段
  实现错误（按实际源码调用栈归属，含 NameError/UnboundLocalError）
    -> 当前源码及具体反馈交 Coding 修订，重新绑定/审查
  源码和执行选择均未变化 -> 拒绝重复运行已失败实现
  真实科学歧义 -> 返回原研究者；宿主/资源故障 -> 保存工程失败
  JSON/字段格式错误 -> 同任务 repair_patch 修必要字段，保留其余科学推理

模型提交：
  先补齐确定性身份和字段，再核对实质科学决定及明确冲突
  可选分析逐条校验；坏条目保存 submission_issues，其余科学产出可提交
  历史分页交付记录仍保留；未读完不阻塞提交，不伪称已读
  证据权限、来源身份与固定 H* 关系继续检查

Recorder：
  读取既定批次，提交科学分析、建议及可选知识更新
  对每条更新：
    从真实 Evidence 补齐来源与 scope，绑定现有知识版本
    不同条件按 Evidence 分别绑定 scope.comparison，保留差异与限制；不合并成共同范围
    沿 claim_id / supersedes 修订或明确 abandoned；当前pending只呈现仍未处理项
    若有效 -> 加入本次有效更新
    若冲突/缺少科学信息/证据不适用 -> 保存原条目、索引和具体问题为待核实
  原子保存科学复盘及有效知识更新
  L1 的实际假说/实验/证据来自 Journal；Recorder 引用子集不能覆盖
  next_questions增量新增；省略不清空；resolved/abandoned_questions明确关闭
  原始事实持续可读；分别呈现事实归档、科学复盘与知识待核实状态
```

新流程没有 Reference 角色任务、双实现数值对照任务或替代性通用验证层。浮点基准、算法基线和真实误差测量继续保留。

```text
模型输入组装（程序，无额外LLM）：
  按角色、任务及提交快照过滤可见来源
  交付当前研究状态、活跃问题/研究笔记、相关本次结果与实际条件
  大型统计投影也受展示量控制，保留覆盖/反证提示及精确展开入口
  旧工具正文和历史交锋转短记录；完整原件继续 read_card/read_asset
  retrieve_memory 默认返回可用短正文，可省略query；精确条件不模糊回退
  方法库直接 read_asset，无需实验链
  展示预算与按需读取不构成科学提交门禁
```
