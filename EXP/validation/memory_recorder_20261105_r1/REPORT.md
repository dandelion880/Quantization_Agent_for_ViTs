# Memory 与 Recorder 优化（2026-11-05）

本轮在工作区已有实现上完成增量修改，保留七角色、Generation/Evolution 自主实验、既定讨论与 H*→H4、单实现 Coding→Safeguard→执行链、四层 Memory 和 Journal。没有新增审批、科研必填字段、阅读确认、知识晋级或模型摘要流程。

## 实现与信息流

- 检索：默认/空查询返回程序整理的短正文、结果、实际条件、状态、限制及精确读取入口；精确条件仍精确匹配。方法资料沿用原文档库，可直接 read_asset。
- 交付：大型统计投影也受预算控制，保留全体统计的描述性含义、尾部极值、混合符号提醒与未展示覆盖；按位点/token/指标展开仍读取原始数据。完整源文件不变。旧工具正文随既有 research_note 转短记录；旧交锋的条件、争点、反证保留短正文和来源。有限的16项投影缓存避免同一不可变 Evidence 重复计算，不修改 Journal。
- L1：真实假说/实验/证据由 Journal 维护，Recorder 引用子集不覆盖事实列表。next_questions 增量添加，省略或空数组不清空；resolved_questions/abandoned_questions 可直接关闭问题。角色可见状态与问题/pending 分页均检查来源可见性。
- Recorder：轮次边界同步处理增量科学批次，输入集中于假说变化、实验目的与结果、关键争点和判断相关失败；知识更新可为空。只有成功工程补记不另启模型；科学失败和未完成综合仍保留待办，沿用延期与恢复。
- 知识：比较认识逐份绑定 Evidence.scope，显示差异与限制；不取首份范围、不合并条件，不把对照当独立重复。pending 使用现有 claim_id/supersedes 修正、发布或 abandoned，旧稿可追溯，当前待办退出已处理项。reviewed_refs 兼容忽略，不作为已审事实，不阻塞有效复盘。

```text
真实执行/研究提交 → 不可变 Journal → L1事实与问题变化
                         ↓
       程序按任务和ACL组装短正文/有界结果/研究笔记/精确来源
                         ↓
       原研究角色推理、解释与自主实验；需要时精确展开原件
                         ↓
       原轮次 Recorder 增量同步综合 → L3复盘 + L2知识修订
                         ↓
       下一轮获得当前状态、有效认识与仍未解决的问题
```

## 验证与开销

完整回归 **393项通过**（`regression_verified.log`）。最后两项目录/方法资料展示调整后，针对最终源码再跑 **64项通过**（`final_directory_verified.log`），覆盖检索工具、L1/pending/比较知识、长统计精确读取、跨轮 Generation/Evolution、ACL、失败继续、Coding→Safeguard→真实 CPU worker 的失败修订链。结构检查通过：142份Python文件、204份源码/资源；`git diff --check` 通过。

旧断言已同步为空查询可用、异质比较可保存、无科学材料不启动Recorder、有界统计仍可准确展开；未恢复已清理门禁。短正文不误切小数，旧rationale中的限制与展开后去重也有回归。

同一已有轨迹（4437个commit、3711张卡片）只读重建三个任务，每项组装3次取中位数；`history_before.json` 与 `history_after_verified.json` 保存完整数字。未计Journal启动加载时间。历史提交数保持4437。

Recorder 输入减少 **17.82%**，组装中位耗时减少 **22.49%**。Generation、position 输入略减，但组装分别增加约 **10.58% / 11.11%**，来自新增状态/结果交付等程序工作；本轮没有宣称所有路径都更快。首次调用与缓存续调有差别，三次样本只用于描述本机观察。

- 大型固定结果：184,767字符原件的默认投影由 **55,044 → 5,966字符（−89.16%）**；保留尾部矛盾值、样本数、限制与原件选择入口。投影冷组装 **57.98 → 70.66ms**，有所增加；续调复用最多16项不可变投影缓存。见 `projection_benchmark.json`。
- 同一小结果的脚本客户端取得目标指标：**2 → 1次宿主读取**，交付 **1,758 → 1,834字符**，本地处理中位 **0.95 → 1.91ms**。这是少一次目录导航往返，非实测少一次模型调用。见 `retrieval_comparison.json`。
- 成功工程补记场景实测新增 Recorder 任务 **0**；科学失败仍pending、显式重试及跨轮继续通过测试。不额外调用摘要模型，检索/投影的新增LLM调用为0。

Recorder批次仍约21万字符；大量科学材料的总规模与必要深读仍可能昂贵。本轮通过短字段、去重、可见状态和现有笔记减量，没有用硬截断或新审批追求降幅。


## 测量边界

没有调用真实 LLM，实际 input/output token、推理费用、模型延迟和端到端科研耗时均未测。字符数不是 token；脚本少一次读取不等于已经实测少一次模型调用。没有进行 ImageNet/ADE 长实验，不改变数据、checkpoint 或正式评测协议。短链测试中的脚本角色输出、合成数值和真实 CPU worker 分别按原测试身份记录。
