# QAViT 贯通前收尾与准备验证

基线为 `320f16e`，开始时工作区干净。本轮增量复用队列、预算账本、原数值执行器、逐图评测及分片汇总，未启动下一轮正式科研。原数据、权重、历史实验及冻结结果未改写。

完成的闭环：

- 移除数值并发固定 1、项目全局 numeric 锁、同 checkpoint 模型锁，以及把实验计入 LLM 总子进程槽的限制。非 Judger 保留共享单通道，Judger 最多三并发、同场互斥。新模板授权 0–4 共五卡，实验并发上限 5；历史显式串行配置仍有效。
- 未指定 GPU 时在实际启动时按授权集合分配；可固定主卡，可用 `gpu_count` 尽力申请实验内部多卡。忙卡等待，不领取尝试、不消耗重试次数、不发布科研失败。跨实验和跨运行共用文件租约，worker 和分片继承，释放以进程退出为准。分配同时检查持久队列，避免进程退出但回执尚未接收时领取失败。NVML 索引经 UUID 绑定 CUDA，再解析真实设备节点；本机 GPU 4 对应 `/dev/nvidia6`，不能直接拼 `/dev/nvidia4`。
- 实验内多卡只接入原生、非训练、纯分类的 `quantize_evaluate/evaluate_artifact`。prepare/校准/导出仍执行一次，分片重载同一冻结包、复用逐图前向和原汇总逻辑。校验候选/FP digest、包身份、样本无重复无遗漏，汇总正确计数及 FP64 误差累加器。分片仅获得已租用设备节点的必要写访问，Landlock 文件边界保持。
- 新运行模板明确启用 `budget.clock_mode=active_segments` 和 `exclude_numeric_wait=true`。纯数值执行、资源排队及等结果不计智能体时间；Coding/审核/推理重叠时照常计时，并行不重复扣减。数值 `estimated_seconds` 沿用单任务超时，不再与智能体余额比较。worker、Supervisor 收尾和外层监控共同遵守同一余额；预算不足时接收已启动实验，停止启动新科学工作。暂停/恢复保留消费，崩溃未知间隔保守计入。预算检查点写失败也不能阻止 worker 清理。
- 公共“最新发现”和数据校验回执不再自动灌入无关外场证据；自身结果、明确引用支持、原分支隔离和按需 Memory 读取保留。system_prompt 仍完整通过 CLI instructions 交付，stdin 不重复传输；审计保留完整语义请求。
- 真实 Coding 冒烟暴露既有缺参反馈逐项修复耗尽次数的问题；现在一次列出已有参数合同的全部缺项，不增字段要求、不猜科学选择。Generation/Evolution 自主循环、三场汇合后 H*、固定父子挑战、最终选择—L3—Recorder—下一轮及单实现返回链保持。

范围与实际限制：

- 仅上述原生分类路径启用实验内部多卡。局部 probe、Profiling、自定义 executor/custom_experiment、训练、ADE 或混合分类/分割继续单卡；这些实验仍可在不同卡间并行。本轮未验证分布式校准、训练、分割或所有算法的多卡能力，也未做性能加速结论。
- 本轮实测为预训练 DeiT + ImageNet 小样本，且只量化两个位点；不是全网 W4A4、50k ImageNet、完整 ADE、完整真实 L3，也没有启动两轮正式自主科研。真实 LLM 只用于有界代码服务，使用已验证 CLI 0.166.0 及原角色模型路由；服务端未回显实际 model/effort 的字段仍保留未知；全流程科研顺序、返回归属和 H* 约束主要由离线控制流回归证明。
- 同卡互斥与 LLM 3+1 槽跨 QAViT 运行共享；对外部程序读取 GPU 占用并等待，无法让不遵守租约的外部程序加入本项目锁协议。
- 分片原始 metrics/timing 保存，父 worker 的资源标量属于父进程；不把它当成全任务峰值显存或部署内核性能。五卡实际分片执行不等于五卡内核始终同时满负载。
- 最终源码身份见 `FINAL_SOURCE_IDENTITY.json`。五卡成功后调整 driver 的预算写失败清理次序并补测试；真实两卡中断恢复覆盖该清理版本。随后将缺参提示改为完整字段路径，44 项相关回归通过；补退出/接收之间的 GPU 排队竞态，并保留原非数值 worker 容量，37 项与最后 21 项针对性测试通过。数值库、分片、GPU 映射和隔离实现逐文件未变；各次真实执行均保存自身源码身份，不冒称同一哈希。
