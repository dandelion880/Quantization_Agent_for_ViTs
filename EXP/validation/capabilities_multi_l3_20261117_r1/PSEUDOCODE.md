```text
加载冻结 Brief、预算、允许 GPU 池、Journal、独立 B 和完整方案目录
为研究角色交付简短能力目录、实验速查及按需知识入口
每轮：
  H1/H2 从明确完整方案改良；H3 保留机制创新
  各 Generation 可 request_experiment：
    已有 profile / frozen_helper / 数值服务 → 原执行与来源核验
    新能力 → 串行 Coding 单实现 → Safeguard → 原数值执行
    Evidence 或明确失败 → 原研究者解释并继续
  等待候选提交或局部失败
  Generation 横向综合全部候选，按需取证与科学修订
    revise_candidate → 不可变新版本 → 重新绑定全部当前版本并综合
  对每个最终候选（H1/H2/H3）：
    分别绑定 selection_ref + slot + hypothesis_ref
    创建独立版本化 plan_l3 / L3 请求；逐分支推进，不早退阻塞兄弟
    GPU 租约先满足不同候选各一主卡；余卡用于受支持的内部并行
    校准一次 → 冻结/导出 → 同包重载 ImageNet + ADE20K
    个别失败沿对应请求修复或明确延期，其余候选继续
    每份有效 Evidence 独立返回、独立考虑方案库/B、幂等归档
  Recorder 综合各候选结果、失败、未完成项及 B 前后时点
  完成度按各候选协议分别统计，三者均通过才算本轮正式验证成功
恢复：
  由 Journal 重建版本、计划、请求、已接收 Evidence、库更新与复盘批次
  保留已消费预算；纯数值等待不计活跃预算，重叠推理/Coding 正常计时
  已完成结果不重测；部分完成不冒充全部完成
```

历史旧卡、引用及已完成轮次保留其当时语义。此伪代码说明当前实现；本次只进行回归与小样本验证，没有启动下一轮正式科研实验。
