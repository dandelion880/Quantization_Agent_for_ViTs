# 当前 QAViT 伪代码（自适应资源修复，2026-11-06）

```text
新研究输入：ResearchBrief、模型/评价协议、预算、runtime
    allowed_gpus=auto：CUDA 实际可见 UUID ∩ 容器/调度器分配
    显式 allowed_gpus：再取授权编号/UUID 交集；[] 保留 CPU 入口
    冻结允许池及 UUID/设备节点映射；experiment_concurrency 默认随池大小
    每个运行进程只解析一次身份，worker 仅看到所租 UUID 的逻辑 cuda:0
恢复：核对配置/源码；保留已消费预算、原请求/任务身份；按冻结 UUID 重新匹配当前设备

程序化 Supervisor 的受监控运行段：
    轮询任务：
        完整回执 -> 核对任务、执行、源码、请求身份
        仍有 worker/登记子进程 -> 保持 running 和资源占用，等待退出
        退出宽限到达 -> 仅清理已完成任务的自有进程，保留完整原回执
        全部进程退出 -> 幂等结算 -> 核验真实结果 -> Evidence 返回原请求者
        没有完整回执且失联 -> 沿原有界中断/重试逻辑；不发布部分结果

    更新智能体时间：
        纯数值执行/排队/等结果区间不计时
        推理、Coding、审核等重叠时计时，同一区间不重复计费
        数值 estimated_seconds 是自身超时，不要求小于智能体余额
        已启动数值任务不受旧总墙钟截止截断；人工停止与资源限制仍生效
        历史显式预算模式保持原口径；恢复不重置消费

    科研流程保持：
        Generation(H1/H2/H3)：自主读 Memory、申请实验、接收反馈、继续研究再提交
        Screening -> H1-H2、H1-H3、H2-H3 各自有序推进并结案
        自动交付自身结果/明确相关引用；其它共享 Memory 按需读取，分支隔离
        三场全部结束才选择并固定 H*
        Evolution 仅从固定 H* 产生 H4，仍可自主实验
        H4 Screening -> 仅 H4-H* 父子挑战 -> 最终选择 -> L3 -> Recorder -> 下一轮
        程序记录事实，Recorder 归纳；不增加 Reference、强制 interpret 或重复审核

    执行调度：
        非 Judger LLM 共用一个通道；Judger 最多三个，同场互斥
        Coding 单份实现 -> Safeguard -> 冻结执行 -> 真实 Evidence -> 原请求继续
        独立数值实验默认各一卡；CPU、单卡、自定义实现沿已有入口
        设备忙：保持排队，不领取尝试、不扣重试、不认定科学失败
        队列占用 + 按 UUID 的跨进程租约共同排除同卡竞争
        worker/分片继承租约；结果接收和资源释放以进程完全退出为边界

    仅在请求 gpu_count>1 且能力兼容时启用实验内部多卡：
        server 原生非训练 quantize_evaluate/evaluate_artifact，且纯 classification
        必需指标可由整数正确计数/FP64误差累加器汇总
        必需时延、显存或不确定的组合结果 schema -> 原单卡路径，保持全部协议
        空闲卡不足 -> 减卡/单卡；无空闲卡 -> 正常排队
        prepare/校准/导出一次；分片加载同一冻结包，核对模型/请求身份
        原逐图前向 -> 汇总累加器 -> 校验无重复/缺失样本 -> 恢复原顺序
        子进程完整结果可先收集，其退出仍由整个作业生命周期管理
        不捏造未采集的性能指标，不缩减样本或量化覆盖

暂停/终止：
    保存完整回执或真实中断原因，停止所有自有进程后结算运行段
    暂停不计入消费；未确认崩溃间隔沿原保守规则计时
    恢复沿原任务继续，不重复结算/发布结果，不扩大冻结授权
```

验证边界见 [REPORT.md](REPORT.md)；这里描述程序行为，不增加科研运行时验收步骤。
