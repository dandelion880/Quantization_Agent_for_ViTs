# QAViT V2 当前伪代码（2026-11-04）

唯一事实源：不可变 Journal/cards/commits。Supervisor 为程序调度器；没有新增 Agent、科研评分或状态协议。

```text
初始化/恢复：核验配置、源码身份、提交链；接收已落盘回执；保留绝对预算截止
for round in 原 max_rounds 内:
    分配 Generation H1=已有方法、H2=工程改进、H3=新机制
    对每个原 Generation 任务:
        repeat 在原预算内:
            程序构建固定 sequence 的 Brief + 任务 + 相关反馈 + 证据概览/目录
            LLM 分析问题、机制、已有证据与缺口
            可选择:
                读取卡片/原始字段、按 site/token_type/metric 查询、检索知识或文献
                提出实验(科学问题、关键科学参数、可选 research_note):
                    不要求已存在 H；没有 Judger 科学审批
                    调用下述实验子流程，等待其终态，回到同一个 Generation
                    LLM 自己解释成功测量/失败回执，再决定实验或修改/提交 H
                提交 H(机制、可证伪预测、验证设计、来源与实际采用的 evidence_refs)
                clarify 真正未解决的阻塞
            实验次数可为零或多次；禁止用请求/失败状态充当测量
        程序绑定 round/slot/type/引用，不替 LLM 编造科学论证

    每个正式 H 交 Judger 筛查；三个 H 均已提交并筛查后:
        依次 H1-H2 → H1-H3 → H2-H3
        每场最多五次交锋，同 exchange 双方及其子任务私有材料隔离
        Judger 可继续申请补充实验并直接解释；双方汇合后裁决
        终局提交 match_closed，下一场才发布；后到证据不改判
    依据三场直接结果固定 H* 完整版本
        明确既有胜负由程序复用；未决才由 Judger 科研选择
    若 H* 合格:
        Evolution 同样可以先实验/反馈/研究，再形成唯一 H4
        H4 的唯一父方案仍为已固定 H*；筛查并仅进行 H4-H* 挑战
    最终选择写 L1；按配置和原预算制定并执行 L3
    Recorder:
        程序绑定全部未综合来源，交付科学对象/证据概览和工程失败
        LLM 提炼科学分析、反馈、问题，可选有范围的 L2 知识
        程序校验来源、范围和独立重复，原子发布 Meta/L1-L3/批次完成
        失败耗尽或延期: 保留 pending，不伪造结论；下一轮交付缺口并合并旧来源
    记录 round_finished，进入下一轮
收尾: 原预算内处理迟到增量；硬停止只保存现场
报告分别标记流程完成、科学复盘完成、正式数值验证完成
```

```text
实验子流程(沿用 request_experiment/原队列):
    预检实际参数、接口、授权范围；程序补默认值与身份
    检查原预算并冻结 ExperimentCard；资源锁限制并发
    若需要新代码:
        Coding 实现 + Reference 独立依据冻结规格实现
        Reference 不得读候选、对方反馈或目录
        程序独立数值比较 → Safeguard 检查忠实性/数值/实验有效性
        拒绝最多两次实现修订，不能改冻结数学/容差/数据来绕过
        首次或修订需澄清规格时返回原申请人
    在申请人的交接时权限下寻找完全匹配、原件完整的缓存
        缓存不得泄漏同回合对方结果，不算独立重复
    若没有缓存: worker 真正执行/导出/重载/评测，程序核验数值回执及哈希
    成功: 程序追加 EvidenceCard/原件，原 Generation/Evolution/Judger 续调
    失败/请求预算不足: 返回真实错误；允许原任务重新设计，不产生成功 Evidence
    无等待判断任务的 L3 或 plan_l3 辅助实验: 保留独立 interpret
    已发布 interpret 仍完成一次；恢复不重复执行已完成任务
```

```text
上下文与 Memory:
    一次宿主操作内复用已校验卡片，文件签名变化立即重验，结束即释放
    索引先过滤元数据；无关键词不解析巨型正文；只为选中页构建条目
    权限归属复用已提交任务快照；最终授权卡片/文件仍核验，规则不放宽
    Evidence:
        原件永远完整；大集合统计遍历所有行，保留极值精确位置及符号计数
        命名聚合指标不择优省略；均值仅为描述性统计，不代替科学合并/解释
        read_card select 按位点/token/指标/数值范围分页，返回原始叶子与来源
        不加 select 可完整分页读原件；所有入口受同一 sequence/ACL 约束
    source_refs = 全部归档来源；evidence_refs/sources.ref = LLM 实际采用依据
    L2 目录含知识状态、复盘时点、原条目与后续新证据入口；不自动断定知识失效
    recording_status 单列 pending/completed；待复盘不等于已形成科学结论
```
