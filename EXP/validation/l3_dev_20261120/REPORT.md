## 执行、隔离和资源

独立开发协议的候选准备使用独立 Landlock 读域和裁剪后的适配器。实际 GPU 探针能读取偏移选定的校准图并前向，直接读取其他校准图、search 图、官方图、新 dev 图和清单均被内核拒绝。返回 evaluator 后可读取这些文件。原有 worker 写隔离和训练审计继续生效。完整 dev 串行评测在长遍历前分别探测任务接口，调试回执与正式指标分开。[读边界探针](preparation_probe.py) · [实际回执](preparation_probe/receipt.json)

冻结模型的复用绑定原始实现、文件和独立重载状态。已有官方成绩按原协议保存，新 dev 按模型和清单身份归档。Coding 可使用版本化文本编辑、精确文本与函数定位，宿主读取完整源码计算内容身份。Safeguard 可按差异、故障和上次审查进入，也可重新读取完整必要代码。按需工程 Skill 的上游提交和裁剪范围列在各自文件内。[接口](../../../QAViT/docs/CODE_INTERFACES.md) · [三项工程技能](../../../QAViT/knowledge/coding/INDEX.md)

Coding 原生工具使用按任务的可写目录、只读授权源码、无网络与 GPU 直接访问的 CLI 配置，并在启动前实际探测。本机 codex-cli 0.170.0 的 bubblewrap 无权创建 namespace，真实 Coding 运行记录为 fallback，全程走既有宿主通道。文件交付、已完成 turn 用量聚合、中断恢复有定向测试；本机无法给出原生多工具调用成功率、完整计费或节省比例。
