# G-only 开发评价与工程回路

```text
读取任务的模型绑定、量化协议、开发清单和官方协议
恢复 Journal 中的主题、H3 灵感、独立 B、实验与源码版本
Generation 按父方案及独立灵感产生 H1/H2/H3，按需请求实验
  已有服务直接绑定；需要实现时 Coding 基于确切源码增量编辑
  宿主冻结完整实现和执行条件，Safeguard 核对科研语义
  worker 执行数值实验；真实结果或具体故障返回请求者
对于配置了 development 的任务
  Generation 可为中间完整候选请求 L3-dev
  三个完成候选分别获得完整 L3-dev 机会
  按绑定 calibration 构造并导出单份骨干，或独立加载已核验完整包
  核验冻结状态、覆盖及哈希，evaluator 加载指定开发视图
  在同一状态上运行分类和分割，分别记录同视图 FP/Q 和完成范围
  资源足够时每候选先分配主卡，再给支持独立加载的候选分配副卡
  按执行、源码、评价视图身份验证缓存和 Evidence
  开发结果分别按模型与视图归档，Generation 决定继续、修订或暂存
阶段性冻结的方法可单独运行官方评价，保留既有官方记录及来源
Recorder 归纳实测、混杂和下一步问题并写入 Memory
```
