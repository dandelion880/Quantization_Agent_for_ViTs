# QAViT 研究流程和本轮数值入口

```text
输入 ResearchBrief、用户绑定的模型/任务资产、精度/资源/数据协议、Journal 版本
恢复本轮候选、主题、启发、方法谱系、Evidence 和 Skill 快照
以实际前向和 metadata 确定模块、边、head、prefix、window、图像与标注身份

Generation 依据待解决的问题选主题，可组合八个研究维度
  从方法目录 read_asset 阅读原法与修订；read_method 恢复实际运行谱系
  构造独立 B 与三条候选；H1/H2 恢复完整父状态，H3 延续已知启发
  选择预测能区分机制的控制实验，按需要读取 Skill 或申请数值测量
Critic 给出有证据的质疑、风险与可检验的加强方案；Generation 作决定

对一个获选的数值请求
  冻结执行参数、模型身份、实际读取视图、候选版本与资源
  如继承父包，按确切引用独立加载并核对完整状态与校准来源
  新包可从用户 plan 或来源版本展开阶段，解析真实拓扑
  只在许可的有限校准集做统计、配对求解、离散搜索、像素生成或局部优化
  每个改变输入/执行前缀的阶段完成后再拟合下游，记录参考与更新对象
  实测精度分配后，按获选位宽重建整包
  持久化网格/索引/补偿/结构和版本；从冻结包重新加载并前向
  冻结评价从显式 head/视图读取真实预测、标签与 mask
  只读导数准备绑定参考后缀、损失、温度、扰动与视图，按 key 复用
  用同池完整候选检验代理排序，选择质量和资源开销随实验记录

Recorder 绑定来源、观察范围、失败和待判问题，发布确切版本
下一轮从 Journal、Evidence、可见 Skills 与当前主题恢复
正式运行时三条最终候选各自按原任务契约走 L3，按可比条件归档
```

本目录的短研究链在局部配对实验后停止。科研决策与测量见 `generation.json`、`focus_measurement.json`、`recorder.json` 和 `memory_restore.json`。
